§Recompute-based gradient math for the Mamba-3 single-SSD

The analytic backward of the single-pass MIMO-first scan:

  1. Recompute the forward intermediates (K1–K4) from the saved leaf inputs.
  2. Compute every chunk-local gradient batched: the K5 state-to-output (BLUE), the strict lower-triangular intra-chunk (LOWER) and the γ-weighted diagonal (DIAG) terms. BLUE and LOWER run one chunk group at a time (backward_chunk_group).
  3. Walk the K4 state-passing backward, the one recurrence.

This pathway applies the trapezoid weights inside the kernel, so it also returns d_gamma and d_scale. The extended K3 helper and K1/K2/K4 (forward and backward) come from the standard SSD scan.

All the math is on backend primitives, through the rank-tagged F wrapper. The recompute node runs with a generic backend B, where the high-level Tensor is not available, so the math uses the float_* ops of B.
