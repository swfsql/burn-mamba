§Recompute-based gradient math for the Mamba-3 single-SSD

The analytic backward of the single-pass MIMO-first scan:

  1. Recompute the forward intermediates (K1–K4) from the saved leaf inputs.
  2. Compute every chunk-local gradient batched: the K5 state-to-output (BLUE), the strict lower-triangular intra-chunk (LOWER) and the γ-weighted diagonal (DIAG) terms. BLUE and LOWER run one chunk group at a time.
  3. Walk the K4 state-passing backward, the one recurrence.

This pathway applies the trapezoid weights inside the kernel, so it also returns d_gamma and d_scale.

The backwards of K1–K4, BLUE and LOWER are in the kernels of the standard SSD scan. This file assembles them. It adds the terms of this pathway: the diagonal DIAG, the split of the K3 gradient into d_b and d_scale, and the boundary seeds.

All the math is on backend primitives, through the rank-tagged F wrapper. The recompute node runs with a generic backend B, where the high-level Tensor is not available, so the math uses the float_* ops of B.
