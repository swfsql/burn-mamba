pub fn repeat_micro_bs(t_bsw: Tensor<3>, micro_steps: usize) -> Tensor<3>
Expand description

Broadcast a per-token projection across the token’s micro-steps, so it can ride the folded sequence alongside the per-micro-step ones.

Used for the read C: only its last-micro-step copy is ever read (the others’ outputs are dropped by last_micro5), but that copy has to sit at the last position to pick up the right cumulative rotation.
