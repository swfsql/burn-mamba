Module scan 

Source
Expand description

The log-semiring scan that both members run on. The log-semiring prefix product that every positive member runs on.

An element is a 2×2 nonnegative matrix in log coordinates, one per [batch, position, head]. It has two shapes:

  • Mobius — all four entries, acting projectively on (ℓ, 0). The read is σ₀ − σ₁, so any constant shift of the product is allowed. The scan applies one after every combine, to keep the entries bounded.
  • Affine — the lower row is fixed at (−∞, 0), so only (a, b) is carried. The read lse(a + c₀, b) is absolute: no shift is allowed, and none is necessary.

prefix composes them by Hillis–Steele doubling, the same schedule as the quaternion scan (rotation::quat_cumprod): ⌈log₂ len⌉ full-width combines. fold is the sequential left fold, the reference for prefix in the tests.
