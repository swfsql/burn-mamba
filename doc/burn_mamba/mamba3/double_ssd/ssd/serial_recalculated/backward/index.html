The registered custom Backward node (autodiff op).

§Custom autodiff node for the Mamba-3 double-SSD recompute backward

Implements Mamba3DoubleSsdBackendExt for Autodiff<B> with one Burn Backward node. The forward keeps only its leaf inputs. The backprop replays the serial kernels and the gradient math in super::combined_backward, so the large intermediates are never kept. [burn_stack::utils::combined_grad] flattens the two outputs (y, final_state) into one tracked tensor, so one node covers both.
