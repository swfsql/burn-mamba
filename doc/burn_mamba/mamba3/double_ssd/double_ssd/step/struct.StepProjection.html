Expand description

One token’s in-projection unpacked into the step-shaped pieces shared by Mamba3::step_double_ssd and the constant-input shortcut Mamba3::step_infinite: the gate/value streams, the pre-rotation QK-normed B/C, the raw rotation channels, and the trapezoid coefficients.

Every per-micro-step stream carries a u axis (MambaProduct; u = 1 for stock Mamba-3). Self::micro peels one micro-step off it.

Fields§

§micro_steps: usize

Recurrence micro-steps per token — the size of the u axis below.

§z_bi: Tensor<2>

Per-token gate stream [batch, d_inner].

§c_bmhr: Tensor<4>

Per-token QK-normed, GQA-expanded, biased C — before the rotation. The read happens once, after all u writes.

§x_buhp: Tensor<4>

Value stream [batch, u, nheads, per_head_dim].

§b_bumhr: Tensor<5>

QK-normed, GQA-expanded, biased B — before the rotation. [batch, u, mimo_rank, nheads, state_rank].

§rot_bua: Option<Tensor<3>>

Raw rotation channels [batch, u, num_rotation_channels]; None for RotationKind::Real1D, which projects none.

§dt_buh: Tensor<3>

Δ [batch, u, nheads].

§alpha_buh: Tensor<3>

α = exp(Δ·A) [batch, u, nheads].

§beta_buh: Tensor<3>

β = (1−λ)·Δ·α [batch, u, nheads].

§gamma_buh: Tensor<3>

γ = λ·Δ [batch, u, nheads].
