pub fn split_rotation_channels<const D: usize>(
    proj: Tensor<D>,
    num_rotation_channels: usize,
    dim: usize,
) -> (Tensor<D>, Option<Tensor<D>>)
Expand description

Split the in-projection into everything-but-the-rotation and the trailing num_rotation_channels rotation channels — None when the block projects none, i.e. RotationKind::Real1D.

The rotation slice cannot simply be one more entry in the main split_into: Burn has no zero-width tensors, and split_with_sizes drops a zero-length segment rather than returning an empty one, so the destructuring would come up one part short.

§Shapes

  • proj : [..., d_in_proj] along dim
  • out : [..., d_in_proj − num_rotation_channels] and, if any, [..., num_rotation_channels]
