Expand description

A [1, len, 1] mask over a write axis: 0 at the first micro-step of each token (p ≡ 0 mod u), where a tap that does not cross tokens closes, and 1 elsewhere.

It broadcasts against any [batch, len, nheads] stream, in forward (len is the write axis, which starts at a token boundary) and in step (len is u, so the closed position is its first entry). At u = 1 every position is a token start, and the mask is all zeros. That alone is why TapPattern::HorizontalReset becomes None there.

Here, the admissibility rule of a pattern becomes a tensor. The caller decides which mass it applies to: λ for TapPattern::tap_crosses_tokens, μ for two_tap_lag1_crosses_tokens.
