§Mamba-3 — In-Projection Layout

One table holds the channel groups of the in-projection. Each row gives the key, the name, the width, the axis, the optimizer and the place of one group. The widths of the in-projection, the Muon plan and the split read this table. A new optional group needs one GroupKey variant, one row, and one field of InProjStreams with its take line.

The doc of Mamba3::in_proj gives the layout in full.

Burn has no zero-width tensors, and split_with_sizes drops a part of zero length. So the table lists only the groups that the block projects, and each row has a width above zero. Each row then has exactly one part of the split.
