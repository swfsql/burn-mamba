§Serial SSD with a custom, memory-efficient backward (Mamba-2)

This is the SerialRecalculated path. The forward goes through the Mamba2BackendExt trait. Thus an Autodiff backend can use a custom backward that recomputes the per-chunk intermediates instead of storing them (see super::backward / super::combined_backward). This costs a little extra compute and saves ~⅓ of the training memory.

The default body of the trait and the custom backward both call the standard SSD scan. This file holds what Mamba-2 adds to the forward of that scan: the inputs v = Δ·x and da = Δ·A, and the D skip.

Every plain (non-autodiff) backend uses the default body of the trait. The [burn_stack::impl_backend_ext_for_burn_backends!] macro makes these per-backend impls.
