§Recompute-based gradient math for the Mamba-2 SSD

The analytic backward of the SerialRecalculated path. The standard SSD scan holds the gradient of the scan. This file holds what Mamba-2 adds to it. It forms the inputs v = Δ·x and da = Δ·A, and it calls the backward of the scan. Then it applies the chain rule back to its own inputs, with the backward of the D skip:

d_x = d_v·Δ + d_y·D
d_Δ = Σ_p d_v·x + d_da·A
d_A = Σ_{b,n,l} d_da·Δ
d_D = Σ_{b,n,l,p} d_y·x

The scan returns d_b, d_c, d_initial_state and d_origin directly. The length-1 m axis of the scan exists only at the call. ADR-0010 records why this path does not follow the reference line by line.

All the math is on backend primitives, through the rank-tagged F wrapper. The recompute node runs with a generic backend B, where the high-level Tensor (pinned to the global Dispatch backend) is not available.
