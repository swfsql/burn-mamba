burn_mamba::family

Module block 

Source
Expand description

MambaBlock, its caches, and the type aliases of the containers. The run-time family choice: one enum over the three blocks.

MambaBlock fills Block. So each generic container of burn-stack takes it with no extra code, and MambaLatentNet, MambaVocabNet, MambaBidiLayers and MambaHNetVocabNet are only type aliases. A call panics when its cache or its SSD path is of another family than the block. docs/adr/0009-family-choice-at-the-block.md gives the consequences for the parameter paths, the caches and a mixed stack.
