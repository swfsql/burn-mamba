Token embedding table, weight shape [padded_vocab, d_model].

§flag_embedding: Param<Tensor<1>>

The flag input, [d_model]: added to the embedding of a token whose flag is 1. Zero at init, so a new network reads no flag.

§layers: Layers<MambaBlock>

The shared layer stack.

§norm_f: RmsNorm

Final RMSNorm applied before the LM head (norm_f).

§lm_head: Option<Linear>

Optional dedicated LM head. None ⇒ weight-tied (reuse embeddingᵀ).

§flag_head: Linear

The flag output: one logit per position (d_model → 1), the last column of the logits.
