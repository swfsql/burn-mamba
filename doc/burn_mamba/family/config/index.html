Module config 

Source
Expand description

The serializable { shape, block } configs, and MambaBlockConfig. The serializable configs of the run-time family choice.

Each config is the pair { shape, block } (burn-stack ADR-0007). The shape is the half that has no block (see [burn_stack::modules::shape]). The block is a MambaBlockConfig, and its variant selects the family. A new knob of a stack goes in the shape of burn-stack, and no config here changes.

#[derive(Config)] takes no generics. So each container has one concrete struct here.
