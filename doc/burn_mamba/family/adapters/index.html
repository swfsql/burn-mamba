burn_mamba::family

Module adapters 

Source
Expand description

The Block / BlockConfig / CacheStack impls of each family. The place where each family connects to the block-generic stack: impl Block, impl BlockConfig, impl CacheStack.

Each CacheStack impl holds only the slot logic of its family. The backend hop of a cache follows from its cache traversal in crate::family::cache_traversal.

Three trait methods have the name of an inherent method of their family: zero_cache, untied_params and muon_projections. Each one calls that inherent method by its type path, for example Mamba1::zero_cache(self, batch, device) and Mamba1Config::muon_projections(self). A call on self selects the same method, but it reads like an endless recursion.
