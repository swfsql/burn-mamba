pub(crate) fn real_end_b(pad_bs: &Tensor<2, Bool>) -> Tensor<1, Int>
Expand description

One past the last real row of each slot, [batch]: where the slot reads its cache fields. Under right padding, this is the number of real rows. In a packed row (crate::packing), pad rows can also end each segment, and only the last real row counts. A slot with no real row gives 0.
