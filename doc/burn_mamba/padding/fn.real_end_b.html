pub(crate) fn real_end_b(pad_bs: &Tensor<2, Bool>) -> Tensor<1, Int>
Expand description

One past the last real token of each row, [batch]: where the row reads its cache fields. Under right padding, this is the number of real tokens. In a packed row (crate::packing), padded positions can also end each segment, and only the last real token counts. A row with no real token gives 0.
