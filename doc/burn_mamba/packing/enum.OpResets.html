Enum OpResets 

Source 
pub enum OpResets<B: Backend> {
    None,
    Some {
        keep_bn: FloatTensor<B>,
        origin_bhpr: FloatTensor<B>,
    },
}
Expand description

The resets of a packed row as an SSD op takes them, on the primitives of B. An op argument of this type has #[extension_type].

This enum takes the place of an Option of the two tensors. Burn has no ExtensionType for Option, and the orphan rule stops this crate from adding one.

Variants§

§

None

No chunk of the call has a reset.

§

Some

The chunks with a reset, and the state that they start from.

Fields

§keep_bn: FloatTensor<B>

[batch, nchunks]: 0 at a chunk that starts a new segment, 1 elsewhere. It is a constant: the op registers no gradient for it.

§origin_bhpr: FloatTensor<B>

[batch, nheads, per_head_dim, state_rank]: the state that each such chunk starts from.

pub(crate) fn into_recompute( self, like: &FloatTensor<Autodiff<B, C>>, ) -> (Option<FloatTensor<B>>, FloatTensor<Autodiff<B, C>>)

The resets as the Autodiff impl of an SSD op gives them to its recompute node:

  • keep_bn, on the primitives of B: a constant, with no gradient.
  • origin_bhpr: a tracked input. For None, it is a placeholder.
