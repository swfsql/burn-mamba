pub fn detach_params<T: Module>(module: T) -> T
Expand description

Return module with every parameter detached from the autodiff graph.

Call it on a clone: the detached copy is what the no-grad part runs, while the original keeps the tracked parameters the back-propagated part needs. Under weight sharing both refer to the same weights, and the gradient then accumulates from the tracked applications alone.

A no-op in effect when the module is not on an autodiff backend — and, per the module warning, not a way to save memory.
