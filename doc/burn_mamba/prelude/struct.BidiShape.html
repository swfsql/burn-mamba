Expand description

The block-independent knobs of a BidiLayers stack.

It is its own shape, not a NetworkShape: the pairs carry per-pair merge configs and a BidiSchedule, and this path has no feed-forward or init policy.

Fields§

§n_real_layers: usize

Number of real (weight-bearing) layers. Must be even: they pair up.

§outputs_merge: Vec<OutputMergeConfig>

One merge config per real pair, length n_real_layers / 2.

§n_virtual_layers: Option<(usize, BidiSchedule)>

Optional layer schedule over the real pairs.

§ignore_first_residual: bool

Zero the first virtual pair’s residual.

§ignore_last_residual: bool

Zero the last virtual pair’s residual.

§class_latents: Vec<ClassLatent>

Stack-level class latents, spliced once before the first pair.

§residuals: ResidualsConfig

Inter-pair residual scheme.

§untied: Vec<LayerUntied>

The parameters of the layers that are held once per application, not tied (see NetworkShape::untied).
