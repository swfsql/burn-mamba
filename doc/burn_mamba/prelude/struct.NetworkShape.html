Expand description

The block-independent half of a network config: everything about the stack rather than the block.

Fields§

§n_real_layers: usize

Number of real layers.

§n_virtual_layers: Option<(usize, Schedule)>

Optional layer schedule: run n virtual layers over the real layers, mapped by a Schedule. Depth at no parameter cost. The reference architectures do not do this.

§grad_horizon: Option<GradHorizon>

The gradient horizon (for deep recursion): which virtual layers back-propagate. The others run on the inner backend. None ⇒ track the whole stack. See Layers::grad_horizon.

§class_latents: Vec<ClassLatent>

Stack-level class latents, spliced into the sequence before the first layer (width d_model).

§ignore_first_residual: bool

Suppress the first virtual layer’s residual.

§ignore_last_residual: bool

Suppress the last virtual layer’s residual (the output is then the transform of the last layer alone).

§residuals: ResidualsConfig

Inter-layer residual scheme (plain additive vs Multi-Gate). The reference architectures are Standard.

§mlp: Option<GatedMlpConfig>

Optional per-layer SwiGLU feed-forward sub-block, with its own pre-norm and inner residual. None ⇒ each layer has only its block.

Every reference language model of the recurrent families has one. The architecture is the macro design of Llama, with a recurrent block in place of self-attention. So a SwiGLU MLP of GatedMlpConfig::from_hidden_ratio width follows each block.

§untied: Vec<LayerUntied>

The parameters of the layer itself that are held once per application of its real layer, not tied across them. The block config names those of the block. Only virtual layers give a real layer more than one application. See [crate::utils::untied].

§init: Option<InitPolicy>

Optional post-build re-initialisation of the whole network (the reference initializer_range + residual rescale). None ⇒ keep the per-module defaults of Burn. See InitPolicy.

impl NetworkShape

pub fn residuals_per_layer(&self) -> usize

The number of residual sub-blocks per layer of this stack: the block, plus the feed-forward when there is one. An InitPolicy rescale counts over this number.

pub fn n_applied_layers(&self) -> usize

The depth of the stack in applied layers: the virtual count when there is one, else the real count.

pub fn init_policy(&self) -> Option<InitPolicy>

The InitPolicy to apply after the build, with its rescale resolved against the depth of this stack.

pub fn apply_init<M>(&self, module: M) -> M
where M: Module,

Apply Self::init_policy to a built module (a no-op when unset).

pub fn layers<C>(&self, block: C) -> LayersBuilder<C>
where C: BlockConfig,

The layer-stack builder for a given block config.

pub fn init<C>( &self, block: C, device: &Device, ) -> Layers<<C as BlockConfig>::Block>
where C: BlockConfig,

Allocate the bare layer stack on device, with the init policy applied.

pub fn retie<M>(&self, layers: Layers<M>) -> Layers<M>
where M: Block,

Tie the untied copies of a stack back together after Self::apply_init. Its redraw of every 2-D weight would start each application from a draw of its own (see Layers::retie). A no-op without an init policy.

pub fn muon_plan<C>(&self, block: &C) -> MuonPlan
where C: BlockConfig,

The MuonPlan for a stack of this shape at block: the fused projections of the block, plus those of the optional MLP.

The I/O weights of a network (in_proj/out_proj, the embedding and LM head, class-marker tables) stay out on purpose (see [crate::optim]).
