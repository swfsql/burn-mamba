§The kernels of the standard SSD scan

The forward K1–K5 on backend primitives, and the analytic backward of each kernel beside its forward. super::combined_backward() and the backward of the single-SSD pathway assemble these functions. Only the terms of a pathway stay outside this file.

The K5 backward serves the two K5 forwards. The intra-chunk term of each forward differs only in its mask diagonal and in a scale per source position. The other term, BLUE, is the same in both.

A backward takes each large tensor by value. A caller clones a tensor only if the caller reads that tensor again.

The kernels run under a generic backend B, where the high-level Tensor (pinned to Dispatch) is not available. So the math uses the rank-tagged [F] primitive wrapper.
