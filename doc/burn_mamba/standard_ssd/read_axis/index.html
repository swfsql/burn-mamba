§The read axis on primitives

The helpers of the read axis for the recompute-backward math. A chunk has chunk_len write positions, and a read position is the last of each run of read_stride write positions. Each helper is the identity at read_stride = 1.

The Tensor twins of these helpers are in src/mamba3/helpers.rs. Every kernel of this crate has this split: a Tensor body, and an F<B, _> body that a Backward node can run (see fprim). Both are reshape-and-narrow, so neither needs an op that F does not have.
