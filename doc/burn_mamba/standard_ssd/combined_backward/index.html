§The analytic backward of the standard SSD scan

The steps of the backward of one SSD call:

  1. Recompute the forward intermediates (K1–K4) from the saved leaf inputs. They are not stored.
  2. Run the chunk-local K5 backward batched, one chunk group at a time.
  3. Walk the K4 state-passing backward: the one recurrence, and the only walk.
  4. Run the K3, K2 and K1 backwards batched.

The backward of each kernel is in super::kernels, beside its forward. This file assembles them. The single-SSD pathway assembles the same functions, with its own terms.

The fused L·M length carries the mimo_rank axis through the intra-chunk products.

All the math is on backend primitives, through the rank-tagged F wrapper. The recompute node runs with a generic backend B, where the high-level Tensor is not available, so the math uses the float_* ops of B.
