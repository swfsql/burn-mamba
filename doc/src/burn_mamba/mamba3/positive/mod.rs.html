1//! # Positive systems that set the gate
2//!
3//! A Mamba-3 head is a linear **parameter-varying** plant: its transition,
4//! write and read are linear in the state, with coefficients `ρₜ = g(uₜ)` set
5//! token by token from the input. This module adds a second, smaller system
6//! next to it — one scalar per head — whose output sets some of those
7//! coefficients instead:
8//!
9//! ```text
10//!   σₜ = Mₜ ⊗ σₜ₋₁          Mₜ from the in-projection alone
11//!   ρₜ = g(uₜ, σₜ₋₁)        read by the plant, never written by it
12//! ```
13//!
14//! The one-way path is the whole design rule: `Mₜ` reads the token and never
15//! the plant, so the cascade still scans — the plant's chunkwise SSD takes the
16//! scheduled coefficients as ordinary tensors, and `σ` has an associative scan
17//! of its own ([`scan`]). A gain that read the plant's state would close the
18//! loop and lose both.
19//!
20//! ## The members are positive linear systems, in log coordinates
21//!
22//! Every `Mₜ` is a **nonnegative** 2×2 matrix acting projectively on a
23//! nonnegative 2-vector, so `σ` is carried as a log-vector and the product is
24//! the log-semiring one, `(X ⊗ Y)ᵢⱼ = log Σₖ exp(Xᵢₖ + Yₖⱼ)` ([`scan::lse`]).
25//! Ordinary arithmetic on positives *is* that semiring in log coordinates, so
26//! one kernel carries both members:
27//!
28//! | member | `Mₜ` | carries | port |
29//! |---|---|---|---|
30//! | [`Gain::Kalman`] | shift by `ν`, predict, shift by `γ` (projective, [`scan::Mobius`]) | `ℓ = ln Λ`, the head's precision | `A` and `C` |
31//! | [`Tropical::MaxPlus`] | `[[a, b], [−∞, 0]]` (affine, [`scan::Affine`]) | `c`, a soft max-plus register | `D` |
32//!
33//! Log coordinates are forced, not convenient: the Kalman member's natural
34//! entries include `1/α`, which overflows at a reset token, and the tropical
35//! one's growth (`a > 0`) overflows in any linear form.
36//!
37//! ### The Kalman gate ([`kalman`])
38//!
39//! Mamba's update is an exponential moving average of a rank-one setpoint whose
40//! gain `1 − α` is *projected*. A Kalman filter has the same form with the gain
41//! *computed* from a variance that accumulates evidence. In information form
42//! (`Λ = 1/P`, `η = Λ·S`) the per-head scalar filter is an SSD whose decay is
43//! computed:
44//!
45//! ```text
46//!   dₜ = αₜ / (1 + qₜ·αₜ·(Λₜ₋₁ + νₜ))
47//!   ηₜ = dₜ·ηₜ₋₁ + (the block's own write)        ← the plant, unchanged
48//!   Λₜ = dₜ·(Λₜ₋₁ + νₜ) + γₜ                       ← the same recurrence on ones
49//! ```
50//!
51//! with the trapezoid's masses as the evidence — `γₜ` the right endpoint, `νₜ`
52//! the left one's installment, which the plant pays a step late and transports
53//! by that step's decay (exact for a lag-1 tap, an upper bound at lag `u`:
54//! [`kalman`]); without a tap, `γ = Δ` and `ν = 0`. Stock's `αₜ` sits in the
55//! covariance (`a² = 1/α`), and `qₜ = κₕ·Δₜ` — Brownian: doubt grows with
56//! elapsed time. [`Gain::KalmanProjectedNoise`] multiplies `q` by a projected
57//! `exp(rₜ)`, so a token can add doubt without evidence (a gap). Only the decay
58//! changes: `dₜ` replaces `αₜ` where it is formed, before any consumer reads
59//! it, so the trapezoid's transports, the tap slots and single-SSD's key scale
60//! all follow. At `κ = 0` the block is stock bit for bit (`log1p(0) = 0`). Two
61//! facts carry the design:
62//!
63//! - **a ceiling:** `Λₜ < 1/qₜ + γₜ` whatever the history, so strong evidence
64//!   dominates for a bounded time rather than one growing with its strength;
65//! - **a contraction:** for `q, γ > 0` the matrix is entrywise positive, so by
66//!   Birkhoff's theorem it contracts the Hilbert distance `|ln Λ − ln Λ'|` by at
67//!   least `tanh(¼·ln(1 + 1/(q·γ)))` per step, with no `α` in the bound — the
68//!   cache's initial `Λ`, and any rounding in it, is forgotten geometrically.
69//!
70//! The block also reads through `(Λₜ + ε)^(−ωₕ)` (`ω = 0` at init): `ω = 1`
71//! reads the estimate `S = η/Λ` instead of the information `η` — a mean rather
72//! than a sum. The scale lands on the SSD's readout *before* the `D` skip and
73//! the register's `c·e`, so a per-head output norm does not remove it: it
74//! removes only what the three terms share, and `ω` sets the SSD's share
75//! against the other two (it cancels only when they vanish, and then only up
76//! to the norm's `ε`).
77//!
78//! ### The tropical register ([`tropical`])
79//!
80//! The affine member with its log-decay allowed to be positive:
81//!
82//! ```text
83//!   cₜ = log(exp(cₜ₋₁ + aₜ) + exp(bₜ))   →   max(cₜ₋₁ + aₜ, bₜ)   as the scale grows
84//! ```
85//!
86//! Linear in the (max, +) semiring, so exactly scannable, yet it computes what
87//! no linear recurrence does: `(x, 0)` is the Lindley recursion (a counter
88//! clamped at zero), `(0, v)` a running maximum, `(−∞, b)` a reset to `b`. The
89//! soft value overshoots the hard one by at most `ln(T + 1)` in projection
90//! units, so the temperature is the in-projection's own scale and not a knob.
91//! It feeds the readout, `yₜ,ₕ += cₜ,ₕ·eₕ` with a zero-initialised `eₕ ∈ ℝᵖ`.
92//!
93//! ## Resolution
94//!
95//! Both run on the folded axis, like the recurrence (one matrix per micro-step
96//! under [`crate::mamba3::product`]); what the `C` and `D` ports read is the
97//! value at each token's last micro-step, the read axis. The mimo ranks share
98//! one state, hence one transition, hence one `Λ` per head broadcast over them
99//! (`info/mamba-3/mimo-as-batch.md` §7 makes the same argument for the rotation).
100

112/// `ln 0`, kept finite.
113///
114/// A log-sum-exp of two `−∞` is `NaN`, and so is `0·(−∞)` in a zero-initialised
115/// readout, so structural zeros are this instead. It is far enough below every
116/// real entry to vanish under `exp`, and `2·LOG_ZERO` still fits in f16, which
117/// every combine re-clamps to.
118pub const LOG_ZERO: f32 = -3.0e4;
119
120/// How a head's decay is formed — projected from the token, or computed by a
121/// per-head Kalman filter on top of that projection. See the module header.
122///
123/// Structural, like [`Trapezoid`](crate::mamba3::trapezoid::Trapezoid): a
124/// Kalman member allocates the per-head `κ` and `ω`, a cache slot for `ln Λ`,
125/// and under [`KalmanProjectedNoise`](Self::KalmanProjectedNoise) one
126/// in-projection channel per (head, micro-step).
127#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, serde::Serialize, serde::Deserialize)]
128pub enum Gain {
129    /// Stock Mamba-3: `αₜ = exp(Δₜ·Aₜ)`, projected.
130    #[default]
131    Projected,
132    /// The tied arm: `qₜ = κₕ·Δₜ`, the evidence the trapezoid's own masses. No
133    /// in-projection channel; stock bit for bit at `κ = 0`.
134    Kalman,
135    /// `qₜ = κₕ·Δₜ·exp(rₜ)` with `rₜ` projected per (head, micro-step): a token
136    /// may add doubt without adding evidence, which the tied arm cannot (its
137    /// doubt and its evidence both scale with `Δ`). `r ≡ 0` is
138    /// [`Kalman`](Self::Kalman).
139    KalmanProjectedNoise,
140}
141
142impl Gain {
143    /// Whether the decay is computed (a `ln Λ` slot, a `κ` per head).
144    pub fn is_kalman(self) -> bool {
145        !matches!(self, Gain::Projected)
146    }
147
148    /// Whether the in-projection carries the noise channel `r`.
149    pub fn projects_noise(self) -> bool {
150        matches!(self, Gain::KalmanProjectedNoise)
151    }
152}

154/// Whether each head carries a tropical register feeding its readout. See the
155/// module header.
156#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, serde::Serialize, serde::Deserialize)]
157pub enum Tropical {
158    /// No register.
159    #[default]
160    None,
161    /// One soft max-plus register per head: two in-projection channels
162    /// `(a, b)` per (head, micro-step), a cache slot, and the readout `eₕ`.
163    MaxPlus,
164}
165
166impl Tropical {
167    /// Whether the block carries the register.
168    pub fn is_on(self) -> bool {
169        matches!(self, Tropical::MaxPlus)
170    }
171}

173/// The fresh-sequence slots `(ln Λ, c)`, each `[batch, nheads]` at
174/// [`LOG_ZERO`] — no evidence yet, the max of nothing — or `None` for a system
175/// the block does not carry. Every cache constructor goes through this.
176pub fn fresh_slots(
177    gain: Gain,
178    tropical: Tropical,
179    batch: usize,
180    nheads: usize,
181    device: &Device,
182) -> (Option<Tensor<2>>, Option<Tensor<2>>) {
183    let slot = || Tensor::full([batch, nheads], LOG_ZERO, device);
184    (gain.is_kalman().then(slot), tropical.is_on().then(slot))
185}
