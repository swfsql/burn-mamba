1//! # Quaternion (k=4) rotational state — the non-abelian generalisation of RoPE
2//!
3//! Mamba-3's data-dependent RoPE realises a **complex-valued** SSM: the state
4//! transition factors as a per-head scalar decay times a block-diagonal of
5//! `2×2` rotations (paper Prop. *Complex-to-Real SSM Equivalence*), and because
6//! `SO(2) ≅ U(1)` is **abelian** the cumulative rotation collapses to a
7//! `cumsum` of angles and is absorbed into `B`/`C` (the "RoPE trick", Prop.
8//! *Complex SSM, Data-Dependent RoPE Equivalence*).  See
9//! [`crate::mamba3::double_ssd::double_ssd::apply_rope`].
10//!
11//! This module implements the next rung of the ladder: a **quaternion**
12//! (`k = 4`) rotational state, i.e. the transition's rotation lives in the
13//! left-isoclinic subgroup `SU(2) ⊂ SO(4)` instead of `SO(2)`.  Unit
14//! quaternions under multiplication are `SU(2)`, which is **non-abelian** and
15//! contains non-solvable finite subgroups (the binary icosahedral group
16//! `2I = SL(2,5)`, a double cover of `A₅`).  By Barrington's theorem this lifts
17//! the layer's reachable state-tracking from the solvable/`TC⁰` regime (parity,
18//! mod-k) toward `NC¹`, which abelian rotations provably cannot reach.
19//!
20//! ## What survives, what changes
21//!
22//! The key fact (derivable purely from telescoping + orthogonality, **without**
23//! commutativity — see the crate discussion) is that the RoPE *factoring*
24//! survives intact: with the **ordered** cumulative rotation
25//! `Pₜ = Rₜ Rₜ₋₁ ⋯ R₁`,
26//!
27//! ```text
28//!   Cₜᵀ (Rₜ⋯Rᵢ₊₁) Bᵢ  =  (Pₜᵀ Cₜ)ᵀ (Pᵢᵀ Bᵢ)  =  C̄ₜᵀ B̄ᵢ ,
29//! ```
30//!
31//! so the scalar-decay SSD core (`L ⊙ C̄B̄ᵀ`) is **unchanged** — only the
32//! projections `B̄ᵢ = Pᵢᵀ Bᵢ`, `C̄ₜ = Pₜᵀ Cₜ` are rotated.  What is lost is the
33//! closed-form `cumsum`: the cumulative rotation must be built by an
34//! **associative scan over the per-step quaternions** ([`quat_cumprod`]) rather
35//! than a sum of angles.  Because a product of unit quaternions is again a unit
36//! quaternion, the scan stays exactly orthogonal (no drift, no `wrap_angle`
37//! needed), and the cross-chunk carry is a single quaternion per block/head —
38//! the exact analogue of `cum_angle` in the existing caches.
39//!
40//! `SO(2)` (today's `apply_rope`) is the abelian collapse: restricting each
41//! quaternion to a single fixed axis makes them commute and reduces
42//! [`quat_cumprod`] to a `cumsum` of half-angles (asserted in the tests).
43//!
44//! ## Pipeline (the `k = 4` instantiation of the rotation block)
45//!
46//! ```text
47//!   per-step unit quaternion qₜ      (materialise from the in-projection; caller)
48//!        │  quat_cumprod (assoc. scan, + cross-chunk carry)
49//!        ▼
50//!   cumulative rotation Qₜ
51//!        │  rotate_state_rank_blocks(B, conj(Qₜ)) , rotate_state_rank_blocks(C, conj(Qₜ))
52//!        ▼
53//!   B̄, C̄  ──►  standard scalar-decay SSD  (unchanged)
54//! ```
55//!
56//! Quaternion layout: the last axis has size 4 and holds `(w, x, y, z)` with
57//! `w` the real part.  A `state_rank` of `r = 4·J` is treated as `J` independent
58//! quaternion blocks; the rotation acts within each block, exactly as RoPE acts
59//! within each `2`-pair.  This module is a self-contained, tested reference for
60//! the math; wiring it into the [`Mamba3`](crate::mamba3::mamba3::Mamba3) block
61//! is a separate, larger change (the SSD kernels themselves need no edits).

71/// Which rotational-state algebra the block uses for the data-dependent
72/// positional rotation of `B`/`C`.
73///
74/// - [`Complex2D`](RotationKind::Complex2D) — the abelian `SO(2)`/complex RoPE
75///   that Mamba-3 ships: cumulative *angles* via `cumsum`, applied by
76///   [`apply_rope`]. The default; behaviourally unchanged.
77/// - [`Quaternion4D`](RotationKind::Quaternion4D) — the non-abelian
78///   `SU(2) ⊂ SO(4)` quaternion rotation of this module: cumulative *product*
79///   via [`quat_cumprod`], applied by [`rotate_state_rank_blocks`]. Richer
80///   state-tracking; selects the [`RotationState::Quaternion`] cache accumulator.
81#[derive(Debug, Clone, Copy, PartialEq, Eq, serde::Serialize, serde::Deserialize)]
82pub enum RotationKind {
83    /// Abelian complex (`SO(2)`) RoPE — the current default behaviour.
84    Complex2D,
85    /// Non-abelian quaternion (`SU(2)`) rotation.
86    Quaternion4D,
87}
88
89impl Default for RotationKind {
90    fn default() -> Self {
91        RotationKind::Complex2D
92    }
93}

95/// The cumulative-rotation accumulator carried between calls in a Mamba-3 cache
96/// — the variant matching the block's [`RotationKind`].
97///
98/// - [`Angle`](RotationState::Angle) — abelian per-pair cumulative RoPE angle,
99///   shape `[batch, nheads, num_rope_angles]` (today's `cum_angle`).
100/// - [`Quaternion`](RotationState::Quaternion) — per-block cumulative unit
101///   quaternion, shape `[batch, nheads, blocks, 4]`, produced by
102///   [`quat_cumprod`].
103///
104/// This is the cache-level counterpart of [`RotationKind`]. It is defined here
105/// (the rotation module owns the accumulator type); substituting it for the
106/// pathway caches' `cum_angle_bha` field happens together with the forward/step
107/// wiring that consumes it.
108#[derive(Module, Debug)]
109pub enum RotationState {
110    /// Abelian RoPE cumulative angle, shape `[batch, nheads, num_rope_angles]`.
111    Angle(Tensor<3>),
112    /// Quaternion cumulative rotation, shape `[batch, nheads, blocks, 4]`.
113    Quaternion(Tensor<4>),
114}
115
116impl RotationState {
117    /// Zero-initialised abelian angle accumulator `[batch, nheads, num_rope_angles]`.
118    pub fn zeros_angle(
119        batch: usize,
120        nheads: usize,
121        num_rope_angles: usize,
122        device: &Device,
123    ) -> Self {
124        RotationState::Angle(Tensor::zeros([batch, nheads, num_rope_angles], device))
125    }
126
127    /// Identity-initialised quaternion accumulator `[batch, nheads, blocks, 4]`
128    /// (every block is the identity quaternion `(1, 0, 0, 0)`).
129    pub fn identity_quaternion(
130        batch: usize,
131        nheads: usize,
132        blocks: usize,
133        device: &Device,
134    ) -> Self {
135        let w = Tensor::ones([batch, nheads, blocks, 1], device);
136        let xyz = Tensor::zeros([batch, nheads, blocks, 3], device);
137        RotationState::Quaternion(Tensor::cat(vec![w, xyz], 3))
138    }
139
140    /// Unwrap the abelian angle accumulator; panics if this is a quaternion.
141    pub fn angle(self) -> Tensor<3> {
142        match self {
143            RotationState::Angle(a) => a,
144            RotationState::Quaternion(_) => {
145                panic!("RotationState is Quaternion, expected Angle")
146            }
147        }
148    }
149
150    /// Unwrap the quaternion accumulator; panics if this is an angle.
151    pub fn quaternion(self) -> Tensor<4> {
152        match self {
153            RotationState::Quaternion(q) => q,
154            RotationState::Angle(_) => panic!("RotationState is Angle, expected Quaternion"),
155        }
156    }
157
158    /// Run the [`NaN`/`Inf` guards](crate::utils::sanity) on the held tensor.
159    pub fn sanity(&self) {
160        match self {
161            RotationState::Angle(a) => crate::modules::sanity(a),
162            RotationState::Quaternion(q) => crate::modules::sanity(q),
163        }
164    }
165
166    /// The **physical-frame** view of a cache's SSM state: rotate the `r` axis
167    /// by the inverse of the rotation absorbed into B/C (negated cumulative
168    /// angle / un-conjugated cumulative quaternion), so the result is what
169    /// raw, un-rotated C reads — the step-side counterpart of
170    /// [`RotationSeq::derotate_states`], used by the stepwise diagnostics and
171    /// the forward↔step moments parity tests.
172    ///
173    /// `rope_dim` / `rotate_pairwise` select the [`Angle`](RotationState::Angle)
174    /// pairing (pass the block's `rope_dim` and `mimo_rank == 1`); the
175    /// quaternion width comes from the accumulator itself.
176    ///
177    /// # Shapes
178    /// - `ssm_bhpr`: `[batch, nheads, per_head_dim, state_rank]`
179    pub fn derotate_state(
180        &self,
181        ssm_bhpr: Tensor<4>,
182        rope_dim: usize,
183        rotate_pairwise: bool,
184    ) -> Tensor<4> {
185        let [batch, nheads, per_head_dim, _state_rank] = ssm_bhpr.dims();
186        match self {
187            RotationState::Angle(cum_bha) => {
188                if rope_dim == 0 {
189                    return ssm_bhpr;
190                }
191                let num_angles = cum_bha.dims()[2];
192                let ang_bhpa = cum_bha
193                    .clone()
194                    .unsqueeze_dim::<4>(2)
195                    .expand([batch, nheads, per_head_dim, num_angles]);
196                apply_rope_partial::<4>(ssm_bhpr, -ang_bhpa, rope_dim, rotate_pairwise)
197            }
198            RotationState::Quaternion(q_bhj4) => {
199                let blocks = q_bhj4.dims()[2];
200                let q_bhpj4 = q_bhj4
201                    .clone()
202                    .unsqueeze_dim::<5>(2)
203                    .expand([batch, nheads, per_head_dim, blocks, 4]);
204                rotate_blocks_partial::<4, 5>(ssm_bhpr, q_bhpj4, blocks * 4)
205            }
206        }
207    }
208}

210/// Per-token cumulative rotation of one `forward` call — the sequence-resolved
211/// counterpart of the cache's final [`RotationState`], exported by
212/// [`rotate_bc_forward`] (it is already materialised there) for the
213/// physical-frame state moments: the per-token states must be de-rotated by
214/// the **inverse** of the rotation absorbed into B/C (see
215/// [`Self::derotate_states`]). Carries its own application metadata so a
216/// consumer cannot re-derive a mismatched pairing layout.
217#[derive(Debug, Clone)]
218pub enum RotationSeq {
219    /// Abelian cumulative RoPE angles.
220    Angle {
221        /// Cumulative angles `[batch, sequence, nheads, num_rope_angles]`
222        /// (un-wrapped — every consumer is `2π`-periodic).
223        cum_bsha: Tensor<4>,
224        /// Number of rotated B/C entries (`0` ⇒ the rotation is the identity).
225        rope_dim: usize,
226        /// Interleaved/NeoX (SISO) vs half-and-half/GPT-J (MIMO) pairing —
227        /// exactly the flag [`apply_rope_partial`] was called with.
228        rotate_pairwise: bool,
229    },
230    /// Quaternion cumulative rotation `[batch, sequence, nheads, blocks, 4]`;
231    /// rotates the first `4·blocks` state-rank entries as consecutive blocks.
232    Quaternion {
233        /// Cumulative unit quaternions (the `quat_cumprod` output).
234        cum_bshj4: Tensor<5>,
235    },
236}
237
238impl RotationSeq {
239    /// A value-identical copy detached from any autodiff graph.
240    pub fn detached(&self) -> Self {
241        match self {
242            RotationSeq::Angle {
243                cum_bsha,
244                rope_dim,
245                rotate_pairwise,
246            } => RotationSeq::Angle {
247                cum_bsha: cum_bsha.clone().detach(),
248                rope_dim: *rope_dim,
249                rotate_pairwise: *rotate_pairwise,
250            },
251            RotationSeq::Quaternion { cum_bshj4 } => RotationSeq::Quaternion {
252                cum_bshj4: cum_bshj4.clone().detach(),
253            },
254        }
255    }
256
257    /// Zero-pad the sequence axis to `padded_len` (the SSD chunk padding).
258    /// Pad values are never read un-masked: the moments mask excludes pad
259    /// positions before accumulation.
260    pub fn pad_to(self, padded_len: usize) -> Self {
261        match self {
262            RotationSeq::Angle {
263                cum_bsha,
264                rope_dim,
265                rotate_pairwise,
266            } => {
267                let [batch, sequence, nheads, num_angles] = cum_bsha.dims();
268                let cum_bsha = if sequence == padded_len {
269                    cum_bsha
270                } else {
271                    let pad = Tensor::zeros(
272                        [batch, padded_len - sequence, nheads, num_angles],
273                        &cum_bsha.device(),
274                    );
275                    Tensor::cat(vec![cum_bsha, pad], 1)
276                };
277                RotationSeq::Angle {
278                    cum_bsha,
279                    rope_dim,
280                    rotate_pairwise,
281                }
282            }
283            RotationSeq::Quaternion { cum_bshj4 } => {
284                let [batch, sequence, nheads, blocks, _four] = cum_bshj4.dims();
285                let cum_bshj4 = if sequence == padded_len {
286                    cum_bshj4
287                } else {
288                    let pad = Tensor::zeros(
289                        [batch, padded_len - sequence, nheads, blocks, 4],
290                        &cum_bshj4.device(),
291                    );
292                    Tensor::cat(vec![cum_bshj4, pad], 1)
293                };
294                RotationSeq::Quaternion { cum_bshj4 }
295            }
296        }
297    }
298
299    /// Rotate the `state_rank` axis of per-token cache-frame states **back to
300    /// the physical frame** — the inverse of the rotation [`rotate_bc_forward`]
301    /// absorbed into B/C, so the result `cₜ` is what raw, un-rotated C reads
302    /// (`yₜ = C̃ₜᵀh̃ₜ = Cₜᵀcₜ`):
303    ///
304    /// - [`Angle`](RotationSeq::Angle): B/C were rotated by `+θₜ`, so the state
305    ///   gets `R(−θₜ)` (negated angles).
306    /// - [`Quaternion`](RotationSeq::Quaternion): B/C were left-multiplied by
307    ///   `conj(Qₜ)`, so the state gets `Qₜ` **un-conjugated**.
308    ///
309    /// `start` is the offset of this chunk of states within the rotation's
310    /// sequence axis.
311    ///
312    /// # Shapes
313    /// - `states_blhpr`: `[batch, len, nheads, per_head_dim, state_rank]`
314    /// - output: same shape.
315    pub fn derotate_states(&self, states_blhpr: Tensor<5>, start: usize) -> Tensor<5> {
316        let [batch, len, nheads, per_head_dim, _state_rank] = states_blhpr.dims();
317        match self {
318            RotationSeq::Angle {
319                cum_bsha,
320                rope_dim,
321                rotate_pairwise,
322            } => {
323                if *rope_dim == 0 {
324                    return states_blhpr;
325                }
326                let num_angles = cum_bsha.dims()[3];
327                let ang_blhpa = cum_bsha
328                    .clone()
329                    .narrow(1, start, len)
330                    .unsqueeze_dim::<5>(3)
331                    .expand([batch, len, nheads, per_head_dim, num_angles]);
332                apply_rope_partial::<5>(states_blhpr, -ang_blhpa, *rope_dim, *rotate_pairwise)
333            }
334            RotationSeq::Quaternion { cum_bshj4 } => {
335                let blocks = cum_bshj4.dims()[3];
336                let q_blhpj4 = cum_bshj4
337                    .clone()
338                    .narrow(1, start, len)
339                    .unsqueeze_dim::<6>(3)
340                    .expand([batch, len, nheads, per_head_dim, blocks, 4]);
341                rotate_blocks_partial::<5, 6>(states_blhpr, q_blhpj4, blocks * 4)
342            }
343        }
344    }
345}

351/// Hamilton product `a ⊗ b` of two quaternion tensors.
352///
353/// Both inputs have shape `[..., 4]` with the last axis ordered `(w, x, y, z)`;
354/// the product is computed component-wise and broadcasts over the leading dims.
355/// Quaternion multiplication is **non-commutative** (`a ⊗ b ≠ b ⊗ a` in
356/// general) but associative.
357///
358/// Identifying `ℝ⁴` with the quaternions, left-multiplication `v ↦ a ⊗ v` is
359/// exactly the action of the `4×4` rotation matrix [`quat_to_rot4`]`(a)`, so
360/// this is also how a rotation is *applied* to a state/`B`/`C` block (see
361/// [`rotate_state_rank_blocks`]).
362pub fn quat_mul<const D: usize>(a: Tensor<D>, b: Tensor<D>) -> Tensor<D> {
363    let n = D - 1;
364    let aw = a.clone().narrow(n, 0, 1);
365    let ax = a.clone().narrow(n, 1, 1);
366    let ay = a.clone().narrow(n, 2, 1);
367    let az = a.narrow(n, 3, 1);
368    let bw = b.clone().narrow(n, 0, 1);
369    let bx = b.clone().narrow(n, 1, 1);
370    let by = b.clone().narrow(n, 2, 1);
371    let bz = b.narrow(n, 3, 1);
372
373    // Hamilton product (each term is shape [..., 1]).
374    let w = aw.clone() * bw.clone()
375        - ax.clone() * bx.clone()
376        - ay.clone() * by.clone()
377        - az.clone() * bz.clone();
378    let x = aw.clone() * bx.clone() + ax.clone() * bw.clone() + ay.clone() * bz.clone()
379        - az.clone() * by.clone();
380    let y = aw.clone() * by.clone() - ax.clone() * bz.clone()
381        + ay.clone() * bw.clone()
382        + az.clone() * bx.clone();
383    let z = aw * bz + ax * by - ay * bx + az * bw;
384
385    Tensor::cat(vec![w, x, y, z], n)
386}

388/// Quaternion conjugate `q* = (w, −x, −y, −z)` (shape `[..., 4]`).
389///
390/// For a **unit** quaternion `q* = q⁻¹`, and the corresponding rotation matrix
391/// satisfies `Lₚ⋆ = Lₚᵀ = Lₚ⁻¹`.  Hence rotating by the *inverse* cumulative
392/// rotation (`B̄ = Pᵀ B`) is `rotate_state_rank_blocks(B, conj(Q))`.
393pub fn quat_conj<const D: usize>(q: Tensor<D>) -> Tensor<D> {
394    let n = D - 1;
395    let w = q.clone().narrow(n, 0, 1);
396    let xyz = q.narrow(n, 1, 3);
397    Tensor::cat(vec![w, -xyz], n)
398}

400/// Normalise quaternions to unit norm along the last axis (shape `[..., 4]`).
401///
402/// The per-step rotation is materialised from a raw, unconstrained projection
403/// and normalised here so it is a genuine unit quaternion (an element of
404/// `SU(2)`), the analogue of `tanh(θ)·π` bounding the RoPE angle.  A tiny floor
405/// guards the zero-quaternion.
406pub fn quat_normalize<const D: usize>(q: Tensor<D>) -> Tensor<D> {
407    let n = D - 1;
408    // Clamp the sum-of-squares *before* `sqrt`: at a zero quaternion the forward
409    // `sqrt(0)=0` is fine, but `sqrt`'s backward is `1/(2·0)=∞`, and `∞·(2·0)=NaN`.
410    // Clamping pre-`sqrt` puts the degenerate point in `clamp_min`'s flat region,
411    // so its gradient is a finite 0 (and a genuine unit quaternion, sumsq=1, is
412    // untouched). The floor also keeps `norm` away from 0 for the division.
413    //
414    // The floor is the dtype-aware `div_eps` applied to the *sum-of-squares*
415    // (giving a norm floor of `√div_eps`). It must engage as a representable
416    // normal in the working dtype: in f16 a `div_eps²`-sized floor (~5e-7) would
417    // underflow below the min-normal (~6.1e-5) and silently no-op, so we floor
418    // the squared quantity at `div_eps` itself, which sits above each format's
419    // denormal floor by construction.
420    let eps = crate::utils::div_eps(q.dtype());
421    let norm = (q.clone() * q.clone()).sum_dim(n).clamp_min(eps).sqrt();
422    q / norm
423}

425/// Materialise a unit quaternion from a **scaled rotation vector** `g ∈ ℝ³`
426/// (axis · angle) via the exponential map — the data-dependent "materialise
427/// `Rₜ`" step, analogous to RoPE's `Δₜ · π · tanh(θₜ)` angle.
428///
429/// With `‖g‖ = angle` and `ĝ = g / angle` the axis, returns the unit quaternion
430/// `q = (cos(angle/2), sin(angle/2)·ĝ)`.  A vanishing `g` maps to the identity
431/// `(1, 0, 0, 0)`, so scaling `g` by a small `Δₜ` (the discretisation step)
432/// yields a near-identity rotation — exactly the regime where a small step
433/// barely rotates the state.  The `sin(angle/2)/angle` factor is the numerically
434/// stable form of the (otherwise `0/0`) per-component scale near `g = 0`.
435///
436/// # Shapes
437/// - `g` : `[..., 3]`
438/// - out : `[..., 4]` (ordered `(w, x, y, z)`), unit norm.
439pub fn quat_from_scaled_axis<const D: usize>(g: Tensor<D>) -> Tensor<D> {
440    let n = D - 1;
441    // Clamp the sum-of-squares *before* `sqrt`: at `g = 0` the forward `sqrt(0)=0`
442    // is finite, but `sqrt`'s backward is `1/(2·0)=∞` and `∞·(2·0)=NaN`. Clamping
443    // pre-`sqrt` puts `g = 0` in `clamp_min`'s flat (zero-gradient) region, so the
444    // near-identity rotation gets a finite 0 gradient instead of a NaN. (This is
445    // the FiLM-triggered decoder-backward NaN: a per-position rotation generator
446    // hitting exactly zero.) The floor is the dtype-aware `div_eps` on the squared
447    // quantity — see [`quat_normalize`] for why it floors `sumsq`, not the norm.
448    let eps = crate::utils::div_eps(g.dtype());
449    let angle = (g.clone() * g.clone()).sum_dim(n).clamp_min(eps).sqrt(); // [..., 1]
450    let half = angle.clone() * 0.5;
451    let w = half.clone().cos(); // [..., 1]
452    // sin(angle/2) / angle  → 1/2 as angle → 0 (no rotation); `angle ≥ √div_eps`
453    // after the pre-`sqrt` clamp above, so the division is already guarded.
454    let scale = half.sin() / angle; // [..., 1]
455    let v = g * scale; // [..., 3]
456    quat_normalize(Tensor::cat(vec![w, v], n))
457}

459/// Materialise the `4×4` orthogonal matrix of left-multiplication by `q`.
460///
461/// Maps `q` of shape `[..., 4]` to `[..., 4, 4]` such that, for `v` of shape
462/// `[..., 4]`, `Lq · v == quat_mul(q, v)`.  Concretely (rows = output coords,
463/// cols = input coords, all in `(w, x, y, z)` order):
464///
465/// ```text
466///   ⎡ w  -x  -y  -z ⎤
467///   ⎢ x   w  -z   y ⎥
468///   ⎢ y   z   w  -x ⎥
469///   ⎣ z  -y   x   w ⎦
470/// ```
471///
472/// For a unit `q` this is orthogonal with `det = 1` (a left-isoclinic rotation).
473/// Provided mainly for the generic / verification path; the cheap way to apply a
474/// rotation is [`rotate_state_rank_blocks`] (a quaternion product, no `4×4`
475/// materialisation).  `DR` must equal `D + 1`.
476pub fn quat_to_rot4<const D: usize, const DR: usize>(q: Tensor<D>) -> Tensor<DR> {
477    assert_eq!(D + 1, DR, "quat_to_rot4 maps rank D to rank D+1");
478    let n = D - 1;
479    let w = q.clone().narrow(n, 0, 1);
480    let x = q.clone().narrow(n, 1, 1);
481    let y = q.clone().narrow(n, 2, 1);
482    let z = q.narrow(n, 3, 1);
483
484    // Each row is a [..., 4] tensor (the four column entries).
485    let row0 = Tensor::cat(vec![w.clone(), -x.clone(), -y.clone(), -z.clone()], n);
486    let row1 = Tensor::cat(vec![x.clone(), w.clone(), -z.clone(), y.clone()], n);
487    let row2 = Tensor::cat(vec![y.clone(), z.clone(), w.clone(), -x.clone()], n);
488    let row3 = Tensor::cat(vec![z, -y, x, w], n);
489
490    // Stack the rows along a freshly inserted row axis → [..., 4, 4].
491    Tensor::cat(
492        vec![
493            row0.unsqueeze_dim::<DR>(n),
494            row1.unsqueeze_dim::<DR>(n),
495            row2.unsqueeze_dim::<DR>(n),
496            row3.unsqueeze_dim::<DR>(n),
497        ],
498        n,
499    )
500}

502// ---------------------------------------------------------------------------
503// Rotation application on the state_rank axis
504// ---------------------------------------------------------------------------
505
506/// Apply a per-block quaternion rotation to the `state_rank` axis of `v`.
507///
508/// `v` has shape `[..., state_rank]` with `state_rank = 4·J`, viewed as `J`
509/// independent quaternion blocks; `q` has shape `[..., J, 4]` (one unit
510/// quaternion per block, same leading dims as `v`).  Returns `q ⊗ v` per block,
511/// i.e. the rotation `L_q` applied within each `4`-block, reshaped back to
512/// `[..., state_rank]`.
513///
514/// This is the generalisation of RoPE's per-pair `2×2` rotation to per-block
515/// `4×4`.  To rotate by the *inverse* cumulative rotation when absorbing into
516/// `B`/`C` (`B̄ = Pᵀ B`), pass `q = conj(Qcum)`:
517/// `rotate_state_rank_blocks(b, conj(qcum))`.
518///
519/// `DB` must equal `D + 1` (the block-split inserts the `J` axis).
520pub fn rotate_state_rank_blocks<const D: usize, const DB: usize>(
521    v: Tensor<D>,
522    q: Tensor<DB>,
523) -> Tensor<D> {
524    assert_eq!(
525        D + 1,
526        DB,
527        "rotate_state_rank_blocks splits one axis into (J, 4)"
528    );
529    let dims = v.dims();
530    let state_rank = dims[D - 1];
531    assert_eq!(
532        state_rank % 4,
533        0,
534        "state_rank must be a multiple of 4 (quaternion blocks)"
535    );
536    let blocks = state_rank / 4;
537
538    // Build the block-split shape [..., J, 4] (rank DB) and the flat shape
539    // [..., state_rank] (rank D) for the round trip.
540    let mut split_shape = [0usize; DB];
541    split_shape[..D - 1].copy_from_slice(&dims[..D - 1]);
542    split_shape[DB - 2] = blocks;
543    split_shape[DB - 1] = 4;
544
545    let v_blocks = v.reshape(split_shape); // [..., J, 4]
546    let rotated = quat_mul(q, v_blocks); // L_q applied per block
547    rotated.reshape(dims) // [..., state_rank]
548}

550// ---------------------------------------------------------------------------
551// Cumulative rotation scan (the associative, non-abelian replacement for cumsum)
552// ---------------------------------------------------------------------------
553
554/// Cumulative (ordered, left-accumulating) quaternion product along the
555/// sequence axis, with a cross-chunk carry.
556///
557/// This is the non-abelian analogue of the cumulative *sum of angles* used by
558/// RoPE: where complex rotations compose by adding angles (a `cumsum`),
559/// quaternions compose by multiplication, which is order-dependent, so a real
560/// scan is required.
561///
562/// # Shapes
563/// - `q_bshj4` : `[batch, sequence, nheads, J, 4]` per-step **unit** quaternions
564///   (block count `J = state_rank / 4`).
565/// - `init`    : optional carry `[batch, nheads, J, 4]` — the cumulative
566///   rotation at the end of the previous chunk (identity `(1,0,0,0)` for a fresh
567///   start).
568/// - returns `(cum, final_carry)` where `cum` is `[batch, sequence, nheads, J, 4]`
569///   with `cum[:, t] = qₜ ⊗ qₜ₋₁ ⊗ ⋯ ⊗ q₀ ⊗ init` (newest on the left, matching
570///   `Pₜ = Rₜ ⋯ R₁`), and `final_carry` `[batch, nheads, J, 4]` is `cum[:, −1]`
571///   to thread into the next chunk.
572///
573/// Running this over a split sequence while threading `final_carry` is exactly
574/// equal to running it over the whole sequence (asserted in the tests) — the
575/// chunked-prefill / streaming guarantee, here for the rotation accumulator.
576///
577/// Implemented as a **Hillis–Steele** inclusive associative scan: the quaternion
578/// product is associative (just not commutative), so a log-depth scan applies as
579/// long as operand order is preserved (newest-on-left). Each doubling step is a
580/// single full-tensor [`quat_mul`] plus a sequence shift, so the *sequential
581/// dependency depth* is `O(log sequence)` rather than the `O(sequence)` of a
582/// token-by-token loop — the same values, but a handful of large batched kernels
583/// instead of thousands of serialized tiny ones (and a correspondingly shallow
584/// autodiff graph). The sequential reference it replaces is kept as a test oracle
585/// (`quat_cumprod_sequential` in the tests module) and asserted equal on values
586/// **and** gradients.
587pub fn quat_cumprod(q_bshj4: Tensor<5>, init: Option<Tensor<4>>) -> (Tensor<5>, Tensor<4>) {
588    let [batch, sequence, nheads, blocks, _four] = q_bshj4.dims();
589    let device = q_bshj4.device();
590
591    // Pure prefix product Pₜ = qₜ ⊗ qₜ₋₁ ⊗ ⋯ ⊗ q₀ by Hillis–Steele doubling.
592    // Invariant after each step with offset `d`: a[t] holds the product of the
593    // window [t .. max(t-2d+1, 0)] (newest on the left). After ⌈log₂ sequence⌉
594    // doublings the window covers [t .. 0], i.e. a[t] = Pₜ.
595    let mut a = q_bshj4;
596    let mut offset = 1usize;
597    while offset < sequence {
598        // shifted[t] = a[t-offset] for t ≥ offset, else the identity quaternion
599        // (1,0,0,0) — so the first `offset` prefixes pass through unchanged
600        // (a ⊗ identity = a).
601        let ident = {
602            let w = Tensor::ones([batch, offset, nheads, blocks, 1], &device);
603            let xyz = Tensor::zeros([batch, offset, nheads, blocks, 3], &device);
604            Tensor::cat(vec![w, xyz], 4)
605        };
606        let shifted = Tensor::cat(vec![ident, a.clone()], 1).narrow(1, 0, sequence);
607        // Recent block (a) on the left, older block (shifted) on the right.
608        a = quat_mul(a, shifted);
609        offset *= 2;
610    }
611
612    // Fold the cross-chunk carry once: cumₜ = Pₜ ⊗ init. `init` (the previous
613    // chunk's final cumulative rotation) is the oldest factor, hence on the
614    // right; a missing carry is the identity and needs no multiply.
615    let cum = match init {
616        Some(init_bhj4) => {
617            assert_eq!([batch, nheads, blocks, 4], init_bhj4.dims());
618            quat_mul(a, init_bhj4.unsqueeze_dim::<5>(1)) // [batch, 1, nheads, J, 4] broadcasts over seq
619        }
620        None => a,
621    };
622
623    let final_carry = cum.clone().narrow(1, sequence - 1, 1).squeeze_dim::<4>(1); // [batch, nheads, J, 4]
624    (cum, final_carry)
625}

627// ---------------------------------------------------------------------------
628// Partial block rotation (rope_fraction support)
629// ---------------------------------------------------------------------------
630
631/// Apply a per-block quaternion rotation to the first `rope_width` entries of
632/// the `state_rank` axis (a multiple of 4); the remainder passes through. The
633/// quaternion analogue of [`apply_rope_partial`].
634///
635/// `q` has one quaternion per rotated block (`rope_width / 4` of them). `DB`
636/// must equal `D + 1`.
637pub fn rotate_blocks_partial<const D: usize, const DB: usize>(
638    v: Tensor<D>,
639    q: Tensor<DB>,
640    rope_width: usize,
641) -> Tensor<D> {
642    let r = v.dims()[D - 1];
643    if rope_width == r {
644        rotate_state_rank_blocks::<D, DB>(v, q)
645    } else {
646        let head = v.clone().narrow(D - 1, 0, rope_width);
647        let tail = v.narrow(D - 1, rope_width, r - rope_width);
648        let head_rot = rotate_state_rank_blocks::<D, DB>(head, q);
649        Tensor::cat(vec![head_rot, tail], D - 1)
650    }
651}

653// ---------------------------------------------------------------------------
654// Forward / step rotation of B and C (shared by both SSD pathways)
655// ---------------------------------------------------------------------------
656
657/// Rotate `B`/`C` for a **full sequence** by the data-dependent positional
658/// rotation, returning the rotated projections, the new cumulative
659/// [`RotationState`] to store in the cache, and the per-token cumulative
660/// rotation ([`RotationSeq`] — already materialised here; consumed by the
661/// physical-frame state moments, dropped otherwise).
662///
663/// Branches on [`RotationKind`]:
664/// - [`Complex2D`](RotationKind::Complex2D): the abelian RoPE — cumulative
665///   angle `cumsum` continued from `prev`, then [`apply_rope_partial`]. Exactly
666///   the original Mamba-3 behaviour.
667/// - [`Quaternion4D`](RotationKind::Quaternion4D): per-step unit quaternion
668///   [`quat_from_scaled_axis`] (the in-projection generators scaled per-head by
669///   `Δ`), composed by [`quat_cumprod`] continuing the cached quaternion, then
670///   applied to `B`/`C` as `rotate(·, conj(Qₜ))` over the first `4·blocks`
671///   state-rank entries.
672///
673/// # Shapes
674/// - `rot_bsa` : `[batch, sequence, num_rotation_channels]` — the in-projection
675///   rotation channels (angles for Complex2D, `3·blocks` quaternion generators
676///   for Quaternion4D).
677/// - `dt_bsh`  : `[batch, sequence, nheads]` (`Δ`).
678/// - `b_bsmhr` / `c_bsmhr` : `[batch, sequence, mimo_rank, nheads, state_rank]`.
679pub fn rotate_bc_forward(
680    rot_bsa: Tensor<3>,
681    dt_bsh: Tensor<3>,
682    prev: RotationState,
683    b_bsmhr: Tensor<5>,
684    c_bsmhr: Tensor<5>,
685    kind: RotationKind,
686    rope_dim: usize,
687) -> (Tensor<5>, Tensor<5>, RotationState, RotationSeq) {
688    let [batch, sequence, mimo_rank, nheads, _state_rank] = b_bsmhr.dims();
689    match kind {
690        RotationKind::Complex2D => {
691            let prev_angle_bha = prev.angle();
692            let num_rope_angles = prev_angle_bha.dims()[2];
693            let theta_scaled_bsa = rot_bsa.tanh() * std::f32::consts::PI;
694            let raw_angles_bsha =
695                dt_bsh.unsqueeze_dim::<4>(3) * theta_scaled_bsa.unsqueeze_dim::<4>(2);
696            let cum_angles_bsha = prev_angle_bha.unsqueeze_dim::<4>(1) + raw_angles_bsha.cumsum(1);
697            let cum_angles_bsmha = cum_angles_bsha.clone().unsqueeze_dim::<5>(2).expand([
698                batch,
699                sequence,
700                mimo_rank,
701                nheads,
702                num_rope_angles,
703            ]);
704            let rotate_pairwise = mimo_rank == 1;
705            let b = apply_rope_partial::<5>(
706                b_bsmhr,
707                cum_angles_bsmha.clone(),
708                rope_dim,
709                rotate_pairwise,
710            );
711            let c = apply_rope_partial::<5>(c_bsmhr, cum_angles_bsmha, rope_dim, rotate_pairwise);
712            let last = wrap_angle(
713                cum_angles_bsha
714                    .clone()
715                    .narrow(1, sequence - 1, 1)
716                    .squeeze_dim::<3>(1),
717            );
718            let seq = RotationSeq::Angle {
719                cum_bsha: cum_angles_bsha,
720                rope_dim,
721                rotate_pairwise,
722            };
723            (b, c, RotationState::Angle(last), seq)
724        }
725        RotationKind::Quaternion4D => {
726            let prev_q_bhj4 = prev.quaternion();
727            let blocks = prev_q_bhj4.dims()[2];
728            let rope_width = blocks * 4;
729            // Generators [b,s,blocks,3] (shared across heads), scaled per-head by Δ.
730            //
731            // Bound the raw generator with `tanh·π` before scaling by Δ — the
732            // direct analogue of the Complex2D path (`rot.tanh()·π`). Without it
733            // the generator is unbounded, so a large in-projection activation makes
734            // `g = rot·Δ` overflow f32 to `inf`, and `quat_from_scaled_axis`'s
735            // `cos(∞)` then yields a forward NaN. The bound caps each per-step
736            // rotation to `±π·Δ` (cos/sin still give the periodicity within range);
737            // healthy `O(1)` generators stay in tanh's near-linear region.
738            let g_bshj3 = (rot_bsa.tanh() * core::f32::consts::PI)
739                .reshape([batch, sequence, blocks, 3])
740                .unsqueeze_dim::<5>(2)
741                * dt_bsh.unsqueeze_dim::<4>(3).unsqueeze_dim::<5>(4);
742            let q_step_bshj4 = quat_from_scaled_axis::<5>(g_bshj3);
743            // Memory-efficient scan: a custom recompute backward (saves only the
744            // leaf inputs) instead of retaining the scan's intermediates. Equal
745            // to [`quat_cumprod`] on values and gradients (asserted in tests).
746            let (cum_bshj4, final_bhj4) = crate::mamba3::quat_scan::quat_cumprod_recalculated(
747                q_step_bshj4,
748                Some(prev_q_bhj4),
749            );
750            // B̄ = rotate by the inverse cumulative rotation (conjugate), per block,
751            // broadcast over the mimo_rank axis.
752            let conj_bsmhj4 = quat_conj(cum_bshj4.clone())
753                .unsqueeze_dim::<6>(2)
754                .expand([batch, sequence, mimo_rank, nheads, blocks, 4]);
755            let b = rotate_blocks_partial::<5, 6>(b_bsmhr, conj_bsmhj4.clone(), rope_width);
756            let c = rotate_blocks_partial::<5, 6>(c_bsmhr, conj_bsmhj4, rope_width);
757            let seq = RotationSeq::Quaternion { cum_bshj4 };
758            (
759                b,
760                c,
761                RotationState::Quaternion(quat_normalize(final_bhj4)),
762                seq,
763            )
764        }
765    }
766}

768/// Single-token counterpart of [`rotate_bc_forward`] for the recurrent `step`.
769///
770/// # Shapes
771/// - `rot_ba`  : `[batch, num_rotation_channels]`.
772/// - `dt_bh`   : `[batch, nheads]`.
773/// - `b_bmhr` / `c_bmhr` : `[batch, mimo_rank, nheads, state_rank]`.
774pub fn rotate_bc_step(
775    rot_ba: Tensor<2>,
776    dt_bh: Tensor<2>,
777    prev: RotationState,
778    b_bmhr: Tensor<4>,
779    c_bmhr: Tensor<4>,
780    kind: RotationKind,
781    rope_dim: usize,
782) -> (Tensor<4>, Tensor<4>, RotationState) {
783    let [batch, mimo_rank, nheads, _state_rank] = b_bmhr.dims();
784    match kind {
785        RotationKind::Complex2D => {
786            let prev_angle_bha = prev.angle();
787            let num_rope_angles = prev_angle_bha.dims()[2];
788            let theta_scaled_ba = rot_ba.tanh() * std::f32::consts::PI;
789            let raw_angle_bha = dt_bh.unsqueeze_dim::<3>(2) * theta_scaled_ba.unsqueeze_dim::<3>(1);
790            let new_cum_angle_bha = wrap_angle(prev_angle_bha + raw_angle_bha);
791            let new_cum_angle_bmha = new_cum_angle_bha.clone().unsqueeze_dim::<4>(1).expand([
792                batch,
793                mimo_rank,
794                nheads,
795                num_rope_angles,
796            ]);
797            let rotate_pairwise = mimo_rank == 1;
798            let b = apply_rope_partial::<4>(
799                b_bmhr,
800                new_cum_angle_bmha.clone(),
801                rope_dim,
802                rotate_pairwise,
803            );
804            let c = apply_rope_partial::<4>(c_bmhr, new_cum_angle_bmha, rope_dim, rotate_pairwise);
805            (b, c, RotationState::Angle(new_cum_angle_bha))
806        }
807        RotationKind::Quaternion4D => {
808            let prev_q_bhj4 = prev.quaternion();
809            let blocks = prev_q_bhj4.dims()[2];
810            let rope_width = blocks * 4;
811            // `tanh·π` bound, matching `rotate_bc_forward` (see the note there).
812            let g_bhj3 = (rot_ba.tanh() * core::f32::consts::PI)
813                .reshape([batch, blocks, 3])
814                .unsqueeze_dim::<4>(1)
815                * dt_bh.unsqueeze_dim::<3>(2).unsqueeze_dim::<4>(3);
816            let q_step_bhj4 = quat_from_scaled_axis::<4>(g_bhj3);
817            // Single step: Qₜ = qₜ ⊗ Qₜ₋₁.
818            let new_q_bhj4 = quat_normalize(quat_mul(q_step_bhj4, prev_q_bhj4));
819            let conj_bmhj4 = quat_conj(new_q_bhj4.clone())
820                .unsqueeze_dim::<5>(1)
821                .expand([batch, mimo_rank, nheads, blocks, 4]);
822            let b = rotate_blocks_partial::<4, 5>(b_bmhr, conj_bmhj4.clone(), rope_width);
823            let c = rotate_blocks_partial::<4, 5>(c_bmhr, conj_bmhj4, rope_width);
824            (b, c, RotationState::Quaternion(new_q_bhj4))
825        }
826    }
827}
