1//! # Mamba-3 SSM Block — Exponential-Trapezoidal SSD with Data-Dependent RoPE
2//!
3//! This module implements the core **Mamba-3 layer** from the paper
4//! *"Mamba-3: Improved Sequence Modeling using State Space Principles"*.
5//!
6//! Mamba-3 adds three independent extensions to the Mamba-2 SSD recurrence:
7//! (1) trapezoidal discretisation, (2) a **complex-valued state transition**,
8//! implemented as data-dependent rotary embeddings on B and C (the "RoPE
9//! trick"), and (3) MIMO (multiple-input multiple-output) projection.
10//! Each is shown in isolation below, then combined.
11//!
12//! ## 1. Trapezoidal recurrence (SISO, no RoPE, no MIMO — Proposition 1)
13//!
14//! ```text
15//!   hₜ = αₜ hₜ₋₁ + βₜ Bₜ₋₁ xₜ₋₁ᵀ + γₜ Bₜ xₜᵀ   (state update)
16//!   yₜ = Cₜᵀ hₜ + D xₜ                          (output)
17//! ```
18//!
19//! where the trapezoidal coefficients are
20//!
21//! ```text
22//!   αₜ = exp(Δₜ Aₜ)                — decay (Aₜ < 0, data-dependent)
23//!   βₜ = (1 − λₜ) Δₜ αₜ            — left-endpoint weight (Bₜ₋₁ xₜ₋₁ contribution)
24//!   γₜ = λₜ Δₜ                      — right-endpoint weight (Bₜ xₜ contribution)
25//! ```
26//!
27//! with `λₜ = σ(λ̂ₜ) ∈ (0, 1)` controlling the left/right split of the trapezoid.
28//! Setting `λ ≡ 1` collapses this to the Mamba-2 (Euler / right-endpoint) form.
29//!
30//! *Which* earlier sample the `βₜ` tap reads is [`Mamba3Config::trapezoid`]; at
31//! `micro_steps = 1` (below) `t−1` is the only answer. At `u > 1` the default
32//! [`Trapezoid::HorizontalCarryOver`] keeps reading the immediately preceding
33//! recurrence step, and [`Trapezoid::Vertical`] reads the previous **token**'s
34//! same micro-step instead — one lag, everywhere the tap appears. Two members
35//! read **both**, splitting `(1 − λₜ)Δₜ` between them by a second projected
36//! scalar `μₜ = σ(μ̂ₜ)`; one gates its lag-1 tap to within a token. The tap and
37//! its mass are one choice: a closed tap hands its share back (to the other tap,
38//! or to `γ`), so the step's mass is `Δₜ` under every member. See
39//! [`Trapezoid`]'s header.
40//!
41//! ## 2. Complex transition, a.k.a. "data-dependent RoPE" (no trapezoid, no MIMO
42//! — paper section *Complex-Valued SSMs*)
43//!
44//! Despite the name this is **not a positional encoding**: it is the *imaginary
45//! part of the state transition*. Mamba-3's `A` is complex (`A + iϑ`), and under
46//! discretisation a complex SSM of state `N/2` is exactly a real SSM of state `N`
47//! whose transition is the scalar decay `α` times a block-diagonal of `2×2`
48//! rotations (paper Prop. *Complex-to-Real SSM Equivalence*):
49//!
50//! ```text
51//!   ρₜ = R(Δₜ · ϱ · π · tanh(ϑₜ)) ∈ SO(2)^{N/2}  — per-step rotation (data-dependent)
52//!   hₜ = αₜ ρₜ hₜ₋₁ + Δₜ Bₜ xₜᵀ                   — rotational state update
53//! ```
54//!
55//! `ϱ` is [`Mamba3Config::rotation_range`], the per-step bound in half-turns per
56//! unit `Δ`: `2` here (a whole turn of the group per unit `Δ`), `1` in the
57//! reference. It is a gradient budget, not a reach limit — see its own docs.
58//!
59//! The **exponential** discretisation is load-bearing here, not merely more
60//! accurate than forward Euler: `|exp(iΔϑ)| = 1` exactly, so the transition is
61//! orthogonal and a tracked rotation neither decays nor grows, where Euler's
62//! `|1 + iΔϑ| > 1` spirals outward (`info/rotation-as-optimization.md` §9.5).
63//!
64//! `αₜ` is a scalar (so it commutes with `ρₜ`) and each `ρₜ` is orthogonal, so
65//! the *cumulative* rotation telescopes out of the recurrence and can be absorbed
66//! into B/C instead — the **"RoPE trick"** (paper Prop. *Complex SSM,
67//! Data-Dependent RoPE Equivalence*). That is the form implemented here: the
68//! rotation never touches the state (the cached `h` is the rotated-frame one) and
69//! the SSD core stays the plain scalar-decay kernel.
70//!
71//! ```text
72//!   θₜ = θₜ₋₁ + Δₜ · ϱ · π · tanh(ϑₜ)    — cumulative angles (per-pair)
73//!   Rₜ = R(θₜ) = ρₜ ⋯ ρ₁ ∈ SO(2)^{N/2}   — block-diagonal cumulative rotation
74//!   B̃ₜ = Rₜ Bₜ,   C̃ₜ = Rₜ Cₜ              — rotated state-space projections
75//! ```
76//!
77//! The standard recurrence then runs with `B̃ₜ`/`C̃ₜ` in place of `Bₜ`/`Cₜ`:
78//!
79//! ```text
80//!   hₜ = Āₜ hₜ₋₁ + B̄̃ₜ xₜᵀ                (scalar-decay state update)
81//!   yₜ = C̃ₜᵀ hₜ + D xₜ                   (output)
82//! ```
83//!
84//! Orthogonality makes the readout-vs-input similarity depend only on the
85//! rotation *accumulated between* the two steps:
86//!
87//! ```text
88//!   C̃ᵢᵀ B̃ⱼ = (Rᵢ Cᵢ)ᵀ (Rⱼ Bⱼ) = Cᵢᵀ R(θⱼ − θᵢ) Bⱼ
89//! ```
90//!
91//! `θⱼ − θᵢ` is not a position: it is `Σ Δ·ϱ·π·tanh(ϑ)` over the intervening
92//! steps — how far the transition itself rotated, driven by the inputs. It would
93//! reduce to vanilla RoPE's relative position only in the degenerate case of an
94//! input-independent, constant per-step angle (`θⱼ − θᵢ = (j−i)·θ`). Data
95//! dependence is the whole point: it gives the layer rotational state dynamics,
96//! hence state-tracking (parity, mod-k) that a real, non-negative-eigenvalue SSM
97//! provably cannot express. See [`crate::mamba3::rotation`], whose `Quaternion4D`
98//! carries the same argument to a non-abelian rotation group.
99//!
100//! ## 3. MIMO Extension (no trapezoid coefficients, no RoPE — `mimo_rank = M > 1`)
101//!
102//! With MIMO, B/C carry M parallel rank channels and the state update is a sum
103//! of M outer-product contributions; the readout produces M outputs which are
104//! gated and combined back:
105//!
106//! ```text
107//!   hₜ = Āₜ hₜ₋₁ + Σₘ B̄ₜ[m] ⊗ (xₜ ⊙ mimo_x[m])                  (state update)
108//!   yₜ[m] = Cₜ[m]ᵀ hₜ + D · (xₜ ⊙ mimo_x[m])                    (per-rank output)
109//!   outₜ  = Σₘ mimo_o[m] ⊙ silu(zₜ ⊙ mimo_z[m]) ⊙ yₜ[m]         (rank merge)
110//! ```
111//!
112//! The hidden state hₜ is shared across ranks; each rank contributes to it
113//! independently but reads the full shared state when producing its output.
114//!
115//! ## 4. Combined formulation (everything together)
116//!
117//! Putting trapezoid + RoPE + MIMO into a single expression — `B̃ₜ[m] = Rₜ Bₜ[m]`
118//! and `C̃ₜ[m] = Rₜ Cₜ[m]` denote the RoPE-rotated MIMO projections, and the `β`
119//! tap is written at the default member's lag 1 (§1: it reads `t−l` for that
120//! member's own `l`, and a two-tap member adds a second such term):
121//!
122//! ```text
123//!   hₜ = αₜ hₜ₋₁
124//!      + βₜ Σₘ B̃ₜ₋₁[m] ⊗ (xₜ₋₁ ⊙ mimo_x[m])
125//!      + γₜ Σₘ B̃ₜ[m]   ⊗ (xₜ   ⊙ mimo_x[m])
126//!
127//!   yₜ[m] = C̃ₜ[m]ᵀ hₜ + D · (xₜ ⊙ mimo_x[m])
128//!   outₜ  = Σₘ mimo_o[m] ⊙ silu(zₜ ⊙ mimo_z[m]) ⊙ yₜ[m]
129//! ```
130//!
131//! ## 5. MambaProduct (`micro_steps = u > 1`)
132//!
133//! A fourth, independent dial (DeltaProduct's dial, not its mechanism — see
134//! [`crate::mamba3::product`] and `info/rotation-as-optimization.md`): `u`
135//! recurrence micro-steps per token, each a full step of the above with its own
136//! projected `x`, `B`, `Δ`, `A`, `λ` and rotation. One *token*'s transition is
137//! then the **product**
138//!
139//! ```text
140//!   Mₜ = (∏ⱼ αₜ,ⱼ) · Rₜ,ᵤ ⋯ Rₜ,₁
141//! ```
142//!
143//! and its write a sum of `u` outer products staggered along it; the read `C`,
144//! the gate `z` and the `D` skip stay per token. It is evaluated by folding the
145//! micro-steps into the sequence axis, so nothing below this line changes. See
146//! [`crate::mamba3::product`] for what `u` buys per
147//! [`RotationKind`] — the answer is very
148//! different for the abelian and non-abelian ones.
149//!
150//! Implementation note: the trapezoidal recurrence (in the double-ssd pathway)
151//! is computed by splitting it into a γ-SSD (the current sample) and one β-SSD
152//! per tap, at that tap's own lag; see
153//! [`crate::mamba3::double_ssd::ssd::ssd_path`]. The single-ssd pathway does the
154//! same work in one call. The rotation is applied to B and C before the SSD
155//! calls, through the one entry point
156//! [`rotate_bc_forward`](crate::mamba3::rotation::rotate_bc_forward) (which is
157//! [`apply_rope`](crate::mamba3::rotation::rope::apply_rope) for the abelian
158//! kind and a quaternion scan for the others), and MIMO expansion happens by
159//! augmenting the V tensor with the per-rank `mimo_x` projection.
160//!
161//! See also: [`crate::mamba3::double_ssd::double_ssd`] and [`crate::mamba3::single_ssd::single_ssd`].
162//!
163//! ## Notation / Dimension Keys
164//!
165//! Throughout all Mamba-3 files, tensor names carry a suffix representing their shape.
166//! The letters used differ from the reference paper and the python implementation.
167//! The "Paper" column gives the symbol from the Mamba-3 paper; the "Python" column
168//! gives the field/variable name in the reference implementation
169//! (`../py/state-spaces/mamba/mamba_ssm/modules/mamba3.py`).
170//!
171//! | Letter | Dimension | Paper | Python | Typical value |
172//! |--------|-----------|-------|--------|---------------|
173//! | `b`    | `batch` | — | `batch` | varies |
174//! | `s`    | `sequence` length, **folded** = `tokens · u` | `T` | `seqlen` | varies |
175//! | `t`    | `tokens` = `s`/`u` — the [read axis](crate::mamba3::product) | `T` | `seqlen` | varies |
176//! | `u`    | `micro_steps` (MambaProduct) | — | — | 1 (stock) |
177//! | `d`    | `d_model` | `D` | `d_model` | 768, 1024 |
178//! | `i`    | `d_inner` = `expand`·`d_model` | `E·D` | `d_inner` | 2·`d_model` |
179//! | `h`    | `nheads` | `H` | `nheads` | `d_inner` / `per_head_dim` |
180//! | `p`    | `per_head_dim` | `P` | `headdim` | 64, 128 |
181//! | `r`    | `state_rank` | `N` | `d_state` | 64, 256 |
182//! | `m`    | `mimo_rank` | `M` | `mimo_rank` | 1, .., 8 |
183//! | `n`    | `nchunks` = `sequence`/`chunk_len` | — | `nchunks` | varies |
184//! | `g`    | `ngroups` | `G` | `num_bc_heads` | 1, .., `nheads` |
185//! | `l`    | `chunk_len` | `Q` | `chunk_size` | 64, .., 256 |
186//! | `a`    | `num_rope_angles` = `state_rank` / 2 (or `rope_dim` / 2) | — | `num_rope_angles` | varies |
187//!
188//! Uppercase letters represent a relation (e.g. offset, multiple, concat, stacking)
189//! of the lowercase letters. e.g. `X` may represent `x+1`, `x-1`, `x*2`, etc.
190//! `XY` may also represent `x+y`, `x*y`, etc.

208/// The Mamba-3 SSM block.
209///
210/// Implements the full Mamba-3 layer with exponential-trapezoidal discretization
211/// and data-dependent RoPE.  Supports SISO (mimo_rank=1) and MIMO (mimo_rank>1).
212/// Supports two execution modes:
213///
214/// - [`Self::forward`] — chunkwise double-SSD algorithm for training / prefill
215/// - [`Self::step`]    — recurrent form for token-by-token decoding
216#[derive(Module, Debug)]
217pub struct Mamba3 {
218    /// Input projection; width [`Mamba3Config::d_in_proj`].
219    ///
220    /// Output splits, with `u` = [`Self::micro_steps`]:
221    /// `[z | x·u | B_raw·u | C_raw | dd_dt·u | dd_A·u | lambda_raw·u | rotation·u]`
222    ///
223    /// The last two segments are optional and trail for that reason:
224    /// [`Trapezoid::None`] projects no `lambda_raw`,
225    /// [`RotationKind::Real1D`] no `rotation`.
226    ///
227    /// Every **per-micro-step** stream is projected `u` times over and folded
228    /// into the sequence by [`crate::mamba3::product`]; the gate `z` and the
229    /// read `C` are per token. At the default `u = 1` this is the stock
230    /// `d_model → 2·d_inner + 2·ngroups·state_rank·mimo_rank + 3·nheads
231    /// + num_rotation_channels`.
232    ///
233    /// Under [`Mamba3Untied::InProjTail`] it stops at `C_raw`, the rest living in
234    /// [`Self::in_proj_tail`]; [`Self::project_in`] reads the two as one.
235    pub in_proj: Linear,
236
237    /// `in_proj`'s trailing per-micro-step segments
238    /// `[dd_dt·u | dd_A·u | lambda_raw·u | mu_raw·u | rotation·u]`, split off when
239    /// [`Mamba3Untied::InProjTail`] unties them: one copy per application, along
240    /// the output axis. `None` ⇒ `in_proj` carries them.
241    pub in_proj_tail: Option<Linear>,
242
243    /// Per-head bias for the discretisation step size Δ.
244    /// Shape: `[nheads]`
245    pub dt_bias_h: Param<Tensor<1>>,
246
247    /// Hard clamp applied to Δ after softplus.
248    pub dt_limit: (f64, f64),
249
250    /// Minimum absolute value of A: `A ∈ (−∞, −a_floor]`.
251    pub a_floor: f64,
252
253    /// Per-head skip (D) coefficient.
254    /// Shape: `[nheads]`; initialised to ones.
255    pub d_h: Param<Tensor<1>>,
256
257    /// RMSNorm applied to the B projection (QK-Norm, no gating).
258    /// Normalises over the `state_rank` dimension.
259    pub b_norm: RmsNorm,
260
261    /// RMSNorm applied to the C projection (QK-Norm, no gating).
262    /// Normalises over the `state_rank` dimension.
263    pub c_norm: RmsNorm,
264
265    /// Learnable per-head, per-rank bias for B, added after QK-norm.
266    /// Shape: `[nheads, mimo_rank, state_rank]`; initialised to ones.
267    pub b_bias_hmr: Param<Tensor<3>>,
268
269    /// Learnable per-head, per-rank bias for C, added after QK-norm.
270    /// Shape: `[nheads, mimo_rank, state_rank]`; initialised to ones.
271    pub c_bias_hmr: Param<Tensor<3>>,
272
273    /// MIMO up-projection for x (values).
274    /// Shape: `[nheads, mimo_rank, per_head_dim]`.
275    /// Only present when `mimo_rank > 1`.  When SISO, this is `None`.
276    pub mimo_x_hmp: Option<Param<Tensor<3>>>,
277
278    /// MIMO up-projection for z (gate).
279    /// Shape: `[nheads, mimo_rank, per_head_dim]`.
280    /// Only present when `mimo_rank > 1`. When SISO, this is `None`.
281    pub mimo_z_hmp: Option<Param<Tensor<3>>>,
282
283    /// MIMO down-projection for the output.
284    /// Shape: `[nheads, mimo_rank, per_head_dim]`.
285    /// Only present when `mimo_rank > 1`. When SISO, this is `None`.
286    pub mimo_o_hmp: Option<Param<Tensor<3>>>,
287
288    /// Optional gated RMSNorm applied before the output projection.
289    ///
290    /// When `Some`, the SiLU gate at the block tail is replaced by
291    /// `RmsNormGated(y, z)` which normalises `y` over `per_head_dim` and
292    /// gates with `SiLU(z)`. Created when `has_outproj_norm = true`.
293    pub out_norm: Option<RmsNormGated>,
294
295    /// Output projection: maps `d_inner → d_model`.
296    pub out_proj: Linear,
297
298    /// Optional learnable initial hidden state `h₀`.
299    /// Shape: `[nheads, per_head_dim, state_rank]`
300    pub init_state_hpr: Option<Param<Tensor<3>>>,
301
302    /// State rank — the latent dimension of the SSM hidden state.
303    ///
304    /// Paper: `N`. Python: `d_state`.
305    pub state_rank: usize,
306
307    /// Number of B/C groups. Must divide `nheads`.
308    ///
309    /// Paper: `G`. Python: `num_bc_heads`.
310    pub ngroups: usize,
311
312    /// Number of RoPE angle pairs (`rope_dim / 2`).
313    ///
314    /// Python: `num_rope_angles`.
315    pub num_rope_angles: usize,
316
317    /// Effective RoPE dimension (= `2 · num_rope_angles`). Always even and
318    /// `≤ state_rank`. Only the first `rope_dim` entries of B/C are rotated.
319    /// `0` — like every other rotation count here — for
320    /// [`RotationKind::Real1D`], which rotates nothing.
321    pub rope_dim: usize,
322
323    /// MIMO rank. 1 = SISO (standard Mamba-3).
324    ///
325    /// Paper: `M`. Python: `mimo_rank`.
326    pub mimo_rank: usize,
327
328    /// Recurrence micro-steps per token — DeltaProduct's `u`
329    /// (see [`Mamba3Config::micro_steps`] and [`crate::mamba3::product`]).
330    /// `1` is stock Mamba-3.
331    pub micro_steps: usize,
332
333    /// Which transition rotation the block applies to `B`/`C` ([`RotationKind`]).
334    /// A non-parameter constant — `#[module(skip)]` keeps it out of the record and
335    /// carries it through `load_record`/`to_device`/… unchanged.
336    #[module(skip)]
337    pub rotation: RotationKind,
338
339    /// Which earlier sample(s) the trapezoid's `β` tap reads ([`Trapezoid`]).
340    /// A non-parameter constant, like [`Self::rotation`].
341    #[module(skip)]
342    pub trapezoid: Trapezoid,
343
344    /// How far one step may rotate, in half-turns per unit `Δ`
345    /// (see [`Mamba3Config::rotation_range`]).
346    pub rotation_range: f64,
347
348    /// Number of in-projection channels devoted to the rotation parameters
349    /// (`num_rope_angles` for `Complex2D`, `nheads·3·num_rotation_blocks` for
350    /// the quaternion kinds, `0` for `Real1D`); the size of the trailing
351    /// `in_proj` segment, which is absent entirely when it is `0`.
352    pub num_rotation_channels: usize,
353
354    /// Number of quaternion blocks (`rope_dim / 4`); only used for
355    /// [`RotationKind::Quaternion4D`] / [`RotationKind::Rotor4D`].
356    pub num_quat_blocks: usize,
357
358    /// Whether the `mimo_rank == 1` specialized *chunkwise* kernel is enabled
359    /// (see [`Mamba3Config::siso_specialization`]).
360    ///
361    /// A performance knob, not a semantic one: both branches compute the same
362    /// values and gradients. A non-parameter constant — `#[module(skip)]` keeps
363    /// it out of the record.
364    #[module(skip)]
365    pub siso_specialization: bool,
366
367    /// Whether the `mimo_rank == 1` specialized *per-token* kernels are enabled
368    /// (see [`Mamba3Config::siso_specialization_decode`]). Same performance-only
369    /// nature, opposite backend preference.
370    #[module(skip)]
371    pub siso_specialization_decode: bool,
372
373    /// The parameters held once per application instead of tied
374    /// ([`Mamba3Config::untied`]). A non-parameter constant, like
375    /// [`Self::rotation`].
376    #[module(skip)]
377    pub untied: Vec<Mamba3Untied>,
378}

380impl Mamba3 {
381    /// `d_inner = expand · d_model`.
382    pub fn d_inner(&self) -> usize {
383        // Inferred from `out_proj`
384        let [d_inner, _d_model] = self.out_proj.weight.dims();
385        d_inner
386    }
387
388    /// `nheads = d_inner / per_head_dim`.
389    pub fn nheads(&self) -> usize {
390        //  Inferred from `d_h`
391        let [nheads] = self.d_h.dims();
392        nheads
393    }
394
395    /// `per_head_dim = d_inner / nheads`.
396    pub fn per_head_dim(&self) -> usize {
397        self.d_inner() / self.nheads()
398    }
399
400    /// The block's rotation kind ([`RotationKind`]).
401    pub fn rotation_kind(&self) -> RotationKind {
402        self.rotation
403    }
404
405    /// Number of quaternion blocks the rotation projection and its cumulative
406    /// scan run over: `num_quat_blocks · quat_factors` — twice the state's
407    /// 4-block count for [`RotationKind::Rotor4D`], whose left and right
408    /// factors share one stacked block axis.
409    pub fn num_rotation_blocks(&self) -> usize {
410        self.num_quat_blocks * self.rotation.quat_factors()
411    }
412
413    /// Width of the in-projection's trailing rotation segment: the per-step
414    /// [`Self::num_rotation_channels`] once per micro-step, since each
415    /// micro-step turns the state by a rotation of its own.
416    pub fn rotation_channels_total(&self) -> usize {
417        self.micro_steps * self.num_rotation_channels
418    }
419
420    /// Width of the in-projection's `λ` segment — one channel per (head,
421    /// micro-step), or **`0`** under [`Trapezoid::None`], which has no `λ` to
422    /// project. Peeled off the tail by `helpers::split_trailing`, immediately
423    /// inside the rotation segment.
424    pub fn lambda_channels_total(&self) -> usize {
425        if self.trapezoid.has_beta_tap() {
426            self.micro_steps * self.nheads()
427        } else {
428            0
429        }
430    }
431
432    /// Width of the in-projection's `μ` segment — the second tap's mix, one
433    /// channel per (head, micro-step) for the two-tap patterns and **`0`** for
434    /// every other, including a two-tap one at `u = 1`, where the taps fold
435    /// ([`Trapezoid::has_interior_tap`]). Peeled off the tail by
436    /// `helpers::split_trailing`, immediately inside the `λ` segment.
437    pub fn mu_channels_total(&self) -> usize {
438        if self.trapezoid.has_interior_tap(self.micro_steps) {
439            self.micro_steps * self.nheads()
440        } else {
441            0
442        }
443    }
444
445    /// Everything the discretisation needs, in one place — the tap pattern, the
446    /// micro-steps its gates are periodic in, and the two clamps. Every site
447    /// that forms the trapezoid's masses ([`forward`](Self::forward),
448    /// [`step`](Self::step)) goes through this.
449    pub fn trapezoid_spec(&self) -> crate::mamba3::trapezoid::TrapezoidSpec {
450        crate::mamba3::trapezoid::TrapezoidSpec {
451            pattern: self.trapezoid,
452            micro_steps: self.micro_steps,
453            dt_limit: self.dt_limit,
454            a_floor: self.a_floor,
455        }
456    }
457
458    /// Everything the rotation needs, in one place — the algebra, the rotated
459    /// width, and the per-step bound. Every site that materialises a per-step
460    /// rotation ([`forward`](Self::forward), [`step`](Self::step)) goes
461    /// through this.
462    pub fn rotation_spec(&self) -> crate::mamba3::rotation::RotationSpec {
463        crate::mamba3::rotation::RotationSpec {
464            kind: self.rotation,
465            rope_dim: self.rope_dim,
466            range: self.rotation_range,
467        }
468    }
469
470    /// Whether the specialized `mimo_rank == 1` **per-token** kernels should run:
471    /// the block is SISO **and** [`Mamba3Config::siso_specialization_decode`] is
472    /// enabled.
473    ///
474    /// The chunkwise counterpart is [`Mamba3Config::siso_specialization`], which
475    /// travels to its kernel as a field of the SSD input bundle rather than
476    /// through a method.
477    ///
478    /// Purely a performance choice — see [`Mamba3Config::siso_specialization_decode`].
479    pub fn use_siso_decode_kernels(&self) -> bool {
480        self.mimo_rank == 1 && self.siso_specialization_decode
481    }
482
483    /// The in-projection's output `[z | … | rotation·u]`: `in_proj` alone, or —
484    /// under [`Mamba3Untied::InProjTail`] — followed by [`Self::in_proj_tail`].
485    pub fn project_in<const D: usize>(&self, x: Tensor<D>) -> Tensor<D> {
486        match &self.in_proj_tail {
487            None => self.in_proj.forward(x),
488            Some(tail) => Tensor::cat(vec![self.in_proj.forward(x.clone()), tail.forward(x)], D - 1),
489        }
490    }
491
492    /// The parameters held once per application ([`Self::untied`]), each with
493    /// the axis its copies lie along. See [`burn_stack::utils::untied`].
494    pub fn untied_params(&self) -> Vec<UntiedParam> {
495        let axis0 = |p: &Param<Tensor<1>>| UntiedParam::new(p, 0);
496        let axis0_hmx = |p: &Param<Tensor<3>>| UntiedParam::new(p, 0);
497        self.untied
498            .iter()
499            .flat_map(|part| -> Vec<UntiedParam> {
500                match part {
501                    Mamba3Untied::InProjTail => self
502                        .in_proj_tail
503                        .iter()
504                        .flat_map(|tail| {
505                            std::iter::once(UntiedParam::new(&tail.weight, 1))
506                                .chain(tail.bias.as_ref().map(axis0))
507                        })
508                        .collect(),
509                    Mamba3Untied::DtBias => vec![axis0(&self.dt_bias_h)],
510                    Mamba3Untied::D => vec![axis0(&self.d_h)],
511                    Mamba3Untied::BNorm => vec![axis0(&self.b_norm.gamma)],
512                    Mamba3Untied::CNorm => vec![axis0(&self.c_norm.gamma)],
513                    Mamba3Untied::BBias => vec![axis0_hmx(&self.b_bias_hmr)],
514                    Mamba3Untied::CBias => vec![axis0_hmx(&self.c_bias_hmr)],
515                    Mamba3Untied::MimoX => self.mimo_x_hmp.iter().map(axis0_hmx).collect(),
516                    Mamba3Untied::MimoZ => self.mimo_z_hmp.iter().map(axis0_hmx).collect(),
517                    Mamba3Untied::MimoO => self.mimo_o_hmp.iter().map(axis0_hmx).collect(),
518                    Mamba3Untied::OutNorm => self.out_norm.iter().map(|n| axis0(&n.gamma)).collect(),
519                    Mamba3Untied::InitState => self.init_state_hpr.iter().map(axis0_hmx).collect(),
520                }
521            })
522            .collect()
523    }

615    /// products. The read `C`, the gate `z`, the `D` skip and the output are

619    /// [`Real1D`](crate::mamba3::rotation::RotationKind::Real1D) the factors are

634    /// previous step" may mean the previous micro-step or the previous token;
635    /// at `u = 1` every pattern either coincides with the default or switches

665    /// Whether to add a bias term to the `in_proj` and `out_proj`.

673    /// Fraction of `state_rank` the transition rotation turns (must be `0.5`
674    /// or `1.0`).
675    ///
676    /// To disable the rotation, pick the *kind* [`RotationKind::Real1D`] rather
677    /// than a fraction of zero: a real transition projects no rotation channels
678    /// and caches no accumulator, where a zero fraction used to keep both alive
679    /// around a rotation nobody applied. Ignored by `Real1D`, which turns
680    /// nothing whatever this says.
681    ///
682    /// - `0.5`: partial rotation — only `state_rank / 2` dimensions are turned;
683    ///   the rest pass through unchanged. This is the reference's value in
684    ///   `mamba3.py`; set it explicitly to reproduce that model.
685    /// - `1.0` (default): full rotation — every B/C dimension is turned.
686    ///
687    /// The default turns everything, for both rotation kinds: a partial
688    /// rotation is a capacity trade (keeping "content" channels out of the
689    /// turn), which is a deliberate choice a config should have to ask for
690    /// rather than get by omission. For
691    /// [`Quaternion4D`](RotationKind::Quaternion4D) and
692    /// [`Rotor4D`](RotationKind::Rotor4D) it is also what keeps the smallest
693    /// legal `state_rank` (4 — a single quaternion block) usable, since a
694    /// partial quaternion rotation must land on whole 4-blocks.
695    #[config(default = 1.0)]
696    pub rope_fraction: f64,

699    ///

701    /// per-head [`RmsNormGated`] (group size = `per_head_dim`) which both
702    /// normalises `y` and gates it with `SiLU(z)`. Matches the reference's
703    /// `is_outproj_norm` argument in `mamba3.py`.
704    #[config(default = false)]
705    pub has_outproj_norm: bool,

708    /// carried by the state transition and absorbed into `B`/`C` (see
709    /// [`RotationKind`]).
710    ///
711    /// Defaults to the abelian [`Complex2D`](RotationKind::Complex2D) — the
712    /// current Mamba-3 RoPE — for which the block is byte-for-byte unchanged.
713    /// [`Quaternion4D`](RotationKind::Quaternion4D) selects the non-abelian
714    /// quaternion rotation; its in-projection devotes
715    /// `nheads · 3 · num_quat_blocks` channels to per-head quaternion
716    /// generators in place of the shared `num_rope_angles` angle channels (see
717    /// [`Self::num_rotation_channels`]). [`Rotor4D`](RotationKind::Rotor4D)
718    /// selects the full `SO(4)` rotation of each 4-block and doubles that
719    /// channel count (a left and a right generator per head and block).
720    /// [`Real1D`](RotationKind::Real1D) removes the rotation altogether — no
721    /// channels, no accumulator, a real transition.
722    #[config(default = "crate::mamba3::rotation::RotationKind::Complex2D")]
723    pub rotation: RotationKind,
724
725    /// How far a single step may rotate the state, in **half-turns per unit
726    /// `Δ`**: the per-step angle is bounded by `rotation_range · π · Δ`.
727    ///
728    /// The default of `2.0` is "one unit of `Δ` may traverse the whole rotation
729    /// group once", which means the same thing for both kinds even though their
730    /// periods differ:
731    ///
732    /// - [`Complex2D`](RotationKind::Complex2D): `2π` is a full turn of
733    ///   `SO(2)`.
734    /// - [`Quaternion4D`](RotationKind::Quaternion4D): `2π` reaches every
735    ///   element of `SU(2)`, whose period is `4π` — `q` and `−q` are the two
736    ///   lifts of one `SO(3)` rotation and turn the state differently.
737    /// - [`Rotor4D`](RotationKind::Rotor4D): the bound applies to **each
738    ///   factor**, so at the default each of `q` and `p` independently sweeps
739    ///   all of `SU(2)` and the pair reaches every element of
740    ///   `SO(4) ≅ (SU(2)×SU(2))/±1`. Bounding the composite instead (halving
741    ///   the per-factor angle) would cost reach for nothing: the two plane
742    ///   angles `a∓b` are periodic in `2π` anyway.
743    ///
744    /// What the bound buys is not reach but **gradients**. A rotation of exactly
745    /// `range·π` sits at `tanh`'s asymptote, where the gradient is not merely
746    /// small but **exactly zero** in f32 (`tanh(10) == 1.0`). Half-turns are
747    /// what state-tracking wants, so at `range = 1` — where `π` *is* the
748    /// bound — the most useful rotation is the one the optimiser can never
749    /// reach. At `2.0` it sits at `tanh = 1/2`, in the interior.
750    ///
751    /// `1.0` is the reference implementation's abelian bound (`Δ·π·tanh(ϑ)`);
752    /// set it explicitly to reproduce that model. Ignored by
753    /// [`Real1D`](RotationKind::Real1D), which never turns.
754    #[config(default = 2.0)]
755    pub rotation_range: f64,
756
757    /// Whether to use the specialized `mimo_rank == 1` (SISO) **chunkwise**
758    /// kernel: the same-step γ-correction
759    /// ([`y_diag_correction`](crate::mamba3::single_ssd::ssd::diag::y_diag_correction)),
760    /// forward *and* its analytic backward.
761    ///
762    /// At `mimo_rank == 1` the `m × m` Gram is a scalar, so the general form
763    /// issues a `1×r×1` and a `1×1×p` GEMM per `(batch, nchunks, chunk_len,
764    /// nheads)` — thousands of degenerate products. The SISO branch replaces all
765    /// of them with one elementwise multiply and a `state_rank` reduction over
766    /// the whole tensor, which is why deleting the tiny GEMMs helps everywhere:
767    /// ≈ neutral to ~9 % faster across the backends in `bench.md`. Leave it on.
768    ///
769    /// **Values and gradients are identical either way** — this only selects the
770    /// op mix. Ignored when `mimo_rank > 1`, where only the general branch
771    /// applies. See also [`Self::siso_specialization_decode`], the per-token
772    /// counterpart, whose trade-off is *not* the same.
773    #[config(default = true)]
774    pub siso_specialization: bool,
775
776    /// Whether to use the specialized `mimo_rank == 1` (SISO) **per-token**
777    /// kernels: the decode state update and readout
778    /// (`helpers::mimo_outer_sum`, `Mamba3::step_readout`) and the single-SSD
779    /// boundary-β seed.
780    ///
781    /// **Set this to `false` on the CPU backends.** Unlike the chunkwise flag,
782    /// this one replaces a *single, already efficient* batched matmul with a
783    /// broadcast multiply, so the verdict flips with the backend: at
784    /// `benches/layer.rs`'s default size the `step` group is ~12 % faster on CUDA
785    /// and about **3× slower on flex**, whose broadcast-elementwise path trails
786    /// its matmul by more than an order of magnitude at these shapes. The default
787    /// (`true`) suits the GPU backends; a CPU deployment that decodes should turn
788    /// it off — and can do so while keeping [`Self::siso_specialization`] on,
789    /// which is the point of having two flags.
790    ///
791    /// **Values and gradients are identical either way.** Ignored when
792    /// `mimo_rank > 1`.
793    #[config(default = true)]
794    pub siso_specialization_decode: bool,
795
796    /// The parameters held once per application of the block's real layer
797    /// instead of tied across them ([`Mamba3Untied`]); only virtual layers give
798    /// a real layer more than one. Each must exist in this config. The layout
799    /// follows the list alone — [`Mamba3Untied::InProjTail`] splits `in_proj` at
800    /// any count — so every real layer of a stack has the one Muon plan. See
801    /// [`burn_stack::utils::untied`].
802    #[config(default = "Vec::new()")]
803    pub untied: Vec<Mamba3Untied>,
804}

806impl Mamba3Config {
807    /// Inner (expanded) channel width: `expand · d_model`.
808    pub fn d_inner(&self) -> usize {
809        self.expand * self.d_model
810    }
811    /// Number of SSM heads: `d_inner / per_head_dim`.
812    pub fn nheads(&self) -> usize {
813        self.d_inner() / self.per_head_dim
814    }
815
816    /// Effective RoPE dimension: the number of B/C channels actually rotated.
817    /// `state_rank` for full RoPE (`rope_fraction = 1.0`), `state_rank / 2` for
818    /// `rope_fraction = 0.5` — and `0` for [`RotationKind::Real1D`], which
819    /// rotates nothing at all.
820    pub fn rope_dim(&self) -> usize {
821        if self.rotation == RotationKind::Real1D {
822            return 0;
823        }
824        let mut d = (self.state_rank as f64 * self.rope_fraction) as usize;
825        if !d.is_multiple_of(2) {
826            d -= 1;
827        }
828        d
829    }
830
831    /// Number of RoPE rotation angles projected per head: `rope_dim / 2` (`0`
832    /// for [`RotationKind::Real1D`]). `init` asserts every rotating kind turns
833    /// at least one pair, so this is `> 0` wherever it is read.
834    pub fn num_rope_angles(&self) -> usize {
835        self.rope_dim() / 2
836    }
837
838    /// Number of **state** quaternion blocks for the quaternion kinds:
839    /// `rope_dim / 4`, which `init` asserts is a whole number (and non-zero)
840    /// for them. `0` for [`RotationKind::Real1D`]; meaningless, and unread, for
841    /// [`RotationKind::Complex2D`].
842    pub fn num_quat_blocks(&self) -> usize {
843        self.rope_dim() / 4
844    }
845
846    /// Number of in-projection channels devoted to the rotation parameters,
847    /// per the configured [`RotationKind`]:
848    ///
849    /// - [`Real1D`](RotationKind::Real1D): none — the trailing `in_proj`
850    ///   segment is absent, not zero-width (Burn has no zero-width tensors).
851    /// - [`Complex2D`](RotationKind::Complex2D): `num_rope_angles` angle
852    ///   channels, shared across heads and scaled per-head by `Δ`, as in the
853    ///   reference.
854    /// - [`Quaternion4D`](RotationKind::Quaternion4D) /
855    ///   [`Rotor4D`](RotationKind::Rotor4D):
856    ///   `nheads · 3 · num_rotation_blocks` quaternion-generator channels — an
857    ///   axis·angle generator **per head** and block (and, for `Rotor4D`, per
858    ///   *factor*: one generator for the left quaternion and one for the
859    ///   right), fed through
860    ///   [`quat_from_scaled_axis`](crate::mamba3::rotation::quat_from_scaled_axis).
861    ///   For a non-abelian transition the axis is where the expressiveness
862    ///   lives: heads sharing one axis and differing only in `Δ` track one word
863    ///   at different speeds instead of different words. See
864    ///   [`generator_increment`](crate::mamba3::rotation::generator_increment).
865    pub fn num_rotation_channels(&self) -> usize {
866        match self.rotation {
867            // A real transition has no rotation to parameterise.
868            RotationKind::Real1D => 0,
869            RotationKind::Complex2D => self.num_rope_angles(),
870            // Three generator channels per (head, block) and **per factor**:
871            // one factor for Quaternion4D, two for Rotor4D.
872            RotationKind::Quaternion4D | RotationKind::Rotor4D => {
873                self.nheads() * 3 * self.num_rotation_blocks()
874            }
875        }
876    }
877
878    /// Number of quaternion blocks the *rotation projection and scan* run over:
879    /// [`Self::num_quat_blocks`] times [`RotationKind::quat_factors`] — i.e.
880    /// `2 · blocks` for [`RotationKind::Rotor4D`], whose left and right factors
881    /// share one stacked block axis.
882    pub fn num_rotation_blocks(&self) -> usize {
883        self.num_quat_blocks() * self.rotation.quat_factors()
884    }
885
886    /// Total input projection output size.
887    ///
888    /// ```text
889    ///   [ z | x·u | B·u | C | Δ·u | A·u | λ·u | μ·u | rotation·u ]
890    /// ```
891    ///
892    /// i.e. `d_inner + u·d_inner + u·bc + bc + (2 … 4)·u·nheads +
893    /// u·num_rotation_channels` with `bc = ngroups·state_rank·mimo_rank` and `u` =
894    /// [`Self::micro_steps`]. Only the **per-micro-step** segments widen; the
895    /// gate `z` and the read `C` are per token (see [`crate::mamba3::product`]).
896    /// At `u = 1` this is the stock
897    /// `2·d_inner + 2·bc + 3·nheads + num_rotation_channels`.
898    ///
899    /// The three trailing segments are the ones a block may omit outright:
900    /// [`Trapezoid::None`] projects no `λ`, a one-tap pattern no `μ`, and
901    /// [`RotationKind::Real1D`] no rotation (`helpers::split_trailing` peels
902    /// them in the reverse of that order).
903    pub fn d_in_proj(&self) -> usize {
904        let u = self.micro_steps;
905        let bc = self.ngroups * self.state_rank * self.mimo_rank;
906        self.d_inner() + u * self.d_inner() + u * bc + bc + self.d_in_proj_tail()
907    }
908
909    /// Width of the in-projection's trailing per-micro-step segments
910    /// `[Δ·u | A·u | λ·u | μ·u | rotation·u]` — `(2 … 4)·u·nheads +
911    /// u·num_rotation_channels` — which [`Mamba3Untied::InProjTail`] splits off.
912    pub fn d_in_proj_tail(&self) -> usize {
913        let u = self.micro_steps;
914        let scalars = 2
915            + usize::from(self.trapezoid.has_beta_tap())
916            + usize::from(self.trapezoid.has_interior_tap(u));
917        scalars * u * self.nheads() + u * self.num_rotation_channels()
918    }
919
920    /// The block's 2-D weights Muon may own, and how their fused columns split.
921    ///
922    /// `in_proj`'s segments mirror the `split_into` in the SSD pathways
923    /// (`[z | x·u | B·u | C | Δ·u | A·u | λ·u | μ·u | rotation·u]`); the per-head
924    /// *scalar* channels stay on AdamW. See [`burn_stack::optim`].
925    ///
926    /// Each micro-step gets its **own** segment rather than sharing one `u`-wide
927    /// slab: they are `u` independent `d_model → width` maps, and Muon should
928    /// orthogonalise each on its own. They share a name, so
929    /// [`MuonPlan::without_segment`](burn_stack::optim::MuonPlan::without_segment)
930    /// still opts all of a stream's micro-steps out at once.
931    ///
932    /// Under [`Mamba3Untied::InProjTail`] the segments from `Δ` on are
933    /// `in_proj_tail`'s, one copy per application ([`ProjSpec::tiled`]).
934    ///
935    /// [`ProjSpec::tiled`]: burn_stack::optim::ProjSpec::tiled
936    #[cfg(feature = "optim")]
937    pub fn muon_projections(&self) -> Vec<burn_stack::optim::ProjSpec> {
938        use burn_stack::optim::{ProjSegment as Seg, ProjSpec};
939        let d_inner = self.d_inner();
940        let nheads = self.nheads();
941        let bc = self.ngroups * self.state_rank * self.mimo_rank;
942        let rot = self.num_rotation_channels();
943        // One copy of `seg` per micro-step.
944        let per_micro = |seg: Seg| std::iter::repeat_n(seg, self.micro_steps);
945        let head: Vec<Seg> = std::iter::once(Seg::muon("z", d_inner))
946            .chain(per_micro(Seg::muon("x", d_inner)))
947            .chain(per_micro(Seg::muon("b", bc)))
948            .chain(std::iter::once(Seg::muon("c", bc)))
949            .collect();
950        let tail: Vec<Seg> = per_micro(Seg::adamw("dt", nheads))
951            .chain(per_micro(Seg::adamw("a", nheads)))
952            // `Trapezoid::None` projects no `λ`, as `Real1D` projects no rotation;
953            // and only a two-tap pattern projects the second mass's mix `μ`.
954            .chain(
955                self.trapezoid
956                    .has_beta_tap()
957                    .then(|| per_micro(Seg::adamw("lambda", nheads)))
958                    .into_iter()
959                    .flatten(),
960            )
961            .chain(
962                self.trapezoid
963                    .has_interior_tap(self.micro_steps)
964                    .then(|| per_micro(Seg::adamw("mu", nheads)))
965                    .into_iter()
966                    .flatten(),
967            )
968            // `Real1D` has no rotation columns, and a zero-width segment is
969            // not a thing (see `num_rotation_channels`).
970            .chain(
971                (rot > 0)
972                    .then(|| per_micro(Seg::muon("rotation", rot)))
973                    .into_iter()
974                    .flatten(),
975            )
976            .collect();
977        let in_proj = match self.untied.contains(&Mamba3Untied::InProjTail) {
978            true => vec![
979                ProjSpec::block("in_proj.weight", head),
980                ProjSpec::block("in_proj_tail.weight", tail).tiled(),
981            ],
982            false => vec![ProjSpec::block("in_proj.weight", [head, tail].concat())],
983        };
984        in_proj
985            .into_iter()
986            .chain([ProjSpec::block_whole("out_proj.weight", self.d_model)])
987            .collect()
988    }

990    /// Allocate and initialise all Mamba-3 block parameters on `device`, for a
991    /// single application.
992    pub fn init(&self, device: &Device) -> Mamba3 {
993        self.init_applications(1, device)
994    }
995
996    /// Allocate and initialise all Mamba-3 block parameters on `device`, for a
997    /// real layer applied `n_applications` times: every [`Self::untied`]
998    /// parameter holds that many copies of one initialisation.
999    pub fn init_applications(&self, n_applications: usize, device: &Device) -> Mamba3 {
1000        let d_inner = self.d_inner();
1001        let nheads = self.nheads();
1002        let ngroups = self.ngroups;
1003        let state_rank = self.state_rank;
1004        let mimo_rank = self.mimo_rank;
1005        let num_rope_angles = self.num_rope_angles();
1006
1007        assert!(state_rank > 0, "state_rank must be positive");
1008        // Evenness is a RoPE-pairing requirement; `Real1D` pairs nothing, so it
1009        // is the one kind that admits an odd (in particular, scalar) state.
1010        assert!(
1011            self.rotation == RotationKind::Real1D || state_rank.is_multiple_of(2),
1012            "state_rank must be even for RoPE pairing"
1013        );
1014        assert!(self.per_head_dim > 0, "per_head_dim must be positive");
1015        assert_eq!(
1016            nheads * self.per_head_dim,
1017            d_inner,
1018            "d_inner must be divisible by per_head_dim"
1019        );
1020        assert_ne!(ngroups, 0, "ngroups must be at least 1");
1021        assert_eq!(nheads % ngroups, 0, "nheads must be divisible by ngroups");
1022        assert!(self.a_floor > 0.0, "a_floor must be positive");
1023        assert!(mimo_rank >= 1, "mimo_rank must be at least 1");
1024        assert!(self.micro_steps >= 1, "micro_steps must be at least 1");
1025        assert!(
1026            [0.5, 1.0].contains(&self.rope_fraction),
1027            "rope_fraction must be 0.5 or 1.0 (for no rotation use RotationKind::Real1D)"
1028        );
1029        if self.rotation != RotationKind::Real1D {
1030            // Every rotating kind must actually turn something; the ablation is
1031            // a kind of its own now, not a fraction of zero.
1032            assert!(
1033                num_rope_angles > 0,
1034                "{:?} rotates nothing at state_rank = {} and rope_fraction = {} — use RotationKind::Real1D",
1035                self.rotation,
1036                self.state_rank,
1037                self.rope_fraction
1038            );
1039        }
1040        if matches!(
1041            self.rotation,
1042            RotationKind::Quaternion4D | RotationKind::Rotor4D
1043        ) {
1044            assert!(
1045                self.state_rank.is_multiple_of(4),
1046                "{:?} requires state_rank to be a multiple of 4",
1047                self.rotation
1048            );
1049            // The rotated width is a whole number of quaternion blocks, so a
1050            // partial rotation has to land on a multiple of 4. Without this the
1051            // block would quietly round `num_quat_blocks` up to its floor of 1
1052            // and rotate *everything* when asked for half.
1053            assert!(
1054                self.rope_dim().is_multiple_of(4),
1055                "{:?} rotates whole 4-blocks: rope_fraction·state_rank = {} is not a multiple of 4",
1056                self.rotation,
1057                self.rope_dim()
1058            );
1059        }
1060        assert!(self.rotation_range > 0.0, "rotation_range must be positive");
1061        let unties = |part| self.untied.contains(&part);
1062        assert!(
1063            mimo_rank > 1
1064                || ![Mamba3Untied::MimoX, Mamba3Untied::MimoZ, Mamba3Untied::MimoO]
1065                    .into_iter()
1066                    .any(unties),
1067            "Mamba3Untied::Mimo* unties a MIMO projection, and mimo_rank = 1 has none"
1068        );
1069        assert!(
1070            self.has_outproj_norm || !unties(Mamba3Untied::OutNorm),
1071            "Mamba3Untied::OutNorm unties the output norm, and has_outproj_norm is off"
1072        );
1073        assert!(
1074            self.has_learnable_init_state || !unties(Mamba3Untied::InitState),
1075            "Mamba3Untied::InitState unties the initial state, and has_learnable_init_state is off"
1076        );
1077        // How many copies `part` holds: one per application if untied.
1078        let copies = |part| if unties(part) { n_applications } else { 1 };
1079
1080        let uniform_init = |fan_in: usize| {
1081            let bound = 1.0 / (fan_in as f64).sqrt();
1082            Initializer::Uniform {
1083                min: -bound,
1084                max: bound,
1085            }
1086        };
1087
1088        let d_in_proj_tail = unties(Mamba3Untied::InProjTail).then(|| self.d_in_proj_tail());
1089        let in_proj = LinearConfig::new(self.d_model, self.d_in_proj() - d_in_proj_tail.unwrap_or(0))
1090            .with_bias(self.has_proj_bias)
1091            .with_initializer(uniform_init(self.d_model))
1092            .init(device);
1093        let in_proj_tail = d_in_proj_tail.map(|width| {
1094            let Linear { weight, bias } = LinearConfig::new(self.d_model, width)
1095                .with_bias(self.has_proj_bias)
1096                .with_initializer(uniform_init(self.d_model))
1097                .init(device);
1098            Linear {
1099                weight: untied::tile(weight, 1, n_applications),
1100                bias: bias.map(|b| untied::tile(b, 0, n_applications)),
1101            }
1102        });
1103
1104        // dt_bias: inverse-softplus initialisation
1105        let expm1 = |t: Tensor<1>| t.exp() - 1.;
1106        let dt_h = Tensor::random(
1107            [nheads],
1108            burn::tensor::Distribution::Uniform(self.dt_min.ln(), self.dt_max.ln()),
1109            device,
1110        )
1111        .exp();
1112        let dt_h = dt_h.clamp(self.dt_init_floor, f64::INFINITY);
1113        let inv_dt_h = dt_h.clone() + (-expm1(-dt_h)).log();
1114        let dt_bias_h = untied::tile(
1115            Param::from_tensor(inv_dt_h),
1116            0,
1117            copies(Mamba3Untied::DtBias),
1118        );
1119
1120        let d_h = Initializer::Ones.init::<1, _>([nheads], device);
1121        let d_h = untied::tile(d_h, 0, copies(Mamba3Untied::D));
1122
1123        let mut b_norm = RmsNormConfig::new(state_rank).init(device);
1124        b_norm.gamma = untied::tile(b_norm.gamma, 0, copies(Mamba3Untied::BNorm));
1125        let mut c_norm = RmsNormConfig::new(state_rank).init(device);
1126        c_norm.gamma = untied::tile(c_norm.gamma, 0, copies(Mamba3Untied::CNorm));
1127
1128        // B/C biases: [nheads, mimo_rank, state_rank], init to ones
1129        let b_bias_hmr = Initializer::Ones.init::<3, _>([nheads, mimo_rank, state_rank], device);
1130        let b_bias_hmr = untied::tile(b_bias_hmr, 0, copies(Mamba3Untied::BBias));
1131        let c_bias_hmr = Initializer::Ones.init::<3, _>([nheads, mimo_rank, state_rank], device);
1132        let c_bias_hmr = untied::tile(c_bias_hmr, 0, copies(Mamba3Untied::CBias));
1133
1134        // MIMO projections (only for mimo_rank > 1)
1135        let (mimo_x_hmp, mimo_z_hmp, mimo_o_hmp) = if mimo_rank > 1 {
1136            let per_head_dim = self.per_head_dim;
1137            // Init: mimo_x_hmp and mimo_o_hmp to 1/mimo_rank, mimo_z_hmp to 1
1138            let mx = Param::from_tensor(Tensor::full(
1139                [nheads, mimo_rank, per_head_dim],
1140                1.0 / mimo_rank as f64,
1141                device,
1142            ));
1143            let mz = Param::from_tensor(Tensor::ones([nheads, mimo_rank, per_head_dim], device));
1144            let mo = Param::from_tensor(Tensor::full(
1145                [nheads, mimo_rank, per_head_dim],
1146                1.0 / mimo_rank as f64,
1147                device,
1148            ));
1149            (
1150                Some(untied::tile(mx, 0, copies(Mamba3Untied::MimoX))),
1151                Some(untied::tile(mz, 0, copies(Mamba3Untied::MimoZ))),
1152                Some(untied::tile(mo, 0, copies(Mamba3Untied::MimoO))),
1153            )
1154        } else {
1155            (None, None, None)
1156        };
1157
1158        // Gated RMSNorm applied per-head (group size = per_head_dim).
1159        let out_norm = self.has_outproj_norm.then(|| {
1160            let mut norm = RmsNormGatedConfig::new(self.per_head_dim)
1161                .with_norm_before_gate(true)
1162                .init(device);
1163            norm.gamma = untied::tile(norm.gamma, 0, copies(Mamba3Untied::OutNorm));
1164            norm
1165        });
1166
1167        let out_proj = LinearConfig::new(d_inner, self.d_model)
1168            .with_bias(self.has_proj_bias)
1169            .with_initializer(uniform_init(d_inner))
1170            .init(device);
1171
1172        let init_state_hpr = self.has_learnable_init_state.then(|| {
1173            let init = Initializer::Zeros.init::<3, _>([nheads, self.per_head_dim, state_rank], device);
1174            untied::tile(init, 0, copies(Mamba3Untied::InitState))
1175        });
1176
1177        Mamba3 {
1178            in_proj,
1179            in_proj_tail,
1180            dt_bias_h,
1181            dt_limit: self.dt_limit,
1182            a_floor: self.a_floor,
1183            d_h,
1184            b_norm,
1185            c_norm,
1186            b_bias_hmr,
1187            c_bias_hmr,
1188            mimo_x_hmp,
1189            mimo_z_hmp,
1190            mimo_o_hmp,
1191            out_norm,
1192            out_proj,
1193            init_state_hpr,
1194            state_rank,
1195            ngroups,
1196            rope_dim: self.rope_dim(),
1197            num_rope_angles,
1198            mimo_rank,
1199            micro_steps: self.micro_steps,
1200            rotation: self.rotation,
1201            trapezoid: self.trapezoid,
1202            rotation_range: self.rotation_range,
1203            num_rotation_channels: self.num_rotation_channels(),
1204            num_quat_blocks: self.num_quat_blocks(),
1205            siso_specialization: self.siso_specialization,
1206            siso_specialization_decode: self.siso_specialization_decode,
1207            untied: self.untied.clone(),
1208        }
1209    }
1210}

1216impl Mamba3 {
1217    /// Process a full input sequence using the trapezoidal double-SSD algorithm.
1218    ///
1219    /// For SISO (mimo_rank=1), this is the standard double-SSD decomposition.
1220    /// For MIMO (mimo_rank>1), B/C have mimo_rank parallel rank channels.
1221    /// The hidden state is shared across mimo ranks; each mimo rank contributes independently.
1222    ///
1223    /// # Shapes
1224    /// - `input_bsm` : `[batch, sequence, d_model]`
1225    /// - output      : `[batch, sequence, d_model]`
1226    #[allow(non_snake_case)]
1227    pub fn forward(
1228        &self,
1229        input_bsm: Tensor<3>,
1230        cache: Option<Mamba3Cache>,
1231        ssd_path: Mamba3SsdPath,
1232    ) -> (Tensor<3>, Mamba3Cache) {
1233        let [batch, sequence, _d_model] = input_bsm.dims();
1234        let nheads = self.nheads();
1235        let ngroups = self.ngroups;
1236        let _per_head_dim = self.per_head_dim();
1237        let _state_rank = self.state_rank;
1238        let _num_rope_angles = self.num_rope_angles;
1239        let _mimo_rank = self.mimo_rank;
1240        let device = input_bsm.device();
1241
1242        assert!(sequence > 0, "sequence length must be at least 1");
1243        assert_eq!(nheads % ngroups, 0);
1244        san(&input_bsm);
1245
1246        // ── Initialise cache if not provided ──────────────────────────────────
1247        // A missing cache implies the single-ssd pathway (both rotation kinds are
1248        // supported there; see [`forward_single_ssd`]).
1249        let cache = cache.unwrap_or_else(|| self.zero_cache(batch, &device));
1250
1251        // ── SSD Pathway Selection ─────────────────────────────────────────────
1252        match cache {
1253            Mamba3Cache::DoubleSsd(cache) => {
1254                let (out_bsm, cache) = self.forward_double_ssd(input_bsm, Some(cache), &ssd_path);
1255                (out_bsm, cache.into())
1256            }
1257            Mamba3Cache::SingleSsd(cache) => {
1258                let (out_bsm, cache) = self.forward_single_ssd(input_bsm, Some(cache), &ssd_path);
1259                (out_bsm, cache.into())
1260            }
1261        }
1262    }
1263
1264    /// Build the default per-call cache (single-ssd pathway, for either rotation
1265    /// kind). The rotation accumulator is the matching [`RotationState`] variant.
1266    fn zero_cache(&self, batch: usize, device: &Device) -> Mamba3Cache {
1267        let nheads = self.nheads();
1268        let per_head_dim = self.per_head_dim();
1269        let state_rank = self.state_rank;
1270        let ssm_bhpr = Tensor::zeros([batch, nheads, per_head_dim, state_rank], device);
1271        let (k_state_bumhr, v_state_buhp) = self.zero_tap_slots(batch, device);
1272        let rotation = self.zero_rotation_state(batch, device);
1273        crate::mamba3::single_ssd::cache::Mamba3SingleSsdCache {
1274            ssm_bhpr,
1275            k_state_bumhr,
1276            v_state_buhp,
1277            rotation,
1278        }
1279        .into()
1280    }
1281
1282    /// How far back this block's `β` tap reaches, in folded positions —
1283    /// [`Trapezoid::tap_lag`] at this block's `micro_steps`. `0` when the
1284    /// pattern has no tap.
1285    pub fn tap_lag(&self) -> usize {
1286        self.trapezoid.tap_lag(self.micro_steps)
1287    }
1288
1289    /// The trapezoid's tap FIFO, zero-filled: [`Self::tap_lag`] slots of
1290    /// `(B, x)`, oldest first — or `None` under a pattern with no `β` tap, in
1291    /// which case nothing is allocated at all.
1292    ///
1293    /// # Shapes
1294    /// - `.0` : `[batch, tap_slots, mimo_rank, nheads, state_rank]`
1295    /// - `.1` : `[batch, tap_slots, nheads, per_head_dim]`
1296    pub fn zero_tap_slots(
1297        &self,
1298        batch: usize,
1299        device: &Device,
1300    ) -> (Option<Tensor<5>>, Option<Tensor<4>>) {
1301        let slots = self.tap_lag();
1302        if slots == 0 {
1303            return (None, None);
1304        }
1305        let nheads = self.nheads();
1306        (
1307            Some(Tensor::zeros(
1308                [batch, slots, self.mimo_rank, nheads, self.state_rank],
1309                device,
1310            )),
1311            Some(Tensor::zeros(
1312                [batch, slots, nheads, self.per_head_dim()],
1313                device,
1314            )),
1315        )
1316    }
1317
1318    /// The tap FIFO to hand to the next call: the last `lag` folded positions'
1319    /// `(B, x)`, oldest first — or `(None, None)` when the pattern has no `β`
1320    /// tap.
1321    ///
1322    /// `x` is pre-scaled by the decay accumulated since its own position
1323    /// ([`crate::mamba3::helpers::tail_decay`]), which is what lets a lag-`u`
1324    /// tap's gap transport span the call boundary; at `lag = 1` that product is
1325    /// empty and the slot is the plain last `x`. Shared by both pathways, whose
1326    /// caches therefore stay field-identical.
1327    ///
1328    /// # Shapes
1329    /// - `b_bsmhr` : `[batch, sequence, mimo_rank, nheads, state_rank]`
1330    /// - `x_bshp`  : `[batch, sequence, nheads, per_head_dim]`
1331    /// - `da_bsh`  : `[batch, sequence, nheads]`
1332    pub(crate) fn save_tap_slots(
1333        &self,
1334        b_bsmhr: &Tensor<5>,
1335        x_bshp: &Tensor<4>,
1336        da_bsh: &Tensor<3>,
1337        lag: usize,
1338    ) -> (Option<Tensor<5>>, Option<Tensor<4>>) {
1339        if lag == 0 {
1340            return (None, None);
1341        }
1342        let sequence = x_bshp.dims()[1];
1343        let b_last_bumhr = b_bsmhr.clone().narrow(1, sequence - lag, lag);
1344        let x_last_buhp = x_bshp.clone().narrow(1, sequence - lag, lag);
1345        let x_last_buhp = match crate::mamba3::helpers::tail_decay(da_bsh.clone(), lag) {
1346            Some(tail_buh) => x_last_buhp * tail_buh.unsqueeze_dim::<4>(3),
1347            None => x_last_buhp,
1348        };
1349        (Some(b_last_bumhr), Some(x_last_buhp))
1350    }
1351
1352    /// The fresh-sequence rotation accumulator for this block's
1353    /// [`RotationKind`] — the identity rotation, in the matching
1354    /// [`RotationState`] variant.
1355    pub fn zero_rotation_state(&self, batch: usize, device: &Device) -> RotationState {
1356        RotationState::identity(
1357            self.rotation,
1358            batch,
1359            self.nheads(),
1360            self.num_rope_angles,
1361            self.num_quat_blocks,
1362            device,
1363        )
1364    }
1365}

1371mod step {

1374    impl Mamba3 {
1375        /// Process a **single token** using the pure recurrent form.
1376        ///
1377        /// For SISO (mimo_rank=1):
1378        /// ```text
1379        ///   hₜ = αₜ hₜ₋₁ + βₜ Bₜ₋₁ ⊗ xₜ₋₁ + γₜ Bₜ ⊗ xₜ
1380        ///   yₜ = Cₜᵀ hₜ + D xₜ
1381        /// ```
1382        ///
1383        /// For MIMO (mimo_rank>1):
1384        /// ```text
1385        ///   hₜ = αₜ hₜ₋₁ + Σₘ βₜ Bₜ₋₁[m] ⊗ (xₜ₋₁ ⊙ mimo_x_hmp[m]) + Σₘ γₜ Bₜ[m] ⊗ (xₜ ⊙ mimo_x_hmp[m])
1386        ///   yₜ[r] = Cₜ[r]ᵀ hₜ + D xₜ ⊙ mimo_x_hmp[r]
1387        ///   outₜ = Σₘ mimo_o_hmp[m] ⊙ silu(zₜ ⊙ mimo_z_hmp[m]) ⊙ yₜ[m]
1388        /// ```
1389        ///
1390        /// # Shapes
1391        /// - `input_bd` : `[batch, d_model]`
1392        /// - output     : `[batch, d_model]`
1393        #[allow(non_snake_case)]
1394        pub fn step(
1395            &self,
1396            input_bd: Tensor<2>,
1397            cache: Option<Mamba3Cache>,
1398        ) -> (Tensor<2>, Mamba3Cache) {
1399            let [batch, _d_model] = input_bd.dims();
1400            let nheads = self.nheads();
1401            let ngroups = self.ngroups;
1402            let _per_head_dim = self.per_head_dim();
1403            let _state_rank = self.state_rank;
1404            let _num_rope_angles = self.num_rope_angles;
1405            let _mimo_rank = self.mimo_rank;
1406            let device = input_bd.device();
1407
1408            assert_eq!(nheads % ngroups, 0);
1409            san(&input_bd);
1410
1411            // ── Initialise cache if not provided ──────────────────────────────────
1412            // Implies single-ssd pathway if missing (double-ssd for Quaternion4D).
1413            let cache = cache.unwrap_or_else(|| self.zero_cache(batch, &device));
1414
1415            // ── SSD Pathway Selection ─────────────────────────────────────────────
1416            match cache {
1417                Mamba3Cache::DoubleSsd(cache) => {
1418                    let (out_bsm, cache) = self.step_double_ssd(input_bd, Some(cache));
1419                    (out_bsm, cache.into())
1420                }
1421                Mamba3Cache::SingleSsd(cache) => {
1422                    let (out_bsm, cache) = self.step_single_ssd(input_bd, Some(cache));
1423                    (out_bsm, cache.into())
1424                }
1425            }
1426        }
1427    }
