1//! # Mamba-3 SSM Block — Exponential-Trapezoidal SSD with Data-Dependent RoPE
2//!
3//! This module implements the core **Mamba-3 layer** from the paper
4//! *"Mamba-3: Improved Sequence Modeling using State Space Principles"*.
5//!
6//! Mamba-3 adds three independent extensions to the Mamba-2 SSD recurrence:
7//! (1) trapezoidal discretisation, (2) a **complex-valued state transition**,
8//! implemented as data-dependent rotary embeddings on B and C (the "RoPE
9//! trick"), and (3) MIMO (multiple-input multiple-output) projection.
10//! Each is shown in isolation below, then combined.
11//!
12//! ## 1. Trapezoidal recurrence (SISO, no RoPE, no MIMO — Proposition 1)
13//!
14//! ```text
15//!   hₜ = αₜ hₜ₋₁ + βₜ Bₜ₋₁ xₜ₋₁ᵀ + γₜ Bₜ xₜᵀ   (state update)
16//!   yₜ = Cₜᵀ hₜ + D xₜ                          (output)
17//! ```
18//!
19//! where the trapezoidal coefficients are
20//!
21//! ```text
22//!   αₜ = exp(Δₜ Aₜ)                — decay (Aₜ < 0, data-dependent)
23//!   βₜ = (1 − λₜ) Δₜ αₜ            — left-endpoint weight (Bₜ₋₁ xₜ₋₁ contribution)
24//!   γₜ = λₜ Δₜ                      — right-endpoint weight (Bₜ xₜ contribution)
25//! ```
26//!
27//! with `λₜ = σ(λ̂ₜ) ∈ (0, 1)` controlling the left/right split of the trapezoid.
28//! Setting `λ ≡ 1` collapses this to the Mamba-2 (Euler / right-endpoint) form.
29//!
30//! *Which* earlier sample the `βₜ` tap reads is [`Mamba3Config::trapezoid`]; at
31//! `micro_steps = 1` (below) `t−1` is the only answer. At `u > 1` the default
32//! [`Trapezoid::HorizontalCarryOver`] keeps reading the immediately preceding
33//! recurrence step, and [`Trapezoid::Vertical`] reads the previous **token**'s
34//! same micro-step instead — one lag, everywhere the tap appears. Two members
35//! read **both**, splitting `(1 − λₜ)Δₜ` between them by a second projected
36//! scalar `μₜ = σ(μ̂ₜ)`; one gates its lag-1 tap to within a token. The tap and
37//! its mass are one choice: a closed tap hands its share back (to the other tap,
38//! or to `γ`), so the step's mass is `Δₜ` under every member. See
39//! [`Trapezoid`]'s header.
40//!
41//! ## 2. Complex transition, a.k.a. "data-dependent RoPE" (no trapezoid, no MIMO
42//! — paper section *Complex-Valued SSMs*)
43//!
44//! Despite the name this is **not a positional encoding**: it is the *imaginary
45//! part of the state transition*. Mamba-3's `A` is complex (`A + iϑ`), and under
46//! discretisation a complex SSM of state `N/2` is exactly a real SSM of state `N`
47//! whose transition is the scalar decay `α` times a block-diagonal of `2×2`
48//! rotations (paper Prop. *Complex-to-Real SSM Equivalence*):
49//!
50//! ```text
51//!   ρₜ = R(Δₜ · ϱ · π · tanh(ϑₜ)) ∈ SO(2)^{N/2}  — per-step rotation (data-dependent)
52//!   hₜ = αₜ ρₜ hₜ₋₁ + Δₜ Bₜ xₜᵀ                   — rotational state update
53//! ```
54//!
55//! `ϱ` is [`Mamba3Config::rotation_range`], the per-step bound in half-turns per
56//! unit `Δ`: `2` here (a whole turn of the group per unit `Δ`), `1` in the
57//! reference. It is a gradient budget, not a reach limit — see its own docs.
58//!
59//! The **exponential** discretisation is load-bearing here, not merely more
60//! accurate than forward Euler: `|exp(iΔϑ)| = 1` exactly, so the transition is
61//! orthogonal and a tracked rotation neither decays nor grows, where Euler's
62//! `|1 + iΔϑ| > 1` spirals outward (`info/mamba-3/rotation-as-optimization.md` §9.5).
63//!
64//! `αₜ` is a scalar (so it commutes with `ρₜ`) and each `ρₜ` is orthogonal, so
65//! the *cumulative* rotation telescopes out of the recurrence and can be absorbed
66//! into B/C instead — the **"RoPE trick"** (paper Prop. *Complex SSM,
67//! Data-Dependent RoPE Equivalence*). That is the form implemented here: the
68//! rotation never touches the state (the cached `h` is the rotated-frame one) and
69//! the SSD core stays the plain scalar-decay kernel.
70//!
71//! ```text
72//!   θₜ = θₜ₋₁ + Δₜ · ϱ · π · tanh(ϑₜ)    — cumulative angles (per-pair)
73//!   Rₜ = R(θₜ) = ρₜ ⋯ ρ₁ ∈ SO(2)^{N/2}   — block-diagonal cumulative rotation
74//!   B̃ₜ = Rₜ Bₜ,   C̃ₜ = Rₜ Cₜ              — rotated state-space projections
75//! ```
76//!
77//! The standard recurrence then runs with `B̃ₜ`/`C̃ₜ` in place of `Bₜ`/`Cₜ`:
78//!
79//! ```text
80//!   hₜ = Āₜ hₜ₋₁ + B̄̃ₜ xₜᵀ                (scalar-decay state update)
81//!   yₜ = C̃ₜᵀ hₜ + D xₜ                   (output)
82//! ```
83//!
84//! Orthogonality makes the readout-vs-input similarity depend only on the
85//! rotation *accumulated between* the two steps:
86//!
87//! ```text
88//!   C̃ᵢᵀ B̃ⱼ = (Rᵢ Cᵢ)ᵀ (Rⱼ Bⱼ) = Cᵢᵀ R(θⱼ − θᵢ) Bⱼ
89//! ```
90//!
91//! `θⱼ − θᵢ` is not a position: it is `Σ Δ·ϱ·π·tanh(ϑ)` over the intervening
92//! steps — how far the transition itself rotated, driven by the inputs. It would
93//! reduce to vanilla RoPE's relative position only in the degenerate case of an
94//! input-independent, constant per-step angle (`θⱼ − θᵢ = (j−i)·θ`). Data
95//! dependence is the whole point: it gives the layer rotational state dynamics,
96//! hence state-tracking (parity, mod-k) that a real, non-negative-eigenvalue SSM
97//! provably cannot express. See [`crate::mamba3::rotation`], whose `Quaternion4D`
98//! carries the same argument to a non-abelian rotation group.
99//!
100//! ## 3. MIMO Extension (no trapezoid coefficients, no RoPE — `mimo_rank = M > 1`)
101//!
102//! With MIMO, B/C carry M parallel rank channels and the state update is a sum
103//! of M outer-product contributions; the readout produces M outputs which are
104//! gated and combined back:
105//!
106//! ```text
107//!   hₜ = Āₜ hₜ₋₁ + Σₘ B̄ₜ[m] ⊗ (xₜ ⊙ mimo_x[m])                  (state update)
108//!   yₜ[m] = Cₜ[m]ᵀ hₜ + D · (xₜ ⊙ mimo_x[m])                    (per-rank output)
109//!   outₜ  = Σₘ mimo_o[m] ⊙ silu(zₜ ⊙ mimo_z[m]) ⊙ yₜ[m]         (rank merge)
110//! ```
111//!
112//! The hidden state hₜ is shared across ranks; each rank contributes to it
113//! independently but reads the full shared state when producing its output.
114//!
115//! ## 4. Combined formulation (everything together)
116//!
117//! Putting trapezoid + RoPE + MIMO into a single expression — `B̃ₜ[m] = Rₜ Bₜ[m]`
118//! and `C̃ₜ[m] = Rₜ Cₜ[m]` denote the RoPE-rotated MIMO projections, and the `β`
119//! tap is written at the default member's lag 1 (§1: it reads `t−l` for that
120//! member's own `l`, and a two-tap member adds a second such term):
121//!
122//! ```text
123//!   hₜ = αₜ hₜ₋₁
124//!      + βₜ Σₘ B̃ₜ₋₁[m] ⊗ (xₜ₋₁ ⊙ mimo_x[m])
125//!      + γₜ Σₘ B̃ₜ[m]   ⊗ (xₜ   ⊙ mimo_x[m])
126//!
127//!   yₜ[m] = C̃ₜ[m]ᵀ hₜ + D · (xₜ ⊙ mimo_x[m])
128//!   outₜ  = Σₘ mimo_o[m] ⊙ silu(zₜ ⊙ mimo_z[m]) ⊙ yₜ[m]
129//! ```
130//!
131//! ## 5. MambaProduct (`micro_steps = u > 1`)
132//!
133//! A fourth, independent dial (DeltaProduct's dial, not its mechanism — see
134//! [`crate::mamba3::product`] and `info/mamba-3/rotation-as-optimization.md`): `u`
135//! recurrence micro-steps per token, each a full step of the above with its own
136//! projected `x`, `B`, `Δ`, `A`, `λ` and rotation. One *token*'s transition is
137//! then the **product**
138//!
139//! ```text
140//!   Mₜ = (∏ⱼ αₜ,ⱼ) · Rₜ,ᵤ ⋯ Rₜ,₁
141//! ```
142//!
143//! and its write a sum of `u` outer products staggered along it; the read `C`,
144//! the gate `z` and the `D` skip stay per token. It is evaluated by folding the
145//! micro-steps into the sequence axis, so nothing below this line changes. See
146//! [`crate::mamba3::product`] for what `u` buys per
147//! [`RotationKind`] — the answer is very
148//! different for the abelian and non-abelian ones.
149//!
150//! Implementation note: the trapezoidal recurrence (in the double-ssd pathway)
151//! is computed by splitting it into a γ-SSD (the current sample) and one β-SSD
152//! per tap, at that tap's own lag; see
153//! [`crate::mamba3::double_ssd::ssd::ssd_path`]. The single-ssd pathway does the
154//! same work in one call. The rotation is applied to B and C before the SSD
155//! calls, through the one entry point
156//! [`rotate_bc_forward`](crate::mamba3::rotation::rotate_bc_forward) (which is
157//! [`apply_rope`](crate::mamba3::rotation::rope::apply_rope) for the abelian
158//! kind and a quaternion scan for the others), and MIMO expansion happens by
159//! augmenting the V tensor with the per-rank `mimo_x` projection.
160//!
161//! See also: [`crate::mamba3::double_ssd::double_ssd`] and [`crate::mamba3::single_ssd::single_ssd`].
162//!
163//! ## Notation / Dimension Keys
164//!
165//! Throughout all Mamba-3 files, tensor names carry a suffix representing their shape.
166//! The letters used differ from the reference paper and the python implementation.
167//! The "Paper" column gives the symbol from the Mamba-3 paper; the "Python" column
168//! gives the field/variable name in the reference implementation
169//! (`../py/state-spaces/mamba/mamba_ssm/modules/mamba3.py`).
170//!
171//! | Letter | Dimension | Paper | Python | Typical value |
172//! |--------|-----------|-------|--------|---------------|
173//! | `b`    | `batch` | — | `batch` | varies |
174//! | `s`    | `sequence` length, **folded** = `tokens · u` | `T` | `seqlen` | varies |
175//! | `t`    | `tokens` = `s`/`u` — the [read axis](crate::mamba3::product) | `T` | `seqlen` | varies |
176//! | `u`    | `micro_steps` (MambaProduct) | — | — | 1 (stock) |
177//! | `d`    | `d_model` | `D` | `d_model` | 768, 1024 |
178//! | `i`    | `d_inner` = `expand`·`d_model` | `E·D` | `d_inner` | 2·`d_model` |
179//! | `h`    | `nheads` | `H` | `nheads` | `d_inner` / `per_head_dim` |
180//! | `p`    | `per_head_dim` | `P` | `headdim` | 64, 128 |

182//! | `m`    | `mimo_rank` | `M` | `mimo_rank` | 1, .., 8 |

187//!
188//! Uppercase letters represent a relation (e.g. offset, multiple, concat, stacking)

209/// The Mamba-3 SSM block.
210///
211/// Implements the full Mamba-3 layer with exponential-trapezoidal discretization
212/// and data-dependent RoPE.  Supports SISO (mimo_rank=1) and MIMO (mimo_rank>1).
213/// Supports two execution modes:
214///
215/// - [`Self::forward`] — chunkwise double-SSD algorithm for training / prefill
216/// - [`Self::step`]    — recurrent form for token-by-token decoding
217#[derive(Module, Debug)]
218pub struct Mamba3 {
219    /// Input projection; width [`Mamba3Config::d_in_proj`].
220    ///
221    /// Output splits, with `u` = [`Self::micro_steps`]:
222    /// `[z | x·u | B_raw·u | C_raw | dd_dt·u | dd_A·u | lambda_raw·u | mu_raw·u
223    /// | rotation·u | noise·u | tropical_a·u | tropical_b·u]`
224    ///
225    /// The segments from `lambda_raw` on are optional and trail for that
226    /// reason: [`Trapezoid::None`] projects no `lambda_raw`, a one-tap pattern
227    /// no `mu_raw`, [`RotationKind::Real1D`] no `rotation`, every [`Gain`] but
228    /// [`Gain::KalmanProjectedNoise`] no `noise`, and [`Tropical::None`] no
229    /// `tropical_*`.
230    ///
231    /// Every **per-micro-step** stream is projected `u` times over and folded
232    /// into the sequence by [`crate::mamba3::product`]; the gate `z` and the
233    /// read `C` are per token. At the default `u = 1` this is the stock
234    /// `d_model → 2·d_inner + 2·ngroups·state_rank·mimo_rank + 3·nheads
235    /// + num_rotation_channels`.
236    ///
237    /// Under [`Mamba3Untied::InProjTail`] it stops at `C_raw`, the rest living in
238    /// [`Self::in_proj_tail`]; [`Self::project_in`] reads the two as one.
239    pub in_proj: Linear,
240
241    /// `in_proj`'s trailing per-micro-step segments
242    /// `[dd_dt·u | dd_A·u | lambda_raw·u | mu_raw·u | rotation·u | noise·u |
243    /// tropical_a·u | tropical_b·u]`, split off when
244    /// [`Mamba3Untied::InProjTail`] unties them: one copy per application, along
245    /// the output axis. `None` ⇒ `in_proj` carries them.
246    pub in_proj_tail: Option<Linear>,
247
248    /// Per-head bias for the discretisation step size Δ.
249    /// Shape: `[nheads]`
250    pub dt_bias_h: Param<Tensor<1>>,
251
252    /// Hard clamp applied to Δ after softplus.
253    pub dt_limit: (f64, f64),
254
255    /// Minimum absolute value of A: `A ∈ (−∞, −a_floor]`.
256    pub a_floor: f64,
257
258    /// Per-head skip (D) coefficient.
259    /// Shape: `[nheads]`; initialised to ones.
260    pub d_h: Param<Tensor<1>>,
261
262    /// RMSNorm applied to the B projection (QK-Norm, no gating).
263    /// Normalises over the `state_rank` dimension.
264    pub b_norm: RmsNorm,
265
266    /// RMSNorm applied to the C projection (QK-Norm, no gating).
267    /// Normalises over the `state_rank` dimension.
268    pub c_norm: RmsNorm,
269
270    /// Learnable per-head, per-rank bias for B, added after QK-norm.
271    /// Shape: `[nheads, mimo_rank, state_rank]`; initialised to ones.
272    pub b_bias_hmr: Param<Tensor<3>>,
273
274    /// Learnable per-head, per-rank bias for C, added after QK-norm.
275    /// Shape: `[nheads, mimo_rank, state_rank]`; initialised to ones.
276    pub c_bias_hmr: Param<Tensor<3>>,
277
278    /// MIMO up-projection for x (values).
279    /// Shape: `[nheads, mimo_rank, per_head_dim]`.
280    /// Only present when `mimo_rank > 1`.  When SISO, this is `None`.
281    pub mimo_x_hmp: Option<Param<Tensor<3>>>,

288    /// MIMO down-projection for the output.
289    /// Shape: `[nheads, mimo_rank, per_head_dim]`.
290    /// Only present when `mimo_rank > 1`. When SISO, this is `None`.
291    pub mimo_o_hmp: Option<Param<Tensor<3>>>,
292
293    /// Optional gated RMSNorm applied before the output projection.
294    ///
295    /// When `Some`, the SiLU gate at the block tail is replaced by
296    /// `RmsNormGated(y, z)` which normalises `y` over `per_head_dim` and
297    /// gates with `SiLU(z)`. Created when `has_outproj_norm = true`.
298    pub out_norm: Option<RmsNormGated>,
299
300    /// Output projection: maps `d_inner → d_model`.
301    pub out_proj: Linear,
302
303    /// Optional learnable initial hidden state `h₀`.
304    /// Shape: `[nheads, per_head_dim, state_rank]`
305    pub init_state_hpr: Option<Param<Tensor<3>>>,

307    /// `ln κₕ`, the Kalman gate's per-head noise scale (`qₜ = κₕ·Δₜ`; see
308    /// [`crate::mamba3::positive`]). `−∞` is the stock block.
309    /// Shape: `[nheads]`. `None` under [`Gain::Projected`].
310    ///
311    /// Held in logs, not as `softplus` of a raw parameter: `κ` is a scale on
312    /// `q` spanning decades (a gap's doubt against a value's), and an AdamW
313    /// step in `ln κ` is a relative change at every one of them. The price is
314    /// where the stock join sits — at `ln κ = −∞`, a limit training
315    /// approaches but never lands on, with `∂/∂ln κ ∝ κ` fading on the way.

317    /// exact only by assignment, which is how the tests reach it.
318    pub kalman_log_kappa_h: Option<Param<Tensor<1>>>,
319

322    /// information `η`. Shape: `[nheads]`. `None` under [`Gain::Projected`].
323    ///
324    /// Kept under `has_outproj_norm` too: the scale meets the SSD's readout
325    /// before the `D` skip and the register's `c·e` are added, so the per-head
326    /// norm cannot divide it out — `ω` sets the SSD's share against theirs.
327    pub kalman_read_h: Option<Param<Tensor<1>>>,
328

330    /// Shape: `[nheads, per_head_dim]`; initialised to zeros. `None` under
331    /// [`Tropical::None`].
332    pub tropical_readout_hp: Option<Param<Tensor<2>>>,
333
334    /// State rank — the latent dimension of the SSM hidden state.
335    ///
336    /// Paper: `N`. Python: `d_state`.
337    pub state_rank: usize,
338
339    /// Number of B/C groups. Must divide `nheads`.
340    ///
341    /// Paper: `G`. Python: `num_bc_heads`.
342    pub ngroups: usize,
343
344    /// Number of RoPE angle pairs (`rope_dim / 2`).

447    /// Number of quaternion blocks the rotation projection and its cumulative
448    /// scan run over: `num_quat_blocks · quat_factors` — twice the state's

452        self.num_quat_blocks * self.rotation.quat_factors()
453    }

455    /// Width of the in-projection's trailing rotation segment: the per-step
456    /// [`Self::num_rotation_channels`] once per micro-step, since each
457    /// micro-step turns the state by a rotation of its own.
458    pub fn rotation_channels_total(&self) -> usize {
459        self.micro_steps * self.num_rotation_channels
460    }

462    /// Width of the in-projection's `λ` segment — one channel per (head,
463    /// micro-step), or **`0`** under [`Trapezoid::None`], which has no `λ` to
464    /// project. Peeled off the tail by `helpers::split_trailing`, immediately
465    /// inside the rotation segment.
466    pub fn lambda_channels_total(&self) -> usize {
467        if self.trapezoid.has_beta_tap() {
468            self.micro_steps * self.nheads()
469        } else {
470            0
471        }
472    }

474    /// Width of the in-projection's `μ` segment — the second tap's mix, one
475    /// channel per (head, micro-step) for the two-tap patterns and **`0`** for
476    /// every other, including a two-tap one at `u = 1`, where the taps fold
477    /// ([`Trapezoid::has_interior_tap`]). Peeled off the tail by
478    /// `helpers::split_trailing`, immediately inside the `λ` segment.
479    pub fn mu_channels_total(&self) -> usize {
480        if self.trapezoid.has_interior_tap(self.micro_steps) {
481            self.micro_steps * self.nheads()
482        } else {
483            0
484        }
485    }

487    /// Width of the in-projection's Kalman noise segment `r` — one channel per
488    /// (head, micro-step) under [`Gain::KalmanProjectedNoise`], **`0`** for
489    /// every other gain. Peeled off the tail by `helpers::split_trailing`,
490    /// immediately inside the tropical segments.
491    pub fn noise_channels_total(&self) -> usize {
492        if self.gain.projects_noise() {
493            self.micro_steps * self.nheads()
494        } else {
495            0
496        }
497    }

499    /// Width of the in-projection's tropical segments `(a, b)` — two channels
500    /// per (head, micro-step) under [`Tropical::MaxPlus`], **`0`** otherwise.
501    /// The outermost trailing segment, so peeled off first.
502    pub fn tropical_channels_total(&self) -> usize {
503        if self.tropical.is_on() {
504            2 * self.micro_steps * self.nheads()
505        } else {
506            0
507        }
508    }

510    /// Peel the positive systems' trailing segments off an in-projection whose
511    /// channel axis is `dim`: `(rest, noise, tropical (a, b))`, each `None`
512    /// when the block projects it not. The two tropical halves come back
513    /// still `u`-wide, `a` first.
514    #[allow(clippy::type_complexity)]
515    pub(crate) fn split_positive<const D: usize>(
516        &self,
517        proj: Tensor<D>,
518        dim: usize,
519    ) -> (Tensor<D>, Option<Tensor<D>>, Option<(Tensor<D>, Tensor<D>)>) {
520        let (proj, tropical) = crate::mamba3::helpers::split_trailing(
521            proj,
522            self.tropical_channels_total(),
523            dim,
524        );
525        let (proj, noise) =
526            crate::mamba3::helpers::split_trailing(proj, self.noise_channels_total(), dim);
527        let tropical = tropical.map(|ab| {
528            let half = ab.dims()[dim] / 2;
529            (ab.clone().narrow(dim, 0, half), ab.narrow(dim, half, half))
530        });
531        (proj, noise, tropical)
532    }

539    ///   [`Gain::KalmanProjectedNoise`]
540    /// - `carry_bh`  : `[batch, nheads]`

555    /// `[batch, nheads]` at [`LOG_ZERO`](crate::mamba3::positive::LOG_ZERO)

566    /// The positive systems' tail, shared by both pathways' `forward` and by
567    /// `step` (whose folded run is one token's `u` micro-steps): the register's
568    /// scan, each system's carry for the next call (its run's last position),
569    /// and the two readout ports at the read rows ([`Self::positive_read`]).
570    ///
571    /// Returns `(y, ln Λ carry, c carry)`.
572    ///
573    /// # Shapes
574    /// - `y_btmhp`           : `[batch, tokens, mimo_rank, nheads, per_head_dim]`
575    /// - `log_precision_bsh` : `[batch, tokens·u, nheads]`, from the discretisation
576    /// - `tropical_ab_bsh`   : the register's `(a, b)`, each `[batch, tokens·u, nheads]`
577    /// - `tropical_carry_bh` : the cache's `c`, `[batch, nheads]`
578    #[allow(clippy::type_complexity)]
579    pub(crate) fn positive_tail(
580        &self,
581        y_btmhp: Tensor<5>,
582        log_precision_bsh: Option<Tensor<3>>,
583        tropical_ab_bsh: Option<(Tensor<3>, Tensor<3>)>,
584        tropical_carry_bh: Option<Tensor<2>>,
585    ) -> (Tensor<5>, Option<Tensor<2>>, Option<Tensor<2>>) {
586        let u = self.micro_steps;
587        let tropical_bsh = tropical_ab_bsh.map(|(a_bsh, b_bsh)| {
588            let carry_bh = tropical_carry_bh.expect("a tropical register keeps its cache slot");
589            crate::mamba3::positive::tropical::register(a_bsh, b_bsh, carry_bh)
590        });
591        let last_bh = |t_bsh: &Tensor<3>| {
592            let len = t_bsh.dims()[1];
593            t_bsh.clone().narrow(1, len - 1, 1).squeeze_dim::<2>(1)
594        };
595        let log_precision_bh = log_precision_bsh.as_ref().map(last_bh);
596        let tropical_bh = tropical_bsh.as_ref().map(last_bh);
597        let read_rows = |t_bsh: Tensor<3>| crate::mamba3::helpers::read_rows::<3, 4>(t_bsh, 1, u);
598        let y_btmhp = self.positive_read(
599            y_btmhp,
600            log_precision_bsh.map(read_rows),
601            tropical_bsh.map(read_rows),
602        );
603        (y_btmhp, log_precision_bh, tropical_bh)
604    }

606    /// The positive systems' two readout ports, on the SSD's readout — before
607    /// the `D` skip, the gate and the rank merge:
608    ///
609    /// - `C`: `y ← y·(Λ + ε)^(−ω)` when the block has [`Self::kalman_read_h`];
610    /// - `D`: `y ← y + c·e` when it has [`Self::tropical_readout_hp`].
611    ///
612    /// Both are broadcast over the mimo ranks, which share the state.
613    ///
614    /// # Shapes
615    /// - `y_btmhp`            : `[batch, tokens, mimo_rank, nheads, per_head_dim]`
616    /// - `log_precision_bth`  : `[batch, tokens, nheads]`, `ln Λ` at the read rows
617    /// - `tropical_bth`       : `[batch, tokens, nheads]`, `c` at the read rows
618    pub(crate) fn positive_read(
619        &self,
620        y_btmhp: Tensor<5>,
621        log_precision_bth: Option<Tensor<3>>,
622        tropical_bth: Option<Tensor<3>>,
623    ) -> Tensor<5> {
624        let y_btmhp = match (&self.kalman_read_h, log_precision_bth) {
625            (Some(omega_h), Some(log_precision_bth)) => {
626                const LN_EPS: f32 = -13.815511; // ln 1e-6
627                let ln_lambda_bth = crate::mamba3::positive::scan::lse(
628                    log_precision_bth.clone(),
629                    log_precision_bth.full_like(LN_EPS),
630                );
631                let scale_bth = (-(ln_lambda_bth * omega_h.val().unsqueeze::<3>())).exp();
632                y_btmhp * scale_bth.unsqueeze_dims::<5>(&[2, 4])
633            }
634            _ => y_btmhp,
635        };
636        match (&self.tropical_readout_hp, tropical_bth) {
637            (Some(e_hp), Some(c_bth)) => {
638                y_btmhp + c_bth.unsqueeze_dims::<5>(&[2, 4]) * e_hp.val().unsqueeze::<5>()
639            }
640            _ => y_btmhp,
641        }
642    }

714                    Mamba3Untied::CBias => vec![axis0_hmx(&self.c_bias_hmr)],
715                    Mamba3Untied::MimoX => self.mimo_x_hmp.iter().map(axis0_hmx).collect(),
716                    Mamba3Untied::MimoZ => self.mimo_z_hmp.iter().map(axis0_hmx).collect(),
717                    Mamba3Untied::MimoO => self.mimo_o_hmp.iter().map(axis0_hmx).collect(),
718                    Mamba3Untied::OutNorm => self.out_norm.iter().map(|n| axis0(&n.gamma)).collect(),
719                    Mamba3Untied::InitState => self.init_state_hpr.iter().map(axis0_hmx).collect(),

723                        .tropical_readout_hp
724                        .iter()
725                        .map(|p| UntiedParam::new(p, 0))
726                        .collect(),
727                }
728            })
729            .collect()
730    }

849    /// previous step" may mean the previous micro-step or the previous token;

915    /// Fraction of `state_rank` the transition rotation turns (must be `0.5`
916    /// or `1.0`).
917    ///

934    /// [`Rotor4D`](RotationKind::Rotor4D) it is also what keeps the smallest
935    /// legal `state_rank` (4 — a single quaternion block) usable, since a
936    /// partial quaternion rotation must land on whole 4-blocks.
937    #[config(default = 1.0)]
938    pub rope_fraction: f64,

940    /// Whether to apply a gated RMSNorm before the output projection.
941    ///
942    /// When `true`, the SiLU gate at the end of the block is replaced by a
943    /// per-head [`RmsNormGated`] (group size = `per_head_dim`) which both
944    /// normalises `y` and gates it with `SiLU(z)`. Matches the reference's
945    /// `is_outproj_norm` argument in `mamba3.py`.
946    #[config(default = false)]
947    pub has_outproj_norm: bool,

949    /// Which rotational-state algebra to use for the data-dependent rotation
950    /// carried by the state transition and absorbed into `B`/`C` (see
951    /// [`RotationKind`]).
952    ///
953    /// Defaults to the abelian [`Complex2D`](RotationKind::Complex2D) — the
954    /// current Mamba-3 RoPE — for which the block is byte-for-byte unchanged.
955    /// [`Quaternion4D`](RotationKind::Quaternion4D) selects the non-abelian
956    /// quaternion rotation; its in-projection devotes
957    /// `nheads · 3 · num_quat_blocks` channels to per-head quaternion
958    /// generators in place of the shared `num_rope_angles` angle channels (see
959    /// [`Self::num_rotation_channels`]). [`Rotor4D`](RotationKind::Rotor4D)
960    /// selects the full `SO(4)` rotation of each 4-block and doubles that
961    /// channel count (a left and a right generator per head and block).
962    /// [`Real1D`](RotationKind::Real1D) removes the rotation altogether — no
963    /// channels, no accumulator, a real transition.
964    #[config(default = "crate::mamba3::rotation::RotationKind::Complex2D")]
965    pub rotation: RotationKind,
966
967    /// How far a single step may rotate the state, in **half-turns per unit
968    /// `Δ`**: the per-step angle is bounded by `rotation_range · π · Δ`.
969    ///
970    /// The default of `2.0` is "one unit of `Δ` may traverse the whole rotation
971    /// group once", which means the same thing for both kinds even though their
972    /// periods differ:
973    ///
974    /// - [`Complex2D`](RotationKind::Complex2D): `2π` is a full turn of
975    ///   `SO(2)`.
976    /// - [`Quaternion4D`](RotationKind::Quaternion4D): `2π` reaches every
977    ///   element of `SU(2)`, whose period is `4π` — `q` and `−q` are the two
978    ///   lifts of one `SO(3)` rotation and turn the state differently.
979    /// - [`Rotor4D`](RotationKind::Rotor4D): the bound applies to **each
980    ///   factor**, so at the default each of `q` and `p` independently sweeps
981    ///   all of `SU(2)` and the pair reaches every element of
982    ///   `SO(4) ≅ (SU(2)×SU(2))/±1`. Bounding the composite instead (halving
983    ///   the per-factor angle) would cost reach for nothing: the two plane
984    ///   angles `a∓b` are periodic in `2π` anyway.
985    ///
986    /// What the bound buys is not reach but **gradients**. A rotation of exactly
987    /// `range·π` sits at `tanh`'s asymptote, where the gradient is not merely
988    /// small but **exactly zero** in f32 (`tanh(10) == 1.0`). Half-turns are
989    /// what state-tracking wants, so at `range = 1` — where `π` *is* the
990    /// bound — the most useful rotation is the one the optimiser can never
991    /// reach. At `2.0` it sits at `tanh = 1/2`, in the interior.
992    ///
993    /// `1.0` is the reference implementation's abelian bound (`Δ·π·tanh(ϑ)`);
994    /// set it explicitly to reproduce that model. Ignored by
995    /// [`Real1D`](RotationKind::Real1D), which never turns.
996    #[config(default = 2.0)]
997    pub rotation_range: f64,
998
999    /// Whether to use the specialized `mimo_rank == 1` (SISO) **chunkwise**
1000    /// kernel: the same-step γ-correction
1001    /// ([`y_diag_correction`](crate::mamba3::single_ssd::ssd::diag::y_diag_correction)),
1002    /// forward *and* its analytic backward.
1003    ///
1004    /// At `mimo_rank == 1` the `m × m` Gram is a scalar, so the general form
1005    /// issues a `1×r×1` and a `1×1×p` GEMM per `(batch, nchunks, chunk_len,
1006    /// nheads)` — thousands of degenerate products. The SISO branch replaces all
1007    /// of them with one elementwise multiply and a `state_rank` reduction over
1008    /// the whole tensor, which is why deleting the tiny GEMMs helps everywhere:
1009    /// ≈ neutral to ~9 % faster across the backends in `bench.md`. Leave it on.
1010    ///
1011    /// **Values and gradients are identical either way** — this only selects the
1012    /// op mix. Ignored when `mimo_rank > 1`, where only the general branch
1013    /// applies. See also [`Self::siso_specialization_decode`], the per-token
1014    /// counterpart, whose trade-off is *not* the same.
1015    #[config(default = true)]
1016    pub siso_specialization: bool,
1017
1018    /// Whether to use the specialized `mimo_rank == 1` (SISO) **per-token**
1019    /// kernels: the decode state update and readout
1020    /// (`helpers::mimo_outer_sum`, `Mamba3::step_readout`) and the single-SSD
1021    /// boundary-β seed.
1022    ///
1023    /// **Set this to `false` on the CPU backends.** Unlike the chunkwise flag,
1024    /// this one replaces a *single, already efficient* batched matmul with a
1025    /// broadcast multiply, so the verdict flips with the backend: at
1026    /// `benches/layer.rs`'s default size the `step` group is ~12 % faster on CUDA
1027    /// and about **3× slower on flex**, whose broadcast-elementwise path trails
1028    /// its matmul by more than an order of magnitude at these shapes. The default
1029    /// (`true`) suits the GPU backends; a CPU deployment that decodes should turn
1030    /// it off — and can do so while keeping [`Self::siso_specialization`] on,
1031    /// which is the point of having two flags.
1032    ///
1033    /// **Values and gradients are identical either way.** Ignored when
1034    /// `mimo_rank > 1`.
1035    #[config(default = true)]
1036    pub siso_specialization_decode: bool,
1037
1038    /// The parameters held once per application of the block's real layer
1039    /// instead of tied across them ([`Mamba3Untied`]); only virtual layers give
1040    /// a real layer more than one. Each must exist in this config. The layout
1041    /// follows the list alone — [`Mamba3Untied::InProjTail`] splits `in_proj` at
1042    /// any count — so every real layer of a stack has the one Muon plan. See
1043    /// [`burn_stack::utils::untied`].
1044    #[config(default = "Vec::new()")]
1045    pub untied: Vec<Mamba3Untied>,
1046}

1058    /// Effective RoPE dimension: the number of B/C channels actually rotated.
1059    /// `state_rank` for full RoPE (`rope_fraction = 1.0`), `state_rank / 2` for
1060    /// `rope_fraction = 0.5` — and `0` for [`RotationKind::Real1D`], which
1061    /// rotates nothing at all.
1062    pub fn rope_dim(&self) -> usize {
1063        if self.rotation == RotationKind::Real1D {
1064            return 0;
1065        }
1066        let mut d = (self.state_rank as f64 * self.rope_fraction) as usize;
1067        if !d.is_multiple_of(2) {
1068            d -= 1;
1069        }
1070        d

1073    /// Number of RoPE rotation angles projected per head: `rope_dim / 2` (`0`
1074    /// for [`RotationKind::Real1D`]). `init` asserts every rotating kind turns
1075    /// at least one pair, so this is `> 0` wherever it is read.
1076    pub fn num_rope_angles(&self) -> usize {
1077        self.rope_dim() / 2
1078    }
1079
1080    /// Number of **state** quaternion blocks for the quaternion kinds:
1081    /// `rope_dim / 4`, which `init` asserts is a whole number (and non-zero)
1082    /// for them. `0` for [`RotationKind::Real1D`]; meaningless, and unread, for
1083    /// [`RotationKind::Complex2D`].
1084    pub fn num_quat_blocks(&self) -> usize {
1085        self.rope_dim() / 4
1086    }

1088    /// Number of in-projection channels devoted to the rotation parameters,
1089    /// per the configured [`RotationKind`]:
1090    ///
1091    /// - [`Real1D`](RotationKind::Real1D): none — the trailing `in_proj`
1092    ///   segment is absent, not zero-width (Burn has no zero-width tensors).
1093    /// - [`Complex2D`](RotationKind::Complex2D): `num_rope_angles` angle
1094    ///   channels, shared across heads and scaled per-head by `Δ`, as in the
1095    ///   reference.
1096    /// - [`Quaternion4D`](RotationKind::Quaternion4D) /
1097    ///   [`Rotor4D`](RotationKind::Rotor4D):
1098    ///   `nheads · 3 · num_rotation_blocks` quaternion-generator channels — an
1099    ///   axis·angle generator **per head** and block (and, for `Rotor4D`, per
1100    ///   *factor*: one generator for the left quaternion and one for the
1101    ///   right), fed through
1102    ///   [`quat_from_scaled_axis`](crate::mamba3::rotation::quat_from_scaled_axis).
1103    ///   For a non-abelian transition the axis is where the expressiveness
1104    ///   lives: heads sharing one axis and differing only in `Δ` track one word
1105    ///   at different speeds instead of different words. See
1106    ///   [`generator_increment`](crate::mamba3::rotation::generator_increment).
1107    pub fn num_rotation_channels(&self) -> usize {
1108        match self.rotation {
1109            // A real transition has no rotation to parameterise.
1110            RotationKind::Real1D => 0,
1111            RotationKind::Complex2D => self.num_rope_angles(),
1112            // Three generator channels per (head, block) and **per factor**:
1113            // one factor for Quaternion4D, two for Rotor4D.
1114            RotationKind::Quaternion4D | RotationKind::Rotor4D => {
1115                self.nheads() * 3 * self.num_rotation_blocks()
1116            }
1117        }
1118    }
1119
1120    /// Number of quaternion blocks the *rotation projection and scan* run over:
1121    /// [`Self::num_quat_blocks`] times [`RotationKind::quat_factors`] — i.e.
1122    /// `2 · blocks` for [`RotationKind::Rotor4D`], whose left and right factors
1123    /// share one stacked block axis.
1124    pub fn num_rotation_blocks(&self) -> usize {
1125        self.num_quat_blocks() * self.rotation.quat_factors()
1126    }

1128    /// Total input projection output size.
1129    ///
1130    /// ```text
1131    ///   [ z | x·u | B·u | C | Δ·u | A·u | λ·u | μ·u | rotation·u | r·u | a·u | b·u ]
1132    /// ```
1133    ///
1134    /// i.e. `d_inner + u·d_inner + u·bc + bc + (2 … 7)·u·nheads +
1135    /// u·num_rotation_channels` with `bc = ngroups·state_rank·mimo_rank` and `u` =
1136    /// [`Self::micro_steps`]. Only the **per-micro-step** segments widen; the
1137    /// gate `z` and the read `C` are per token (see [`crate::mamba3::product`]).
1138    /// At `u = 1` the stock block (the default trapezoid, no positive system) is
1139    /// `2·d_inner + 2·bc + 3·nheads + num_rotation_channels`.
1140    ///
1141    /// Every segment from `λ` on is one a block may omit outright:
1142    /// [`Trapezoid::None`] projects no `λ`, a one-tap pattern no `μ`,
1143    /// [`RotationKind::Real1D`] no rotation, every [`Gain`] but
1144    /// [`Gain::KalmanProjectedNoise`] no noise `r`, and [`Tropical::None`] no
1145    /// register `(a, b)` (`helpers::split_trailing` peels them in the reverse
1146    /// of that order).
1147    pub fn d_in_proj(&self) -> usize {
1148        let u = self.micro_steps;
1149        let bc = self.ngroups * self.state_rank * self.mimo_rank;
1150        self.d_inner() + u * self.d_inner() + u * bc + bc + self.d_in_proj_tail()
1151    }
1152
1153    /// Width of the in-projection's trailing per-micro-step segments
1154    /// `[Δ·u | A·u | λ·u | μ·u | rotation·u | noise·u | tropical·2u]` —
1155    /// `(2 … 7)·u·nheads + u·num_rotation_channels` — which
1156    /// [`Mamba3Untied::InProjTail`] splits off.
1157    pub fn d_in_proj_tail(&self) -> usize {
1158        let u = self.micro_steps;
1159        let scalars = 2
1160            + usize::from(self.trapezoid.has_beta_tap())
1161            + usize::from(self.trapezoid.has_interior_tap(u))
1162            + usize::from(self.gain.projects_noise())
1163            + 2 * usize::from(self.tropical.is_on());
1164        scalars * u * self.nheads() + u * self.num_rotation_channels()
1165    }

1167    /// The block's 2-D weights Muon may own, and how their fused columns split.
1168    ///
1169    /// `in_proj`'s segments mirror the `split_into` in the SSD pathways
1170    /// (`[z | x·u | B·u | C | Δ·u | A·u | λ·u | μ·u | rotation·u | r·u | a·u |
1171    /// b·u]`); the per-head *scalar* channels stay on AdamW. See
1172    /// [`burn_stack::optim`].
1173    ///
1174    /// Each micro-step gets its **own** segment rather than sharing one `u`-wide
1175    /// slab: they are `u` independent `d_model → width` maps, and Muon should
1176    /// orthogonalise each on its own. They share a name, so
1177    /// [`MuonPlan::without_segment`](burn_stack::optim::MuonPlan::without_segment)
1178    /// still opts all of a stream's micro-steps out at once.
1179    ///
1180    /// Under [`Mamba3Untied::InProjTail`] the segments from `Δ` on are
1181    /// `in_proj_tail`'s, one copy per application ([`ProjSpec::tiled`]).
1182    ///
1183    /// [`ProjSpec::tiled`]: burn_stack::optim::ProjSpec::tiled
1184    #[cfg(feature = "optim")]
1185    pub fn muon_projections(&self) -> Vec<burn_stack::optim::ProjSpec> {
1186        use burn_stack::optim::{ProjSegment as Seg, ProjSpec};
1187        let d_inner = self.d_inner();
1188        let nheads = self.nheads();
1189        let bc = self.ngroups * self.state_rank * self.mimo_rank;
1190        let rot = self.num_rotation_channels();
1191        // One copy of `seg` per micro-step.
1192        let per_micro = |seg: Seg| std::iter::repeat_n(seg, self.micro_steps);
1193        let head: Vec<Seg> = std::iter::once(Seg::muon("z", d_inner))
1194            .chain(per_micro(Seg::muon("x", d_inner)))
1195            .chain(per_micro(Seg::muon("b", bc)))
1196            .chain(std::iter::once(Seg::muon("c", bc)))
1197            .collect();
1198        let tail: Vec<Seg> = per_micro(Seg::adamw("dt", nheads))
1199            .chain(per_micro(Seg::adamw("a", nheads)))
1200            // `Trapezoid::None` projects no `λ`, as `Real1D` projects no rotation;
1201            // and only a two-tap pattern projects the second mass's mix `μ`.
1202            .chain(
1203                self.trapezoid
1204                    .has_beta_tap()
1205                    .then(|| per_micro(Seg::adamw("lambda", nheads)))
1206                    .into_iter()
1207                    .flatten(),
1208            )
1209            .chain(
1210                self.trapezoid
1211                    .has_interior_tap(self.micro_steps)
1212                    .then(|| per_micro(Seg::adamw("mu", nheads)))
1213                    .into_iter()
1214                    .flatten(),
1215            )
1216            // `Real1D` has no rotation columns, and a zero-width segment is
1217            // not a thing (see `num_rotation_channels`).
1218            .chain(
1219                (rot > 0)
1220                    .then(|| per_micro(Seg::muon("rotation", rot)))
1221                    .into_iter()
1222                    .flatten(),
1223            )
1224            // The positive systems' channels are per-head scalars, like `Δ`.
1225            .chain(
1226                self.gain
1227                    .projects_noise()
1228                    .then(|| per_micro(Seg::adamw("kalman_noise", nheads)))
1229                    .into_iter()
1230                    .flatten(),
1231            )
1232            .chain(
1233                self.tropical
1234                    .is_on()
1235                    .then(|| {
1236                        per_micro(Seg::adamw("tropical_a", nheads))
1237                            .chain(per_micro(Seg::adamw("tropical_b", nheads)))
1238                    })
1239                    .into_iter()
1240                    .flatten(),
1241            )
1242            .collect();
1243        let in_proj = match self.untied.contains(&Mamba3Untied::InProjTail) {
1244            true => vec![
1245                ProjSpec::block("in_proj.weight", head),
1246                ProjSpec::block("in_proj_tail.weight", tail).tiled(),
1247            ],
1248            false => vec![ProjSpec::block("in_proj.weight", [head, tail].concat())],
1249        };
1250        in_proj
1251            .into_iter()
1252            .chain([ProjSpec::block_whole("out_proj.weight", self.d_model)])
1253            .collect()
1254    }

1256    /// Allocate and initialise all Mamba-3 block parameters on `device`, for a

1262    /// Allocate and initialise all Mamba-3 block parameters on `device`, for a
1263    /// real layer applied `n_applications` times: every [`Self::untied`]
1264    /// parameter holds that many copies of one initialisation.
1265    pub fn init_applications(&self, n_applications: usize, device: &Device) -> Mamba3 {
1266        let d_inner = self.d_inner();
1267        let nheads = self.nheads();
1268        let ngroups = self.ngroups;
1269        let state_rank = self.state_rank;
1270        let mimo_rank = self.mimo_rank;
1271        let num_rope_angles = self.num_rope_angles();
1272
1273        assert!(state_rank > 0, "state_rank must be positive");
1274        // Evenness is a RoPE-pairing requirement; `Real1D` pairs nothing, so it
1275        // is the one kind that admits an odd (in particular, scalar) state.
1276        assert!(
1277            self.rotation == RotationKind::Real1D || state_rank.is_multiple_of(2),
1278            "state_rank must be even for RoPE pairing"
1279        );
1280        assert!(self.per_head_dim > 0, "per_head_dim must be positive");
1281        assert_eq!(
1282            nheads * self.per_head_dim,
1283            d_inner,
1284            "d_inner must be divisible by per_head_dim"
1285        );
1286        assert_ne!(ngroups, 0, "ngroups must be at least 1");
1287        assert_eq!(nheads % ngroups, 0, "nheads must be divisible by ngroups");
1288        assert!(self.a_floor > 0.0, "a_floor must be positive");
1289        assert!(mimo_rank >= 1, "mimo_rank must be at least 1");
1290        assert!(self.micro_steps >= 1, "micro_steps must be at least 1");
1291        assert!(
1292            [0.5, 1.0].contains(&self.rope_fraction),
1293            "rope_fraction must be 0.5 or 1.0 (for no rotation use RotationKind::Real1D)"
1294        );
1295        if self.rotation != RotationKind::Real1D {
1296            // Every rotating kind must actually turn something; the ablation is
1297            // a kind of its own now, not a fraction of zero.
1298            assert!(
1299                num_rope_angles > 0,
1300                "{:?} rotates nothing at state_rank = {} and rope_fraction = {} — use RotationKind::Real1D",
1301                self.rotation,
1302                self.state_rank,
1303                self.rope_fraction
1304            );
1305        }
1306        if matches!(
1307            self.rotation,
1308            RotationKind::Quaternion4D | RotationKind::Rotor4D
1309        ) {
1310            assert!(
1311                self.state_rank.is_multiple_of(4),
1312                "{:?} requires state_rank to be a multiple of 4",
1313                self.rotation
1314            );
1315            // The rotated width is a whole number of quaternion blocks, so a
1316            // partial rotation has to land on a multiple of 4. Without this the
1317            // block would quietly round `num_quat_blocks` up to its floor of 1
1318            // and rotate *everything* when asked for half.
1319            assert!(
1320                self.rope_dim().is_multiple_of(4),
1321                "{:?} rotates whole 4-blocks: rope_fraction·state_rank = {} is not a multiple of 4",
1322                self.rotation,
1323                self.rope_dim()
1324            );
1325        }
1326        assert!(self.rotation_range > 0.0, "rotation_range must be positive");
1327        let unties = |part| self.untied.contains(&part);
1328        assert!(
1329            mimo_rank > 1
1330                || ![Mamba3Untied::MimoX, Mamba3Untied::MimoZ, Mamba3Untied::MimoO]
1331                    .into_iter()
1332                    .any(unties),
1333            "Mamba3Untied::Mimo* unties a MIMO projection, and mimo_rank = 1 has none"
1334        );
1335        assert!(
1336            self.has_outproj_norm || !unties(Mamba3Untied::OutNorm),
1337            "Mamba3Untied::OutNorm unties the output norm, and has_outproj_norm is off"
1338        );
1339        assert!(
1340            self.has_learnable_init_state || !unties(Mamba3Untied::InitState),
1341            "Mamba3Untied::InitState unties the initial state, and has_learnable_init_state is off"
1342        );
1343        assert!(
1344            self.gain.is_kalman() || !unties(Mamba3Untied::KalmanKappa),
1345            "Mamba3Untied::KalmanKappa unties the Kalman gate's κ, and the gain is Gain::Projected"
1346        );
1347        assert!(
1348            self.gain.is_kalman() || !unties(Mamba3Untied::KalmanRead),
1349            "Mamba3Untied::KalmanRead unties the Kalman read exponent, and the gain is Gain::Projected"
1350        );
1351        assert!(
1352            self.tropical.is_on() || !unties(Mamba3Untied::TropicalReadout),
1353            "Mamba3Untied::TropicalReadout unties the tropical readout, and tropical is Tropical::None"
1354        );
1355        assert!(
1356            !self.gain.is_kalman() || self.kalman_kappa_init > 0.0,
1357            "kalman_kappa_init must be positive (κ = 0 is Gain::Projected)"
1358        );
1359        // How many copies `part` holds: one per application if untied.
1360        let copies = |part| if unties(part) { n_applications } else { 1 };
1361
1362        let uniform_init = |fan_in: usize| {
1363            let bound = 1.0 / (fan_in as f64).sqrt();
1364            Initializer::Uniform {
1365                min: -bound,
1366                max: bound,
1367            }
1368        };
1369
1370        let d_in_proj_tail = unties(Mamba3Untied::InProjTail).then(|| self.d_in_proj_tail());
1371        let in_proj = LinearConfig::new(self.d_model, self.d_in_proj() - d_in_proj_tail.unwrap_or(0))
1372            .with_bias(self.has_proj_bias)
1373            .with_initializer(uniform_init(self.d_model))
1374            .init(device);
1375        let in_proj_tail = d_in_proj_tail.map(|width| {
1376            let Linear { weight, bias } = LinearConfig::new(self.d_model, width)
1377                .with_bias(self.has_proj_bias)
1378                .with_initializer(uniform_init(self.d_model))
1379                .init(device);
1380            Linear {
1381                weight: untied::tile(weight, 1, n_applications),
1382                bias: bias.map(|b| untied::tile(b, 0, n_applications)),
1383            }
1384        });
1385
1386        // dt_bias: inverse-softplus initialisation
1387        let expm1 = |t: Tensor<1>| t.exp() - 1.;
1388        let dt_h = Tensor::random(
1389            [nheads],
1390            burn::tensor::Distribution::Uniform(self.dt_min.ln(), self.dt_max.ln()),
1391            device,
1392        )
1393        .exp();
1394        let dt_h = dt_h.clamp(self.dt_init_floor, f64::INFINITY);
1395        let inv_dt_h = dt_h.clone() + (-expm1(-dt_h)).log();
1396        let dt_bias_h = untied::tile(
1397            Param::from_tensor(inv_dt_h),
1398            0,
1399            copies(Mamba3Untied::DtBias),
1400        );
1401
1402        let d_h = Initializer::Ones.init::<1, _>([nheads], device);
1403        let d_h = untied::tile(d_h, 0, copies(Mamba3Untied::D));
1404
1405        let mut b_norm = RmsNormConfig::new(state_rank).init(device);
1406        b_norm.gamma = untied::tile(b_norm.gamma, 0, copies(Mamba3Untied::BNorm));
1407        let mut c_norm = RmsNormConfig::new(state_rank).init(device);
1408        c_norm.gamma = untied::tile(c_norm.gamma, 0, copies(Mamba3Untied::CNorm));
1409
1410        // B/C biases: [nheads, mimo_rank, state_rank], init to ones
1411        let b_bias_hmr = Initializer::Ones.init::<3, _>([nheads, mimo_rank, state_rank], device);
1412        let b_bias_hmr = untied::tile(b_bias_hmr, 0, copies(Mamba3Untied::BBias));
1413        let c_bias_hmr = Initializer::Ones.init::<3, _>([nheads, mimo_rank, state_rank], device);
1414        let c_bias_hmr = untied::tile(c_bias_hmr, 0, copies(Mamba3Untied::CBias));
1415
1416        // MIMO projections (only for mimo_rank > 1)
1417        let (mimo_x_hmp, mimo_z_hmp, mimo_o_hmp) = if mimo_rank > 1 {
1418            let per_head_dim = self.per_head_dim;
1419            // Init: mimo_x_hmp and mimo_o_hmp to 1/mimo_rank, mimo_z_hmp to 1
1420            let mx = Param::from_tensor(Tensor::full(
1421                [nheads, mimo_rank, per_head_dim],
1422                1.0 / mimo_rank as f64,
1423                device,
1424            ));
1425            let mz = Param::from_tensor(Tensor::ones([nheads, mimo_rank, per_head_dim], device));
1426            let mo = Param::from_tensor(Tensor::full(
1427                [nheads, mimo_rank, per_head_dim],
1428                1.0 / mimo_rank as f64,
1429                device,
1430            ));
1431            (
1432                Some(untied::tile(mx, 0, copies(Mamba3Untied::MimoX))),
1433                Some(untied::tile(mz, 0, copies(Mamba3Untied::MimoZ))),
1434                Some(untied::tile(mo, 0, copies(Mamba3Untied::MimoO))),
1435            )
1436        } else {
1437            (None, None, None)
1438        };
1439
1440        // Gated RMSNorm applied per-head (group size = per_head_dim).
1441        let out_norm = self.has_outproj_norm.then(|| {
1442            let mut norm = RmsNormGatedConfig::new(self.per_head_dim)
1443                .with_norm_before_gate(true)
1444                .init(device);
1445            norm.gamma = untied::tile(norm.gamma, 0, copies(Mamba3Untied::OutNorm));
1446            norm
1447        });
1448
1449        let out_proj = LinearConfig::new(d_inner, self.d_model)
1450            .with_bias(self.has_proj_bias)
1451            .with_initializer(uniform_init(d_inner))
1452            .init(device);
1453
1454        let init_state_hpr = self.has_learnable_init_state.then(|| {
1455            let init = Initializer::Zeros.init::<3, _>([nheads, self.per_head_dim, state_rank], device);
1456            untied::tile(init, 0, copies(Mamba3Untied::InitState))
1457        });
1458
1459        let kalman_log_kappa_h = self.gain.is_kalman().then(|| {
1460            let init = Param::from_tensor(Tensor::full([nheads], self.kalman_kappa_init.ln(), device));
1461            untied::tile(init, 0, copies(Mamba3Untied::KalmanKappa))
1462        });
1463        let kalman_read_h = self.gain.is_kalman().then(|| {
1464            let init = Initializer::Zeros.init::<1, _>([nheads], device);
1465            untied::tile(init, 0, copies(Mamba3Untied::KalmanRead))
1466        });
1467        let tropical_readout_hp = self.tropical.is_on().then(|| {
1468            let init = Initializer::Zeros.init::<2, _>([nheads, self.per_head_dim], device);
1469            untied::tile(init, 0, copies(Mamba3Untied::TropicalReadout))
1470        });
1471
1472        Mamba3 {
1473            in_proj,
1474            in_proj_tail,
1475            dt_bias_h,
1476            dt_limit: self.dt_limit,
1477            a_floor: self.a_floor,
1478            d_h,
1479            b_norm,
1480            c_norm,
1481            b_bias_hmr,
1482            c_bias_hmr,
1483            mimo_x_hmp,
1484            mimo_z_hmp,
1485            mimo_o_hmp,
1486            out_norm,
1487            out_proj,
1488            init_state_hpr,
1489            kalman_log_kappa_h,
1490            kalman_read_h,
1491            tropical_readout_hp,
1492            state_rank,
1493            ngroups,
1494            rope_dim: self.rope_dim(),
1495            num_rope_angles,
1496            mimo_rank,
1497            micro_steps: self.micro_steps,
1498            rotation: self.rotation,
1499            trapezoid: self.trapezoid,
1500            gain: self.gain,
1501            tropical: self.tropical,
1502            rotation_range: self.rotation_range,
1503            num_rotation_channels: self.num_rotation_channels(),
1504            num_quat_blocks: self.num_quat_blocks(),
1505            siso_specialization: self.siso_specialization,
1506            siso_specialization_decode: self.siso_specialization_decode,
1507            untied: self.untied.clone(),
1508        }
1509    }
1510}

1512// ---------------------------------------------------------------------------
1513// Mamba3::forward  (chunkwise double-SSD — training / prefill)
1514// ---------------------------------------------------------------------------
1515
1516impl Mamba3 {
1517    /// Process a full input sequence using the trapezoidal double-SSD algorithm.
1518    ///
1519    /// For SISO (mimo_rank=1), this is the standard double-SSD decomposition.
1520    /// For MIMO (mimo_rank>1), B/C have mimo_rank parallel rank channels.
1521    /// The hidden state is shared across mimo ranks; each mimo rank contributes independently.
1522    ///
1523    /// # Shapes
1524    /// - `input_bsm` : `[batch, sequence, d_model]`
1525    /// - output      : `[batch, sequence, d_model]`
1526    #[allow(non_snake_case)]
1527    pub fn forward(
1528        &self,
1529        input_bsm: Tensor<3>,
1530        cache: Option<Mamba3Cache>,
1531        ssd_path: Mamba3SsdPath,
1532    ) -> (Tensor<3>, Mamba3Cache) {
1533        let [batch, sequence, _d_model] = input_bsm.dims();
1534        let nheads = self.nheads();
1535        let ngroups = self.ngroups;
1536        let _per_head_dim = self.per_head_dim();
1537        let _state_rank = self.state_rank;
1538        let _num_rope_angles = self.num_rope_angles;
1539        let _mimo_rank = self.mimo_rank;
1540        let device = input_bsm.device();
1541
1542        assert!(sequence > 0, "sequence length must be at least 1");
1543        assert_eq!(nheads % ngroups, 0);
1544        san(&input_bsm);
1545
1546        // ── Initialise cache if not provided ──────────────────────────────────
1547        // A missing cache implies the single-ssd pathway (both rotation kinds are
1548        // supported there; see [`forward_single_ssd`]).
1549        let cache = cache.unwrap_or_else(|| self.zero_cache(batch, &device));
1550
1551        // ── SSD Pathway Selection ─────────────────────────────────────────────
1552        match cache {
1553            Mamba3Cache::DoubleSsd(cache) => {
1554                let (out_bsm, cache) = self.forward_double_ssd(input_bsm, Some(cache), &ssd_path);
1555                (out_bsm, cache.into())
1556            }
1557            Mamba3Cache::SingleSsd(cache) => {
1558                let (out_bsm, cache) = self.forward_single_ssd(input_bsm, Some(cache), &ssd_path);
1559                (out_bsm, cache.into())
1560            }
1561        }
1562    }
1563
1564    /// Build the default per-call cache (single-ssd pathway, for either rotation
1565    /// kind). The rotation accumulator is the matching [`RotationState`] variant.
1566    fn zero_cache(&self, batch: usize, device: &Device) -> Mamba3Cache {
1567        let nheads = self.nheads();
1568        let per_head_dim = self.per_head_dim();
1569        let state_rank = self.state_rank;
1570        let ssm_bhpr = Tensor::zeros([batch, nheads, per_head_dim, state_rank], device);
1571        let (k_state_bumhr, v_state_buhp) = self.zero_tap_slots(batch, device);
1572        let rotation = self.zero_rotation_state(batch, device);
1573        let (log_precision_bh, tropical_bh) = self.zero_positive_state(batch, device);
1574        crate::mamba3::single_ssd::cache::Mamba3SingleSsdCache {
1575            ssm_bhpr,
1576            k_state_bumhr,
1577            v_state_buhp,
1578            rotation,
1579            log_precision_bh,
1580            tropical_bh,
1581        }
1582        .into()
1583    }
1584
1585    /// How far back this block's `β` tap reaches, in folded positions —
1586    /// [`Trapezoid::tap_lag`] at this block's `micro_steps`. `0` when the
1587    /// pattern has no tap.
1588    pub fn tap_lag(&self) -> usize {
1589        self.trapezoid.tap_lag(self.micro_steps)
1590    }
1591
1592    /// The trapezoid's tap FIFO, zero-filled: [`Self::tap_lag`] slots of
1593    /// `(B, x)`, oldest first — or `None` under a pattern with no `β` tap, in
1594    /// which case nothing is allocated at all.
1595    ///
1596    /// # Shapes
1597    /// - `.0` : `[batch, tap_slots, mimo_rank, nheads, state_rank]`
1598    /// - `.1` : `[batch, tap_slots, nheads, per_head_dim]`
1599    pub fn zero_tap_slots(
1600        &self,
1601        batch: usize,
1602        device: &Device,
1603    ) -> (Option<Tensor<5>>, Option<Tensor<4>>) {
1604        let slots = self.tap_lag();
1605        if slots == 0 {
1606            return (None, None);
1607        }
1608        let nheads = self.nheads();
1609        (
1610            Some(Tensor::zeros(
1611                [batch, slots, self.mimo_rank, nheads, self.state_rank],
1612                device,
1613            )),
1614            Some(Tensor::zeros(
1615                [batch, slots, nheads, self.per_head_dim()],
1616                device,
1617            )),
1618        )
1619    }
1620
1621    /// The tap FIFO to hand to the next call: the last `lag` folded positions'
1622    /// `(B, x)`, oldest first — or `(None, None)` when the pattern has no `β`
1623    /// tap.
1624    ///
1625    /// `x` is pre-scaled by the decay accumulated since its own position
1626    /// ([`crate::mamba3::helpers::tail_decay`]), which is what lets a lag-`u`
1627    /// tap's gap transport span the call boundary; at `lag = 1` that product is
1628    /// empty and the slot is the plain last `x`. Shared by both pathways, whose
1629    /// caches therefore stay field-identical.
1630    ///
1631    /// # Shapes
1632    /// - `b_bsmhr` : `[batch, sequence, mimo_rank, nheads, state_rank]`
1633    /// - `x_bshp`  : `[batch, sequence, nheads, per_head_dim]`
1634    /// - `da_bsh`  : `[batch, sequence, nheads]`
1635    pub(crate) fn save_tap_slots(
1636        &self,
1637        b_bsmhr: &Tensor<5>,
1638        x_bshp: &Tensor<4>,
1639        da_bsh: &Tensor<3>,
1640        lag: usize,
1641    ) -> (Option<Tensor<5>>, Option<Tensor<4>>) {
1642        if lag == 0 {
1643            return (None, None);
1644        }
1645        let sequence = x_bshp.dims()[1];
1646        let b_last_bumhr = b_bsmhr.clone().narrow(1, sequence - lag, lag);
1647        let x_last_buhp = x_bshp.clone().narrow(1, sequence - lag, lag);
1648        let x_last_buhp = match crate::mamba3::helpers::tail_decay(da_bsh.clone(), lag) {
1649            Some(tail_buh) => x_last_buhp * tail_buh.unsqueeze_dim::<4>(3),
1650            None => x_last_buhp,
1651        };
1652        (Some(b_last_bumhr), Some(x_last_buhp))
1653    }
1654
1655    /// The fresh-sequence rotation accumulator for this block's
1656    /// [`RotationKind`] — the identity rotation, in the matching
1657    /// [`RotationState`] variant.
1658    pub fn zero_rotation_state(&self, batch: usize, device: &Device) -> RotationState {
1659        RotationState::identity(
1660            self.rotation,
1661            batch,
1662            self.nheads(),
1663            self.num_rope_angles,
1664            self.num_quat_blocks,
1665            device,
1666        )
1667    }
1668}

1671// Mamba3::step  (recurrent SSM — token-by-token decoding)
1672// ---------------------------------------------------------------------------
1673
1674mod step {
1675    use super::*;
1676
1677    impl Mamba3 {
1678        /// Process a **single token** using the pure recurrent form.
1679        ///
1680        /// For SISO (mimo_rank=1):
1681        /// ```text
1682        ///   hₜ = αₜ hₜ₋₁ + βₜ Bₜ₋₁ ⊗ xₜ₋₁ + γₜ Bₜ ⊗ xₜ
1683        ///   yₜ = Cₜᵀ hₜ + D xₜ
1684        /// ```
1685        ///
1686        /// For MIMO (mimo_rank>1):
1687        /// ```text
1688        ///   hₜ = αₜ hₜ₋₁ + Σₘ βₜ Bₜ₋₁[m] ⊗ (xₜ₋₁ ⊙ mimo_x_hmp[m]) + Σₘ γₜ Bₜ[m] ⊗ (xₜ ⊙ mimo_x_hmp[m])
1689        ///   yₜ[r] = Cₜ[r]ᵀ hₜ + D xₜ ⊙ mimo_x_hmp[r]
1690        ///   outₜ = Σₘ mimo_o_hmp[m] ⊙ silu(zₜ ⊙ mimo_z_hmp[m]) ⊙ yₜ[m]
1691        /// ```
1692        ///
1693        /// # Shapes
1694        /// - `input_bd` : `[batch, d_model]`
1695        /// - output     : `[batch, d_model]`
1696        #[allow(non_snake_case)]
1697        pub fn step(
1698            &self,
1699            input_bd: Tensor<2>,
1700            cache: Option<Mamba3Cache>,
1701        ) -> (Tensor<2>, Mamba3Cache) {
1702            let [batch, _d_model] = input_bd.dims();
1703            let nheads = self.nheads();
1704            let ngroups = self.ngroups;
1705            let _per_head_dim = self.per_head_dim();
1706            let _state_rank = self.state_rank;
1707            let _num_rope_angles = self.num_rope_angles;
1708            let _mimo_rank = self.mimo_rank;
1709            let device = input_bd.device();
1710
1711            assert_eq!(nheads % ngroups, 0);
1712            san(&input_bd);
1713
1714            // ── Initialise cache if not provided ──────────────────────────────────
1715            // Implies single-ssd pathway if missing (double-ssd for Quaternion4D).
1716            let cache = cache.unwrap_or_else(|| self.zero_cache(batch, &device));
1717
1718            // ── SSD Pathway Selection ─────────────────────────────────────────────
1719            match cache {
1720                Mamba3Cache::DoubleSsd(cache) => {
1721                    let (out_bsm, cache) = self.step_double_ssd(input_bd, Some(cache));
1722                    (out_bsm, cache.into())
1723                }
1724                Mamba3Cache::SingleSsd(cache) => {
1725                    let (out_bsm, cache) = self.step_single_ssd(input_bd, Some(cache));
1726                    (out_bsm, cache.into())
1727                }
1728            }
1729        }
1730    }
