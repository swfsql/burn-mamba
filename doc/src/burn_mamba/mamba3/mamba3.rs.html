1//! # Mamba-3 SSM Block — Exponential-Trapezoidal SSD with Data-Dependent RoPE
2//!
3//! This module implements the core **Mamba-3 layer** from the paper
4//! *"Mamba-3: Improved Sequence Modeling using State Space Principles"*.
5//!
6//! Mamba-3 adds three independent extensions to the Mamba-2 SSD recurrence:
7//! (1) trapezoidal discretisation, (2) a **complex-valued state transition**,
8//! implemented as data-dependent rotary embeddings on B and C (the "RoPE
9//! trick"), and (3) MIMO (multiple-input multiple-output) projection.
10//! Each is shown in isolation below, then combined.
11//!
12//! ## 1. Trapezoidal recurrence (SISO, no RoPE, no MIMO — Proposition 1)
13//!
14//! ```text
15//!   hₜ = αₜ hₜ₋₁ + βₜ Bₜ₋₁ xₜ₋₁ᵀ + γₜ Bₜ xₜᵀ   (state update)
16//!   yₜ = Cₜᵀ hₜ + D xₜ                          (output)
17//! ```
18//!
19//! where the trapezoidal coefficients are
20//!
21//! ```text
22//!   αₜ = exp(Δₜ Aₜ)                — decay (Aₜ < 0, data-dependent)
23//!   βₜ = (1 − λₜ) Δₜ αₜ            — left-endpoint weight (Bₜ₋₁ xₜ₋₁ contribution)
24//!   γₜ = λₜ Δₜ                      — right-endpoint weight (Bₜ xₜ contribution)
25//! ```
26//!
27//! with `λₜ = σ(λ̂ₜ) ∈ (0, 1)` controlling the left/right split of the trapezoid.
28//! Setting `λ ≡ 1` collapses this to the Mamba-2 (Euler / right-endpoint) form.
29//!
30//! ## 2. Complex transition, a.k.a. "data-dependent RoPE" (no trapezoid, no MIMO
31//! — paper section *Complex-Valued SSMs*)
32//!
33//! Despite the name this is **not a positional encoding**: it is the *imaginary
34//! part of the state transition*. Mamba-3's `A` is complex (`A + iϑ`), and under
35//! discretisation a complex SSM of state `N/2` is exactly a real SSM of state `N`
36//! whose transition is the scalar decay `α` times a block-diagonal of `2×2`
37//! rotations (paper Prop. *Complex-to-Real SSM Equivalence*):
38//!
39//! ```text
40//!   ρₜ = R(Δₜ · π · tanh(ϑₜ)) ∈ SO(2)^{N/2}   — per-step rotation (data-dependent)
41//!   hₜ = αₜ ρₜ hₜ₋₁ + Δₜ Bₜ xₜᵀ                — rotational state update
42//! ```
43//!
44//! The **exponential** discretisation is load-bearing here, not merely more
45//! accurate than forward Euler: `|exp(iΔϑ)| = 1` exactly, so the transition is
46//! orthogonal and a tracked rotation neither decays nor grows, where Euler's
47//! `|1 + iΔϑ| > 1` spirals outward (`info/rotation-as-optimization.md` §9.5).
48//!
49//! `αₜ` is a scalar (so it commutes with `ρₜ`) and each `ρₜ` is orthogonal, so
50//! the *cumulative* rotation telescopes out of the recurrence and can be absorbed
51//! into B/C instead — the **"RoPE trick"** (paper Prop. *Complex SSM,
52//! Data-Dependent RoPE Equivalence*). That is the form implemented here: the
53//! rotation never touches the state (the cached `h` is the rotated-frame one) and
54//! the SSD core stays the plain scalar-decay kernel.
55//!
56//! ```text
57//!   θₜ = θₜ₋₁ + Δₜ · π · tanh(ϑₜ)        — cumulative angles (per-pair)
58//!   Rₜ = R(θₜ) = ρₜ ⋯ ρ₁ ∈ SO(2)^{N/2}   — block-diagonal cumulative rotation
59//!   B̃ₜ = Rₜ Bₜ,   C̃ₜ = Rₜ Cₜ              — rotated state-space projections
60//! ```
61//!
62//! The standard recurrence then runs with `B̃ₜ`/`C̃ₜ` in place of `Bₜ`/`Cₜ`:
63//!
64//! ```text
65//!   hₜ = Āₜ hₜ₋₁ + B̄̃ₜ xₜᵀ                (scalar-decay state update)
66//!   yₜ = C̃ₜᵀ hₜ + D xₜ                   (output)
67//! ```
68//!
69//! Orthogonality makes the readout-vs-input similarity depend only on the
70//! rotation *accumulated between* the two steps:
71//!
72//! ```text
73//!   C̃ᵢᵀ B̃ⱼ = (Rᵢ Cᵢ)ᵀ (Rⱼ Bⱼ) = Cᵢᵀ R(θⱼ − θᵢ) Bⱼ
74//! ```
75//!
76//! `θⱼ − θᵢ` is not a position: it is `Σ Δ·π·tanh(ϑ)` over the intervening
77//! steps — how far the transition itself rotated, driven by the inputs. It would
78//! reduce to vanilla RoPE's relative position only in the degenerate case of an
79//! input-independent, constant per-step angle (`θⱼ − θᵢ = (j−i)·θ`). Data
80//! dependence is the whole point: it gives the layer rotational state dynamics,
81//! hence state-tracking (parity, mod-k) that a real, non-negative-eigenvalue SSM
82//! provably cannot express. See [`crate::mamba3::rotation`], whose `Quaternion4D`
83//! carries the same argument to a non-abelian rotation group.
84//!
85//! ## 3. MIMO Extension (no trapezoid coefficients, no RoPE — `mimo_rank = M > 1`)
86//!
87//! With MIMO, B/C carry M parallel rank channels and the state update is a sum
88//! of M outer-product contributions; the readout produces M outputs which are
89//! gated and combined back:
90//!
91//! ```text
92//!   hₜ = Āₜ hₜ₋₁ + Σₘ B̄ₜ[m] ⊗ (xₜ ⊙ mimo_x[m])                  (state update)
93//!   yₜ[m] = Cₜ[m]ᵀ hₜ + D · (xₜ ⊙ mimo_x[m])                    (per-rank output)
94//!   outₜ  = Σₘ mimo_o[m] ⊙ silu(zₜ ⊙ mimo_z[m]) ⊙ yₜ[m]         (rank merge)
95//! ```
96//!
97//! The hidden state hₜ is shared across ranks; each rank contributes to it
98//! independently but reads the full shared state when producing its output.
99//!
100//! ## 4. Combined formulation (everything together)
101//!
102//! Putting trapezoid + RoPE + MIMO into a single expression — `B̃ₜ[m] = Rₜ Bₜ[m]`
103//! and `C̃ₜ[m] = Rₜ Cₜ[m]` denote the RoPE-rotated MIMO projections:
104//!
105//! ```text
106//!   hₜ = αₜ hₜ₋₁
107//!      + βₜ Σₘ B̃ₜ₋₁[m] ⊗ (xₜ₋₁ ⊙ mimo_x[m])
108//!      + γₜ Σₘ B̃ₜ[m]   ⊗ (xₜ   ⊙ mimo_x[m])
109//!
110//!   yₜ[m] = C̃ₜ[m]ᵀ hₜ + D · (xₜ ⊙ mimo_x[m])
111//!   outₜ  = Σₘ mimo_o[m] ⊙ silu(zₜ ⊙ mimo_z[m]) ⊙ yₜ[m]
112//! ```
113//!
114//! ## 5. MambaProduct (`micro_steps = u > 1`)
115//!
116//! A fourth, independent dial (DeltaProduct's dial, not its mechanism — see
117//! [`crate::mamba3::product`] and `info/rotation-as-optimization.md`): `u`
118//! recurrence micro-steps per token, each a full step of the above with its own
119//! projected `x`, `B`, `Δ`, `A`, `λ` and rotation. One *token*'s transition is
120//! then the **product**
121//!
122//! ```text
123//!   Mₜ = (∏ⱼ αₜ,ⱼ) · Rₜ,ᵤ ⋯ Rₜ,₁
124//! ```
125//!
126//! and its write a sum of `u` outer products staggered along it; the read `C`,
127//! the gate `z` and the `D` skip stay per token. It is evaluated by folding the
128//! micro-steps into the sequence axis, so nothing below this line changes. See
129//! [`crate::mamba3::product`] for what `u` buys per
130//! [`RotationKind`] — the answer is very
131//! different for the abelian and non-abelian ones — and for the fact that
132//! [`Mamba3::step_infinite`] has no limit to return at `u > 1` when the
133//! rotations do not commute.
134//!
135//! Implementation note: the trapezoidal recurrence (in the double-ssd pathway)
136//! is computed by splitting it into a γ-SSD (current-token contributions) and
137//! a β-SSD (previous-token contributions); see [`crate::mamba3::double_ssd::ssd::ssd_path`].
138//! RoPE is applied to B and C before the SSD calls
139//! (see [`crate::mamba3::rotation::rope::apply_rope`]),
140//! and MIMO expansion happens by augmenting the V tensor with the per-rank
141//! `mimo_x` projection.
142//!
143//! See also: [`crate::mamba3::double_ssd::double_ssd`] and [`crate::mamba3::single_ssd::single_ssd`].
144//!
145//! ## Notation / Dimension Keys
146//!
147//! Throughout all Mamba-3 files, tensor names carry a suffix representing their shape.
148//! The letters used differ from the reference paper and the python implementation.
149//! The "Paper" column gives the symbol from the Mamba-3 paper; the "Python" column
150//! gives the field/variable name in the reference implementation
151//! (`refs/state-spaces/mamba/mamba_ssm/modules/mamba3.py`).
152//!
153//! | Letter | Dimension | Paper | Python | Typical value |
154//! |--------|-----------|-------|--------|---------------|
155//! | `b`    | `batch` | — | `batch` | varies |
156//! | `s`    | `sequence` length | `T` | `seqlen` | varies |
157//! | `d`    | `d_model` | `D` | `d_model` | 768, 1024 |
158//! | `i`    | `d_inner` = `expand`·`d_model` | `E·D` | `d_inner` | 2·`d_model` |
159//! | `h`    | `nheads` | `H` | `nheads` | `d_inner` / `per_head_dim` |
160//! | `p`    | `per_head_dim` | `P` | `headdim` | 64, 128 |
161//! | `r`    | `state_rank` | `N` | `d_state` | 64, 256 |
162//! | `m`    | `mimo_rank` | `M` | `mimo_rank` | 1, .., 8 |
163//! | `n`    | `nchunks` = `sequence`/`chunk_len` | — | `nchunks` | varies |
164//! | `g`    | `ngroups` | `G` | `num_bc_heads` | 1, .., `nheads` |
165//! | `l`    | `chunk_len` | `Q` | `chunk_size` | 64, .., 256 |
166//! | `a`    | `num_rope_angles` = `state_rank` / 2 (or `rope_dim` / 2) | — | `num_rope_angles` | varies |
167//!
168//! Uppercase letters represent a relation (e.g. offset, multiple, concat, stacking)
169//! of the lowercase letters. e.g. `X` may represent `x+1`, `x-1`, `x*2`, etc.
170//! `XY` may also represent `x+y`, `x*y`, etc.

186/// The Mamba-3 SSM block.
187///
188/// Implements the full Mamba-3 layer with exponential-trapezoidal discretization
189/// and data-dependent RoPE.  Supports SISO (mimo_rank=1) and MIMO (mimo_rank>1).
190/// Supports two execution modes:
191///
192/// - [`Self::forward`] — chunkwise double-SSD algorithm for training / prefill
193/// - [`Self::step`]    — recurrent form for token-by-token decoding
194#[derive(Module, Debug)]
195pub struct Mamba3 {
196    /// Input projection; width [`Mamba3Config::d_in_proj`].
197    ///
198    /// Output splits, with `u` = [`Self::micro_steps`]:
199    /// `[z | x·u | B_raw·u | C_raw | dd_dt·u | dd_A·u | lambda_raw·u | rotation·u]`
200    ///
201    /// Every **per-micro-step** stream is projected `u` times over and folded
202    /// into the sequence by [`crate::mamba3::product`]; the gate `z` and the
203    /// read `C` are per token. At the default `u = 1` this is the stock
204    /// `d_model → 2·d_inner + 2·ngroups·state_rank·mimo_rank + 3·nheads
205    /// + num_rotation_channels`.
206    pub in_proj: Linear,
207
208    /// Per-head bias for the discretisation step size Δ.
209    /// Shape: `[nheads]`
210    pub dt_bias_h: Param<Tensor<1>>,
211
212    /// Hard clamp applied to Δ after softplus.
213    pub dt_limit: (f64, f64),
214
215    /// Minimum absolute value of A: `A ∈ (−∞, −a_floor]`.
216    pub a_floor: f64,
217
218    /// Per-head skip (D) coefficient.
219    /// Shape: `[nheads]`; initialised to ones.
220    pub d_h: Param<Tensor<1>>,
221
222    /// RMSNorm applied to the B projection (QK-Norm, no gating).
223    /// Normalises over the `state_rank` dimension.
224    pub b_norm: RmsNorm,
225
226    /// RMSNorm applied to the C projection (QK-Norm, no gating).
227    /// Normalises over the `state_rank` dimension.
228    pub c_norm: RmsNorm,
229
230    /// Learnable per-head, per-rank bias for B, added after QK-norm.
231    /// Shape: `[nheads, mimo_rank, state_rank]`; initialised to ones.
232    pub b_bias_hmr: Param<Tensor<3>>,
233
234    /// Learnable per-head, per-rank bias for C, added after QK-norm.
235    /// Shape: `[nheads, mimo_rank, state_rank]`; initialised to ones.
236    pub c_bias_hmr: Param<Tensor<3>>,
237
238    /// MIMO up-projection for x (values).
239    /// Shape: `[nheads, mimo_rank, per_head_dim]`.
240    /// Only present when `mimo_rank > 1`.  When SISO, this is `None`.
241    pub mimo_x_hmp: Option<Param<Tensor<3>>>,
242
243    /// MIMO up-projection for z (gate).
244    /// Shape: `[nheads, mimo_rank, per_head_dim]`.
245    /// Only present when `mimo_rank > 1`. When SISO, this is `None`.
246    pub mimo_z_hmp: Option<Param<Tensor<3>>>,
247
248    /// MIMO down-projection for the output.
249    /// Shape: `[nheads, mimo_rank, per_head_dim]`.
250    /// Only present when `mimo_rank > 1`. When SISO, this is `None`.
251    pub mimo_o_hmp: Option<Param<Tensor<3>>>,
252
253    /// Optional gated RMSNorm applied before the output projection.
254    ///
255    /// When `Some`, the SiLU gate at the block tail is replaced by
256    /// `RmsNormGated(y, z)` which normalises `y` over `per_head_dim` and
257    /// gates with `SiLU(z)`. Created when `has_outproj_norm = true`.
258    pub out_norm: Option<RmsNormGated>,
259
260    /// Output projection: maps `d_inner → d_model`.
261    pub out_proj: Linear,
262
263    /// Optional learnable initial hidden state `h₀`.
264    /// Shape: `[nheads, per_head_dim, state_rank]`
265    pub init_state_hpr: Option<Param<Tensor<3>>>,
266
267    /// State rank — the latent dimension of the SSM hidden state.
268    ///
269    /// Paper: `N`. Python: `d_state`.
270    pub state_rank: usize,
271
272    /// Number of B/C groups. Must divide `nheads`.
273    ///
274    /// Paper: `G`. Python: `num_bc_heads`.
275    pub ngroups: usize,
276
277    /// Number of RoPE angle pairs (`rope_dim / 2`).
278    ///
279    /// Python: `num_rope_angles`.
280    pub num_rope_angles: usize,
281
282    /// Effective RoPE dimension (= `2 · num_rope_angles`). Always even and
283    /// `≤ state_rank`. Only the first `rope_dim` entries of B/C are rotated.
284    /// `0` — like every other rotation count here — for
285    /// [`RotationKind::Real1D`], which rotates nothing.
286    pub rope_dim: usize,
287
288    /// MIMO rank. 1 = SISO (standard Mamba-3).
289    ///
290    /// Paper: `M`. Python: `mimo_rank`.
291    pub mimo_rank: usize,
292
293    /// Recurrence micro-steps per token — DeltaProduct's `u`
294    /// (see [`Mamba3Config::micro_steps`] and [`crate::mamba3::product`]).
295    /// `1` is stock Mamba-3.
296    pub micro_steps: usize,
297
298    /// Which transition rotation the block applies to `B`/`C` ([`RotationKind`]).
299    /// A non-parameter constant — `#[module(skip)]` keeps it out of the record and
300    /// carries it through `load_record`/`to_device`/… unchanged.
301    #[module(skip)]
302    pub rotation: RotationKind,
303
304    /// How far one step may rotate, in half-turns per unit `Δ`
305    /// (see [`Mamba3Config::rotation_range`]).
306    pub rotation_range: f64,
307
308    /// Number of in-projection channels devoted to the rotation parameters
309    /// (`num_rope_angles` for `Complex2D`, `nheads·3·num_rotation_blocks` for
310    /// the quaternion kinds, `0` for `Real1D`); the size of the trailing
311    /// `in_proj` segment, which is absent entirely when it is `0`.
312    pub num_rotation_channels: usize,
313
314    /// Number of quaternion blocks (`rope_dim / 4`); only used for
315    /// [`RotationKind::Quaternion4D`] / [`RotationKind::Rotor4D`].
316    pub num_quat_blocks: usize,
317
318    /// Whether the `mimo_rank == 1` specialized *chunkwise* kernel is enabled
319    /// (see [`Mamba3Config::siso_specialization`]).
320    ///
321    /// A performance knob, not a semantic one: both branches compute the same
322    /// values and gradients. A non-parameter constant — `#[module(skip)]` keeps
323    /// it out of the record.
324    #[module(skip)]
325    pub siso_specialization: bool,
326
327    /// Whether the `mimo_rank == 1` specialized *per-token* kernels are enabled
328    /// (see [`Mamba3Config::siso_specialization_decode`]). Same performance-only
329    /// nature, opposite backend preference.
330    #[module(skip)]
331    pub siso_specialization_decode: bool,
332}

334impl Mamba3 {
335    /// `d_inner = expand · d_model`.
336    pub fn d_inner(&self) -> usize {
337        // Inferred from `out_proj`
338        let [d_inner, _d_model] = self.out_proj.weight.dims();
339        d_inner
340    }
341
342    /// `nheads = d_inner / per_head_dim`.
343    pub fn nheads(&self) -> usize {
344        //  Inferred from `d_h`
345        let [nheads] = self.d_h.dims();
346        nheads
347    }
348
349    /// `per_head_dim = d_inner / nheads`.
350    pub fn per_head_dim(&self) -> usize {
351        self.d_inner() / self.nheads()
352    }
353
354    /// The block's rotation kind ([`RotationKind`]).
355    pub fn rotation_kind(&self) -> RotationKind {
356        self.rotation
357    }
358
359    /// Number of quaternion blocks the rotation projection and its cumulative
360    /// scan run over: `num_quat_blocks · quat_factors` — twice the state's
361    /// 4-block count for [`RotationKind::Rotor4D`], whose left and right
362    /// factors share one stacked block axis.
363    pub fn num_rotation_blocks(&self) -> usize {
364        self.num_quat_blocks * self.rotation.quat_factors()
365    }
366
367    /// Width of the in-projection's trailing rotation segment: the per-step
368    /// [`Self::num_rotation_channels`] once per micro-step, since each
369    /// micro-step turns the state by a rotation of its own.
370    pub fn rotation_channels_total(&self) -> usize {
371        self.micro_steps * self.num_rotation_channels
372    }
373
374    /// Everything the rotation needs, in one place — the algebra, the rotated
375    /// width, and the per-step bound. Every site that materialises a per-step
376    /// rotation ([`forward`](Self::forward), [`step`](Self::step),
377    /// [`step_infinite`](Self::step_infinite)) goes through this.
378    pub fn rotation_spec(&self) -> crate::mamba3::rotation::RotationSpec {
379        crate::mamba3::rotation::RotationSpec {
380            kind: self.rotation,
381            rope_dim: self.rope_dim,
382            range: self.rotation_range,
383        }
384    }
385
386    /// Whether the specialized `mimo_rank == 1` **per-token** kernels should run:
387    /// the block is SISO **and** [`Mamba3Config::siso_specialization_decode`] is
388    /// enabled.
389    ///
390    /// The chunkwise counterpart is [`Mamba3Config::siso_specialization`], which
391    /// travels to its kernel as a field of the SSD input bundle rather than
392    /// through a method.
393    ///
394    /// Purely a performance choice — see [`Mamba3Config::siso_specialization_decode`].
395    pub fn use_siso_decode_kernels(&self) -> bool {
396        self.mimo_rank == 1 && self.siso_specialization_decode
397    }
398}

404/// Hyperparameters for the Mamba-3 SSM block.
405#[derive(Config, Debug)]
406pub struct Mamba3Config {
407    /// Model (hidden) dimension.
408    ///
409    /// Paper: `D`. Python: `d_model`.
410    pub d_model: usize,
411
412    /// State rank — the latent dimension of the SSM hidden state.
413    /// **Must be even** for every rotating [`RotationKind`] (RoPE pairing);
414    /// [`RotationKind::Real1D`] pairs nothing, so it also admits an odd rank
415    /// (down to the scalar state `1`).
416    ///
417    /// Paper: `N`. Python: `d_state`.
418    #[config(default = 128)]
419    pub state_rank: usize,
420
421    /// Expansion factor for `d_inner = expand · d_model`.
422    ///
423    /// Paper: `E`. Python: `expand`.
424    #[config(default = 2)]
425    pub expand: usize,
426
427    /// Head dimension. `per_head_dim = d_inner / nheads`.
428    ///
429    /// Paper: `P`. Python: `headdim`.
430    #[config(default = 64)]
431    pub per_head_dim: usize,
432
433    /// Number of B/C groups. Must divide `nheads`.
434    ///
435    /// Paper: `G`. Python: `num_bc_heads`.
436    #[config(default = 1)]
437    pub ngroups: usize,
438
439    /// MIMO rank. `1` = standard SISO Mamba-3.
440    ///
441    /// When `mimo_rank > 1`, the B/C projections have `mimo_rank` parallel rank channels.
442    /// Three extra weight matrices (`mimo_x_hmp`, `mimo_z_hmp`, `mimo_o_hmp`) provide
443    /// element-wise up/down projections in head-space across ranks.
444    ///
445    /// Paper: `M`. Python: `mimo_rank`.
446    #[config(default = 1)]
447    pub mimo_rank: usize,
448
449    /// **MambaProduct**: recurrence micro-steps per token — DeltaProduct's `u`.
450    /// `1` (the default) is stock Mamba-3, byte for byte.
451    ///
452    /// Each micro-step is a full Mamba-3 step with its own projected
453    /// `x`, `B`, `Δ`, `A`, `λ` and rotation, so one *token*'s transition is the
454    /// **product** `(∏ⱼ αⱼ)·Rᵤ⋯R₁` and its write is `u` staggered outer
455    /// products. The read `C`, the gate `z`, the `D` skip and the output are
456    /// per token. Cost is `u`× the recurrence; the state does not grow.
457    ///
458    /// What it buys depends on [`Self::rotation`], and the split is sharp: with
459    /// [`Real1D`](crate::mamba3::rotation::RotationKind::Real1D) the factors are
460    /// scalars and commute, so `u` widens only the write (the sequential
461    /// reading of what [`Self::mimo_rank`] does jointly); with
462    /// [`Complex2D`](crate::mamba3::rotation::RotationKind::Complex2D) it also
463    /// multiplies the per-token angle reach by `u` *without* pushing any single
464    /// factor onto `tanh`'s flat region (see [`Self::rotation_range`]); with the
465    /// non-abelian kinds it composes generators that no single step can express.
466    /// See [`crate::mamba3::product`] for the full argument, the folding, and
467    /// the one capability `u > 1` costs
468    /// ([`step_infinite`](Mamba3::step_infinite) on the non-abelian kinds).
469    #[config(default = 1)]
470    pub micro_steps: usize,
471
472    /// Minimum absolute value of A after clamping.
473    #[config(default = "1e-4")]
474    pub a_floor: f64,
475
476    /// Minimum value of the initial Δ distribution.
477    #[config(default = 1e-3)]
478    pub dt_min: f64,
479
480    /// Maximum value of the initial Δ distribution.
481    #[config(default = 0.1)]
482    pub dt_max: f64,
483
484    /// Floor clamped onto sampled initial Δ values.
485    #[config(default = 1e-4)]
486    pub dt_init_floor: f64,
487
488    /// Hard clamp limits for Δ at runtime.
489    #[config(default = "(0., 6.5504e+4)")]
490    pub dt_limit: (f64, f64),
491
492    /// Whether to add a bias term to the `in_proj` and `out_proj`.
493    #[config(default = false)]
494    pub has_proj_bias: bool,
495
496    /// Whether to allocate a learnable initial SSM state `h₀`.
497    #[config(default = false)]
498    pub has_learnable_init_state: bool,
499
500    /// Fraction of `state_rank` the transition rotation turns (must be `0.5`
501    /// or `1.0`).
502    ///
503    /// To disable the rotation, pick the *kind* [`RotationKind::Real1D`] rather
504    /// than a fraction of zero: a real transition projects no rotation channels
505    /// and caches no accumulator, where a zero fraction used to keep both alive
506    /// around a rotation nobody applied. Ignored by `Real1D`, which turns
507    /// nothing whatever this says.
508    ///
509    /// - `0.5`: partial rotation — only `state_rank / 2` dimensions are turned;
510    ///   the rest pass through unchanged. This is the reference's value in
511    ///   `mamba3.py`; set it explicitly to reproduce that model.
512    /// - `1.0` (default): full rotation — every B/C dimension is turned.
513    ///
514    /// The default turns everything, for both rotation kinds: a partial
515    /// rotation is a capacity trade (keeping "content" channels out of the
516    /// turn), which is a deliberate choice a config should have to ask for
517    /// rather than get by omission. For
518    /// [`Quaternion4D`](RotationKind::Quaternion4D) and
519    /// [`Rotor4D`](RotationKind::Rotor4D) it is also what keeps the smallest
520    /// legal `state_rank` (4 — a single quaternion block) usable, since a
521    /// partial quaternion rotation must land on whole 4-blocks.
522    #[config(default = 1.0)]
523    pub rope_fraction: f64,
524
525    /// Whether to apply a gated RMSNorm before the output projection.
526    ///
527    /// When `true`, the SiLU gate at the end of the block is replaced by a
528    /// per-head [`RmsNormGated`] (group size = `per_head_dim`) which both
529    /// normalises `y` and gates it with `SiLU(z)`. Matches the reference's
530    /// `is_outproj_norm` argument in `mamba3.py`.
531    #[config(default = false)]
532    pub has_outproj_norm: bool,
533
534    /// Which rotational-state algebra to use for the data-dependent rotation
535    /// carried by the state transition and absorbed into `B`/`C` (see
536    /// [`RotationKind`]).
537    ///
538    /// Defaults to the abelian [`Complex2D`](RotationKind::Complex2D) — the
539    /// current Mamba-3 RoPE — for which the block is byte-for-byte unchanged.
540    /// [`Quaternion4D`](RotationKind::Quaternion4D) selects the non-abelian
541    /// quaternion rotation; its in-projection devotes
542    /// `nheads · 3 · num_quat_blocks` channels to per-head quaternion
543    /// generators in place of the shared `num_rope_angles` angle channels (see
544    /// [`Self::num_rotation_channels`]). [`Rotor4D`](RotationKind::Rotor4D)
545    /// selects the full `SO(4)` rotation of each 4-block and doubles that
546    /// channel count (a left and a right generator per head and block).
547    /// [`Real1D`](RotationKind::Real1D) removes the rotation altogether — no
548    /// channels, no accumulator, a real transition.
549    #[config(default = "crate::mamba3::rotation::RotationKind::Complex2D")]
550    pub rotation: RotationKind,
551
552    /// How far a single step may rotate the state, in **half-turns per unit
553    /// `Δ`**: the per-step angle is bounded by `rotation_range · π · Δ`.
554    ///
555    /// The default of `2.0` is "one unit of `Δ` may traverse the whole rotation
556    /// group once", which means the same thing for both kinds even though their
557    /// periods differ:
558    ///
559    /// - [`Complex2D`](RotationKind::Complex2D): `2π` is a full turn of
560    ///   `SO(2)`.
561    /// - [`Quaternion4D`](RotationKind::Quaternion4D): `2π` reaches every
562    ///   element of `SU(2)`, whose period is `4π` — `q` and `−q` are the two
563    ///   lifts of one `SO(3)` rotation and turn the state differently.
564    /// - [`Rotor4D`](RotationKind::Rotor4D): the bound applies to **each
565    ///   factor**, so at the default each of `q` and `p` independently sweeps
566    ///   all of `SU(2)` and the pair reaches every element of
567    ///   `SO(4) ≅ (SU(2)×SU(2))/±1`. Bounding the composite instead (halving
568    ///   the per-factor angle) would cost reach for nothing: the two plane
569    ///   angles `a∓b` are periodic in `2π` anyway.
570    ///
571    /// What the bound buys is not reach but **gradients**. A rotation of exactly
572    /// `range·π` sits at `tanh`'s asymptote, where the gradient is not merely
573    /// small but **exactly zero** in f32 (`tanh(10) == 1.0`). Half-turns are
574    /// what state-tracking wants, so at `range = 1` — where `π` *is* the
575    /// bound — the most useful rotation is the one the optimiser can never
576    /// reach. At `2.0` it sits at `tanh = 1/2`, in the interior.
577    ///
578    /// `1.0` is the reference implementation's abelian bound (`Δ·π·tanh(ϑ)`);
579    /// set it explicitly to reproduce that model. Ignored by
580    /// [`Real1D`](RotationKind::Real1D), which never turns.
581    #[config(default = 2.0)]
582    pub rotation_range: f64,
583
584    /// Whether to use the specialized `mimo_rank == 1` (SISO) **chunkwise**
585    /// kernel: the same-step γ-correction
586    /// ([`y_diag_correction`](crate::mamba3::single_ssd::ssd::diag::y_diag_correction)),
587    /// forward *and* its analytic backward.
588    ///
589    /// At `mimo_rank == 1` the `m × m` Gram is a scalar, so the general form
590    /// issues a `1×r×1` and a `1×1×p` GEMM per `(batch, nchunks, chunk_len,
591    /// nheads)` — thousands of degenerate products. The SISO branch replaces all
592    /// of them with one elementwise multiply and a `state_rank` reduction over
593    /// the whole tensor, which is why deleting the tiny GEMMs helps everywhere:
594    /// ≈ neutral to ~9 % faster across the backends in `bench.md`. Leave it on.
595    ///
596    /// **Values and gradients are identical either way** — this only selects the
597    /// op mix. Ignored when `mimo_rank > 1`, where only the general branch
598    /// applies. See also [`Self::siso_specialization_decode`], the per-token
599    /// counterpart, whose trade-off is *not* the same.
600    #[config(default = true)]
601    pub siso_specialization: bool,
602
603    /// Whether to use the specialized `mimo_rank == 1` (SISO) **per-token**
604    /// kernels: the decode state update and readout
605    /// (`helpers::mimo_outer_sum`, `Mamba3::step_readout`), the single-SSD
606    /// boundary-β seed, and [`step_infinite`](Mamba3::step_infinite)'s Gram.
607    ///
608    /// **Set this to `false` on the CPU backends.** Unlike the chunkwise flag,
609    /// this one replaces a *single, already efficient* batched matmul with a
610    /// broadcast multiply, so the verdict flips with the backend: at
611    /// `benches/layer.rs`'s default size the `step` group is ~12 % faster on CUDA
612    /// and about **3× slower on flex**, whose broadcast-elementwise path trails
613    /// its matmul by more than an order of magnitude at these shapes. The default
614    /// (`true`) suits the GPU backends; a CPU deployment that decodes should turn
615    /// it off — and can do so while keeping [`Self::siso_specialization`] on,
616    /// which is the point of having two flags.
617    ///
618    /// **Values and gradients are identical either way.** Ignored when
619    /// `mimo_rank > 1`.
620    #[config(default = true)]
621    pub siso_specialization_decode: bool,
622}
623
624impl Mamba3Config {
625    /// Inner (expanded) channel width: `expand · d_model`.
626    pub fn d_inner(&self) -> usize {
627        self.expand * self.d_model
628    }
629    /// Number of SSM heads: `d_inner / per_head_dim`.
630    pub fn nheads(&self) -> usize {
631        self.d_inner() / self.per_head_dim
632    }
633
634    /// Effective RoPE dimension: the number of B/C channels actually rotated.
635    /// `state_rank` for full RoPE (`rope_fraction = 1.0`), `state_rank / 2` for
636    /// `rope_fraction = 0.5` — and `0` for [`RotationKind::Real1D`], which
637    /// rotates nothing at all.
638    pub fn rope_dim(&self) -> usize {
639        if self.rotation == RotationKind::Real1D {
640            return 0;
641        }
642        let mut d = (self.state_rank as f64 * self.rope_fraction) as usize;
643        if !d.is_multiple_of(2) {
644            d -= 1;
645        }
646        d
647    }
648
649    /// Number of RoPE rotation angles projected per head: `rope_dim / 2` (`0`
650    /// for [`RotationKind::Real1D`]). `init` asserts every rotating kind turns
651    /// at least one pair, so this is `> 0` wherever it is read.
652    pub fn num_rope_angles(&self) -> usize {
653        self.rope_dim() / 2
654    }
655
656    /// Number of **state** quaternion blocks for the quaternion kinds:
657    /// `rope_dim / 4`, which `init` asserts is a whole number (and non-zero)
658    /// for them. `0` for [`RotationKind::Real1D`]; meaningless, and unread, for
659    /// [`RotationKind::Complex2D`].
660    pub fn num_quat_blocks(&self) -> usize {
661        self.rope_dim() / 4
662    }
663
664    /// Number of in-projection channels devoted to the rotation parameters,
665    /// per the configured [`RotationKind`]:
666    ///
667    /// - [`Real1D`](RotationKind::Real1D): none — the trailing `in_proj`
668    ///   segment is absent, not zero-width (Burn has no zero-width tensors).
669    /// - [`Complex2D`](RotationKind::Complex2D): `num_rope_angles` angle
670    ///   channels, shared across heads and scaled per-head by `Δ`, as in the
671    ///   reference.
672    /// - [`Quaternion4D`](RotationKind::Quaternion4D) /
673    ///   [`Rotor4D`](RotationKind::Rotor4D):
674    ///   `nheads · 3 · num_rotation_blocks` quaternion-generator channels — an
675    ///   axis·angle generator **per head** and block (and, for `Rotor4D`, per
676    ///   *factor*: one generator for the left quaternion and one for the
677    ///   right), fed through
678    ///   [`quat_from_scaled_axis`](crate::mamba3::rotation::quat_from_scaled_axis).
679    ///   For a non-abelian transition the axis is where the expressiveness
680    ///   lives: heads sharing one axis and differing only in `Δ` track one word
681    ///   at different speeds instead of different words. See
682    ///   [`generator_increment`](crate::mamba3::rotation::generator_increment).
683    pub fn num_rotation_channels(&self) -> usize {
684        match self.rotation {
685            // A real transition has no rotation to parameterise.
686            RotationKind::Real1D => 0,
687            RotationKind::Complex2D => self.num_rope_angles(),
688            // Three generator channels per (head, block) and **per factor**:
689            // one factor for Quaternion4D, two for Rotor4D.
690            RotationKind::Quaternion4D | RotationKind::Rotor4D => {
691                self.nheads() * 3 * self.num_rotation_blocks()
692            }
693        }
694    }
695
696    /// Number of quaternion blocks the *rotation projection and scan* run over:
697    /// [`Self::num_quat_blocks`] times [`RotationKind::quat_factors`] — i.e.
698    /// `2 · blocks` for [`RotationKind::Rotor4D`], whose left and right factors
699    /// share one stacked block axis.
700    pub fn num_rotation_blocks(&self) -> usize {
701        self.num_quat_blocks() * self.rotation.quat_factors()
702    }
703
704    /// Total input projection output size.
705    ///
706    /// ```text
707    ///   [ z | x·u | B·u | C | Δ·u | A·u | λ·u | rotation·u ]
708    /// ```
709    ///
710    /// i.e. `d_inner + u·d_inner + u·bc + bc + 3·u·nheads + u·num_rotation_channels`
711    /// with `bc = ngroups·state_rank·mimo_rank` and `u` =
712    /// [`Self::micro_steps`]. Only the **per-micro-step** segments widen; the
713    /// gate `z` and the read `C` are per token (see [`crate::mamba3::product`]).
714    /// At `u = 1` this is the stock
715    /// `2·d_inner + 2·bc + 3·nheads + num_rotation_channels`.
716    pub fn d_in_proj(&self) -> usize {
717        let u = self.micro_steps;
718        let bc = self.ngroups * self.state_rank * self.mimo_rank;
719        self.d_inner()
720            + u * self.d_inner()
721            + u * bc
722            + bc
723            + 3 * u * self.nheads()
724            + u * self.num_rotation_channels()
725    }
726
727    /// The block's 2-D weights Muon may own, and how their fused columns split.
728    ///
729    /// `in_proj`'s segments mirror the `split_into` in the SSD pathways
730    /// (`[z | x·u | B·u | C | Δ·u | A·u | λ·u | rotation·u]`); the three per-head
731    /// *scalar* channels stay on AdamW. See [`burn_stack::optim`].
732    ///
733    /// Each micro-step gets its **own** segment rather than sharing one `u`-wide
734    /// slab: they are `u` independent `d_model → width` maps, and Muon should
735    /// orthogonalise each on its own. They share a name, so
736    /// [`MuonPlan::without_segment`](burn_stack::optim::MuonPlan::without_segment)
737    /// still opts all of a stream's micro-steps out at once.
738    #[cfg(feature = "optim")]
739    pub fn muon_projections(&self) -> Vec<burn_stack::optim::ProjSpec> {
740        use burn_stack::optim::{ProjSegment as Seg, ProjSpec};
741        let d_inner = self.d_inner();
742        let nheads = self.nheads();
743        let bc = self.ngroups * self.state_rank * self.mimo_rank;
744        let rot = self.num_rotation_channels();
745        // One copy of `seg` per micro-step.
746        let per_micro = |seg: Seg| std::iter::repeat_n(seg, self.micro_steps);
747        let segments = std::iter::once(Seg::muon("z", d_inner))
748            .chain(per_micro(Seg::muon("x", d_inner)))
749            .chain(per_micro(Seg::muon("b", bc)))
750            .chain(std::iter::once(Seg::muon("c", bc)))
751            .chain(per_micro(Seg::adamw("dt", nheads)))
752            .chain(per_micro(Seg::adamw("a", nheads)))
753            .chain(per_micro(Seg::adamw("lambda", nheads)))
754            // `Real1D` has no rotation columns, and a zero-width segment is
755            // not a thing (see `num_rotation_channels`).
756            .chain(
757                (rot > 0)
758                    .then(|| per_micro(Seg::muon("rotation", rot)))
759                    .into_iter()
760                    .flatten(),
761            )
762            .collect();
763        vec![
764            ProjSpec::block("in_proj.weight", segments),
765            ProjSpec::block_whole("out_proj.weight", self.d_model),
766        ]
767    }
768
769    /// Allocate and initialise all Mamba-3 block parameters on `device`.
770    pub fn init(&self, device: &Device) -> Mamba3 {
771        let d_inner = self.d_inner();
772        let nheads = self.nheads();
773        let ngroups = self.ngroups;
774        let state_rank = self.state_rank;
775        let mimo_rank = self.mimo_rank;
776        let num_rope_angles = self.num_rope_angles();
777
778        assert!(state_rank > 0, "state_rank must be positive");
779        // Evenness is a RoPE-pairing requirement; `Real1D` pairs nothing, so it
780        // is the one kind that admits an odd (in particular, scalar) state.
781        assert!(
782            self.rotation == RotationKind::Real1D || state_rank.is_multiple_of(2),
783            "state_rank must be even for RoPE pairing"
784        );
785        assert!(self.per_head_dim > 0, "per_head_dim must be positive");
786        assert_eq!(
787            nheads * self.per_head_dim,
788            d_inner,
789            "d_inner must be divisible by per_head_dim"
790        );
791        assert_ne!(ngroups, 0, "ngroups must be at least 1");
792        assert_eq!(nheads % ngroups, 0, "nheads must be divisible by ngroups");
793        assert!(self.a_floor > 0.0, "a_floor must be positive");
794        assert!(mimo_rank >= 1, "mimo_rank must be at least 1");
795        assert!(self.micro_steps >= 1, "micro_steps must be at least 1");
796        assert!(
797            [0.5, 1.0].contains(&self.rope_fraction),
798            "rope_fraction must be 0.5 or 1.0 (for no rotation use RotationKind::Real1D)"
799        );
800        if self.rotation != RotationKind::Real1D {
801            // Every rotating kind must actually turn something; the ablation is
802            // a kind of its own now, not a fraction of zero.
803            assert!(
804                num_rope_angles > 0,
805                "{:?} rotates nothing at state_rank = {} and rope_fraction = {} — use RotationKind::Real1D",
806                self.rotation,
807                self.state_rank,
808                self.rope_fraction
809            );
810        }
811        if matches!(
812            self.rotation,
813            RotationKind::Quaternion4D | RotationKind::Rotor4D
814        ) {
815            assert!(
816                self.state_rank.is_multiple_of(4),
817                "{:?} requires state_rank to be a multiple of 4",
818                self.rotation
819            );
820            // The rotated width is a whole number of quaternion blocks, so a
821            // partial rotation has to land on a multiple of 4. Without this the
822            // block would quietly round `num_quat_blocks` up to its floor of 1
823            // and rotate *everything* when asked for half.
824            assert!(
825                self.rope_dim().is_multiple_of(4),
826                "{:?} rotates whole 4-blocks: rope_fraction·state_rank = {} is not a multiple of 4",
827                self.rotation,
828                self.rope_dim()
829            );
830        }
831        assert!(self.rotation_range > 0.0, "rotation_range must be positive");
832
833        let uniform_init = |fan_in: usize| {
834            let bound = 1.0 / (fan_in as f64).sqrt();
835            Initializer::Uniform {
836                min: -bound,
837                max: bound,
838            }
839        };
840
841        let in_proj = LinearConfig::new(self.d_model, self.d_in_proj())
842            .with_bias(self.has_proj_bias)
843            .with_initializer(uniform_init(self.d_model))
844            .init(device);
845
846        // dt_bias: inverse-softplus initialisation
847        let expm1 = |t: Tensor<1>| t.exp() - 1.;
848        let dt_h = Tensor::random(
849            [nheads],
850            burn::tensor::Distribution::Uniform(self.dt_min.ln(), self.dt_max.ln()),
851            device,
852        )
853        .exp();
854        let dt_h = dt_h.clamp(self.dt_init_floor, f64::INFINITY);
855        let inv_dt_h = dt_h.clone() + (-expm1(-dt_h)).log();
856        let dt_bias_h = Param::from_tensor(inv_dt_h);
857
858        let d_h = Initializer::Ones.init::<1, _>([nheads], device);
859
860        let b_norm = RmsNormConfig::new(state_rank).init(device);
861        let c_norm = RmsNormConfig::new(state_rank).init(device);
862
863        // B/C biases: [nheads, mimo_rank, state_rank], init to ones
864        let b_bias_hmr = Initializer::Ones.init::<3, _>([nheads, mimo_rank, state_rank], device);
865        let c_bias_hmr = Initializer::Ones.init::<3, _>([nheads, mimo_rank, state_rank], device);
866
867        // MIMO projections (only for mimo_rank > 1)
868        let (mimo_x_hmp, mimo_z_hmp, mimo_o_hmp) = if mimo_rank > 1 {
869            let per_head_dim = self.per_head_dim;
870            // Init: mimo_x_hmp and mimo_o_hmp to 1/mimo_rank, mimo_z_hmp to 1
871            let mx = Param::from_tensor(Tensor::full(
872                [nheads, mimo_rank, per_head_dim],
873                1.0 / mimo_rank as f64,
874                device,
875            ));
876            let mz = Param::from_tensor(Tensor::ones([nheads, mimo_rank, per_head_dim], device));
877            let mo = Param::from_tensor(Tensor::full(
878                [nheads, mimo_rank, per_head_dim],
879                1.0 / mimo_rank as f64,
880                device,
881            ));
882            (Some(mx), Some(mz), Some(mo))
883        } else {
884            (None, None, None)
885        };
886
887        // Gated RMSNorm applied per-head (group size = per_head_dim).
888        let out_norm = self.has_outproj_norm.then(|| {
889            RmsNormGatedConfig::new(self.per_head_dim)
890                .with_norm_before_gate(true)
891                .init(device)
892        });
893
894        let out_proj = LinearConfig::new(d_inner, self.d_model)
895            .with_bias(self.has_proj_bias)
896            .with_initializer(uniform_init(d_inner))
897            .init(device);
898
899        let init_state_hpr = self.has_learnable_init_state.then(|| {
900            Initializer::Zeros.init::<3, _>([nheads, self.per_head_dim, state_rank], device)
901        });
902
903        Mamba3 {
904            in_proj,
905            dt_bias_h,
906            dt_limit: self.dt_limit,
907            a_floor: self.a_floor,
908            d_h,
909            b_norm,
910            c_norm,
911            b_bias_hmr,
912            c_bias_hmr,
913            mimo_x_hmp,
914            mimo_z_hmp,
915            mimo_o_hmp,
916            out_norm,
917            out_proj,
918            init_state_hpr,
919            state_rank,
920            ngroups,
921            rope_dim: self.rope_dim(),
922            num_rope_angles,
923            mimo_rank,
924            micro_steps: self.micro_steps,
925            rotation: self.rotation,
926            rotation_range: self.rotation_range,
927            num_rotation_channels: self.num_rotation_channels(),
928            num_quat_blocks: self.num_quat_blocks(),
929            siso_specialization: self.siso_specialization,
930            siso_specialization_decode: self.siso_specialization_decode,
931        }
932    }
933}

935// ---------------------------------------------------------------------------
936// Mamba3::forward  (chunkwise double-SSD — training / prefill)
937// ---------------------------------------------------------------------------
938
939impl Mamba3 {
940    /// Process a full input sequence using the trapezoidal double-SSD algorithm.
941    ///
942    /// For SISO (mimo_rank=1), this is the standard double-SSD decomposition.
943    /// For MIMO (mimo_rank>1), B/C have mimo_rank parallel rank channels.
944    /// The hidden state is shared across mimo ranks; each mimo rank contributes independently.
945    ///
946    /// # Shapes
947    /// - `input_bsm` : `[batch, sequence, d_model]`
948    /// - output      : `[batch, sequence, d_model]`
949    #[allow(non_snake_case)]
950    pub fn forward(
951        &self,
952        input_bsm: Tensor<3>,
953        cache: Option<Mamba3Cache>,
954        ssd_path: Mamba3SsdPath,
955    ) -> (Tensor<3>, Mamba3Cache) {
956        let [batch, sequence, _d_model] = input_bsm.dims();
957        let nheads = self.nheads();
958        let ngroups = self.ngroups;
959        let _per_head_dim = self.per_head_dim();
960        let _state_rank = self.state_rank;
961        let _num_rope_angles = self.num_rope_angles;
962        let _mimo_rank = self.mimo_rank;
963        let device = input_bsm.device();
964
965        assert!(sequence > 0, "sequence length must be at least 1");
966        assert_eq!(nheads % ngroups, 0);
967        san(&input_bsm);
968
969        // ── Initialise cache if not provided ──────────────────────────────────
970        // A missing cache implies the single-ssd pathway (both rotation kinds are
971        // supported there; see [`forward_single_ssd`]).
972        let cache = cache.unwrap_or_else(|| self.zero_cache(batch, &device));
973
974        // ── SSD Pathway Selection ─────────────────────────────────────────────
975        match cache {
976            Mamba3Cache::DoubleSsd(cache) => {
977                let (out_bsm, cache) = self.forward_double_ssd(input_bsm, Some(cache), &ssd_path);
978                (out_bsm, cache.into())
979            }
980            Mamba3Cache::SingleSsd(cache) => {
981                let (out_bsm, cache) = self.forward_single_ssd(input_bsm, Some(cache), &ssd_path);
982                (out_bsm, cache.into())
983            }
984        }
985    }
986
987    /// Build the default per-call cache (single-ssd pathway, for either rotation
988    /// kind). The rotation accumulator is the matching [`RotationState`] variant.
989    fn zero_cache(&self, batch: usize, device: &Device) -> Mamba3Cache {
990        let nheads = self.nheads();
991        let per_head_dim = self.per_head_dim();
992        let state_rank = self.state_rank;
993        let mimo_rank = self.mimo_rank;
994        let ssm_bhpr = Tensor::zeros([batch, nheads, per_head_dim, state_rank], device);
995        let k_state_bmhr = Tensor::zeros([batch, mimo_rank, nheads, state_rank], device);
996        let v_state_bhp = Tensor::zeros([batch, nheads, per_head_dim], device);
997        let rotation = self.zero_rotation_state(batch, device);
998        crate::mamba3::single_ssd::cache::Mamba3SingleSsdCache {
999            ssm_bhpr,
1000            k_state_bmhr,
1001            v_state_bhp,
1002            rotation,
1003        }
1004        .into()
1005    }

1007    /// The fresh-sequence rotation accumulator for this block's
1008    /// [`RotationKind`] — the identity rotation, in the matching
1009    /// [`RotationState`] variant.
1010    pub fn zero_rotation_state(&self, batch: usize, device: &Device) -> RotationState {
1011        RotationState::identity(
1012            self.rotation,
1013            batch,
1014            self.nheads(),
1015            self.num_rope_angles,
1016            self.num_quat_blocks,
1017            device,
1018        )
1019    }

1023// Mamba3::step  (recurrent SSM — token-by-token decoding)
1024// ---------------------------------------------------------------------------
1025
1026mod step {
1027    use super::*;
1028
1029    impl Mamba3 {
1030        /// Process a **single token** using the pure recurrent form.
1031        ///
1032        /// For SISO (mimo_rank=1):
1033        /// ```text
1034        ///   hₜ = αₜ hₜ₋₁ + βₜ Bₜ₋₁ ⊗ xₜ₋₁ + γₜ Bₜ ⊗ xₜ
1035        ///   yₜ = Cₜᵀ hₜ + D xₜ
1036        /// ```
1037        ///
1038        /// For MIMO (mimo_rank>1):
1039        /// ```text
1040        ///   hₜ = αₜ hₜ₋₁ + Σₘ βₜ Bₜ₋₁[m] ⊗ (xₜ₋₁ ⊙ mimo_x_hmp[m]) + Σₘ γₜ Bₜ[m] ⊗ (xₜ ⊙ mimo_x_hmp[m])
1041        ///   yₜ[r] = Cₜ[r]ᵀ hₜ + D xₜ ⊙ mimo_x_hmp[r]
1042        ///   outₜ = Σₘ mimo_o_hmp[m] ⊙ silu(zₜ ⊙ mimo_z_hmp[m]) ⊙ yₜ[m]
1043        /// ```
1044        ///
1045        /// # Shapes
1046        /// - `input_bd` : `[batch, d_model]`
1047        /// - output     : `[batch, d_model]`
1048        #[allow(non_snake_case)]
1049        pub fn step(
1050            &self,
1051            input_bd: Tensor<2>,
1052            cache: Option<Mamba3Cache>,
1053        ) -> (Tensor<2>, Mamba3Cache) {
1054            let [batch, _d_model] = input_bd.dims();
1055            let nheads = self.nheads();
1056            let ngroups = self.ngroups;
1057            let _per_head_dim = self.per_head_dim();
1058            let _state_rank = self.state_rank;
1059            let _num_rope_angles = self.num_rope_angles;
1060            let _mimo_rank = self.mimo_rank;
1061            let device = input_bd.device();
1062
1063            assert_eq!(nheads % ngroups, 0);
1064            san(&input_bd);
1065
1066            // ── Initialise cache if not provided ──────────────────────────────────
1067            // Implies single-ssd pathway if missing (double-ssd for Quaternion4D).
1068            let cache = cache.unwrap_or_else(|| self.zero_cache(batch, &device));
1069
1070            // ── SSD Pathway Selection ─────────────────────────────────────────────
1071            match cache {
1072                Mamba3Cache::DoubleSsd(cache) => {
1073                    let (out_bsm, cache) = self.step_double_ssd(input_bd, Some(cache));
1074                    (out_bsm, cache.into())
1075                }
1076                Mamba3Cache::SingleSsd(cache) => {
1077                    let (out_bsm, cache) = self.step_single_ssd(input_bd, Some(cache));
1078                    (out_bsm, cache.into())
1079                }
1080            }
1081        }
1082    }
