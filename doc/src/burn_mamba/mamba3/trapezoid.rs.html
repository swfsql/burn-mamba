1//! # The trapezoid's tap pattern — which earlier sample the `β` tap reads
2//!
3//! Mamba-3's write is a two-tap filter on the state input: the current sample
4//! at `γₜ = λₜΔₜ` and an earlier one at `βₜ = (1−λₜ)Δₜαₜ`, transported across
5//! the gap between them (`helpers::trapezoidal_coefficients`). At
6//! [`micro_steps`](crate::mamba3::mamba3::Mamba3Config::micro_steps) `= 1`
7//! "earlier" can only mean the previous token and there is nothing to choose;
8//! at `u > 1` the folded sequence carries `u` positions per token
9//! ([`crate::mamba3::product`]) and the choice is real.
10//!
11//! [`Trapezoid`] names the members of that lattice.
12//! `info/trapezoid-as-integration.md` §§8–9 derives it, prices each member and
13//! proves the invariant they all keep (each tap transported across *its own*
14//! gap, which is what preserves the single-SSD `Δ̃` collapse) — cite it, it is
15//! not restated here.
16
17/// Which earlier sample the trapezoid's `β` tap reads.
18///
19/// The choice is **structural**, not a knob on one common algorithm: it decides
20/// the shift the chunkwise pathways apply before chunking, the width of the
21/// single-SSD γ-correction band, whether the in-projection spends `λ` channels
22/// at all, and how many `(B, x)` tap slots the cache carries
23/// ([`tap_slots`](Self::tap_slots)). Two members are also degenerate at
24/// `u = 1`: [`Vertical`](Self::Vertical) *is*
25/// [`HorizontalCarryOver`](Self::HorizontalCarryOver) there, and
26/// [`HorizontalReset`](Self::HorizontalReset) *is* [`None`](Self::None).
27///
28/// Implemented: [`HorizontalCarryOver`](Self::HorizontalCarryOver) (the default,
29/// and what the crate has always done), [`Vertical`](Self::Vertical) and
30/// [`None`](Self::None) (the ablation). The first two are **one algorithm read
31/// at two lags** ([`tap_lag`](Self::tap_lag)); the rest are named so the lattice
32/// has a vocabulary and so
33/// [`Mamba3Config::init`](crate::mamba3::mamba3::Mamba3Config::init) rejects
34/// them loudly ([`assert_implemented`](Self::assert_implemented)) instead of
35/// silently running a different recurrence than the one asked for.
36#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, serde::Serialize, serde::Deserialize)]
37pub enum Trapezoid {
38    /// **No second tap.** `λ ≡ 1`, hence `β = 0` and `γ = Δ`: the write is plain
39    /// exponential-Euler, i.e. Mamba-2's (the note's §4 Lie–Trotter row).
40    ///
41    /// Structural in the same sense as
42    /// [`RotationKind::Real1D`](crate::mamba3::rotation::RotationKind::Real1D),
43    /// and nothing is paid for the absent term: the in-projection spends no `λ`
44    /// channels (so Muon sees no `λ` segment), no `β` is formed, the caches'
45    /// tap slots are `None`, `forward` makes **one** SSD call, and `step` drops
46    /// the second outer product. The two SSD pathways coincide here — with no second
47    /// pass to fuse, single-SSD's composite key scale is `γ` and its
48    /// same-step correction is the whole diagonal — so
49    /// [`forward_single_ssd`](crate::mamba3::mamba3::Mamba3::forward_single_ssd)
50    /// runs the double-SSD code and the caches convert by field identity at
51    /// *every* position, not just at boundaries.
52    None,
53
54    /// **Lag `u`, always**: the tap reads the *same* micro-step of the previous
55    /// **token**, so every tap crosses a token boundary and the pattern is `u`
56    /// parallel token-rate filters, one per micro-step channel. Restores the
57    /// `u = 1` tap semantics at every micro-step.
58    ///
59    /// What is "vertical" is the **tap graph**, not the scan order: the state
60    /// still runs the one flattened chain
61    /// ([`crate::mamba3::product`]), which is what keeps the pattern causal and
62    /// `forward` equal to an unrolled `step`. A scan that truly took every token
63    /// at micro-step `0` before micro-step `1` would have to read token `t+1`
64    /// before finishing token `t` — or keep `u` separate states, which is a
65    /// layer stack (`burn_stack::Layers`), not a tap pattern.
66    ///
67    /// At token resolution the pattern has a closed form: with `Aᵗ` the token
68    /// transition and `ṽᵗⱼ` micro-step `j`'s write transported to the end of its
69    /// own token, the tap's transport `M₍ₜ₋₁,ⱼ₊₁₎:₍ₜ,ⱼ₎` factors through the
70    /// state's own, and the whole `β` side lands **at the token boundary**:
71    ///
72    /// ```text
73    ///   hₜ = Aₜ · ( hₜ₋₁ + Σⱼ νₜ,ⱼ ṽₜ₋₁,ⱼ ) + Σⱼ γₜ,ⱼ ṽₜ,ⱼ ,     ν = (1−λ)Δ
74    /// ```
75    ///
76    /// i.e. **the `u = 1` trapezoid at token resolution, its left endpoint
77    /// promoted from rank 1 to rank `u`** — where
78    /// [`HorizontalCarryOver`](Self::HorizontalCarryOver) taps only the previous
79    /// token's *last* micro-step. `A` is untouched, so it is still `λ`-free
80    /// (`info/trapezoid-as-integration.md` §7).
81    ///
82    /// Costs (§9): key scale `γₛ + (1−λₛ₊ᵤ)Δₛ₊ᵤ`; the tap is transported across
83    /// its own `u`-position gap; the cache's tap buffer becomes a `u`-deep FIFO
84    /// (exactly the previous token). The single-SSD same-step correction widens
85    /// from the diagonal to a `u`-wide band — and that band is **exactly the
86    /// token** at the only positions whose output survives (`j = u−1`), so it is
87    /// one small intra-token contraction outside the chunked kernel rather than
88    /// a wider mask (`crate::mamba3::single_ssd::token_band`).
89    Vertical,
90
91    /// **Lag 1, suppressed at each token's first micro-step**: taps pair
92    /// micro-steps *within* a token and never cross a token boundary. Having no
93    /// cross-token path at all, it cannot do the job the trapezoid was
94    /// introduced for — it is a component of a pattern rather than an
95    /// alternative to one.
96    ///
97    /// Caches like [`HorizontalCarryOver`](Self::HorizontalCarryOver): the same
98    /// one-slot lag-1 buffer, reset at each token's first micro-step. (The reset
99    /// is what makes the carried value inert across a call boundary — the slot
100    /// is layout, not information.)
101    HorizontalReset,
102
103    /// **Lag 1, always** — the default: one
104    /// tap per position of the folded sequence, so `1/u` of the taps cross a
105    /// token boundary and `(u−1)/u` pair two projections of the same token
106    /// (§8). The cache carries one `(B, x)` slot, the last micro-step of the
107    /// last token.
108    #[default]
109    HorizontalCarryOver,
110
111    /// [`Vertical`](Self::Vertical) **and**
112    /// [`HorizontalReset`](Self::HorizontalReset) at once, with its own
113    /// coefficient each instead of the two jobs sharing one `λ`. The **least
114    /// settled** member, and the only one whose tap graph is not a single lag on
115    /// the folded chain: on the `token × micro-step` grid, cell `(t, j)` is
116    /// written by *two* taps — `(t−1, j)` above it and `(t, j−1)` beside it.
117    ///
118    /// What is 2-D is that graph, not the algorithm. Both taps are transported
119    /// across their own gap (`1` and `u` positions of the same folded chain), so
120    /// §9's collapse still applies term by term: the state stays one matrix and
121    /// sample `s` still carries **one** scalar, `γₛ + νʰₛ₊₁ + νᵛₛ₊ᵤ`, into every
122    /// later step. Costs over [`Vertical`](Self::Vertical): one more
123    /// per-micro-step scalar channel and a third nonzero per row of the mask's
124    /// banded factor — the band itself is already `u` wide, and the within-token
125    /// tap never crosses a token boundary, so the cache is
126    /// [`Vertical`](Self::Vertical)'s unchanged.
127    VerticalPlusHorizontalReset,
128}
129
130impl Trapezoid {
131    /// Whether the pattern has a second (`β`) tap at all — `false` only for
132    /// [`None`](Self::None). The predicate every site branches on: no tap means
133    /// no `λ` channels, no `β` coefficient, no tap slots in the cache, and no
134    /// previous-sample term anywhere in the recurrence.
135    pub fn has_beta_tap(self) -> bool {
136        self != Trapezoid::None
137    }
138
139    /// How far back the `β` tap reaches, in **folded** positions
140    /// ([`crate::mamba3::product`]): `0` with no tap, `1` for the lag-1
141    /// patterns, `u` for the lag-`u` ones.
142    ///
143    /// This is the crate's single knob for the two implemented tapping
144    /// patterns — [`HorizontalCarryOver`](Self::HorizontalCarryOver) is `lag =
145    /// 1` and [`Vertical`](Self::Vertical) is `lag = u`, and every site that
146    /// touches the tap (the double-SSD shift, the single-SSD key scale, `step`'s
147    /// FIFO depth, the cache) reads it rather than branching on the pattern. At
148    /// `u = 1` they return the same `1`, which is why the two coincide there.
149    ///
150    /// The tap must be transported across *its own* gap, so a lag-`L` tap
151    /// carries `Πᵈ⁼⁰..ᴸ⁻¹ αₚ₋ᵈ` rather than `αₚ`; that is the condition
152    /// `info/trapezoid-as-integration.md` §9 shows preserves the `Δ̃` collapse,
153    /// hence the single-SSD pathway.
154    pub fn tap_lag(self, micro_steps: usize) -> usize {
155        match self {
156            Trapezoid::None => 0,
157            Trapezoid::HorizontalCarryOver | Trapezoid::HorizontalReset => 1,
158            Trapezoid::Vertical | Trapezoid::VerticalPlusHorizontalReset => micro_steps,
159        }
160    }
161
162    /// Whether this crate implements the pattern today —
163    /// [`HorizontalCarryOver`](Self::HorizontalCarryOver),
164    /// [`Vertical`](Self::Vertical) and [`None`](Self::None) do.
165    pub fn is_implemented(self) -> bool {
166        matches!(
167            self,
168            Trapezoid::HorizontalCarryOver | Trapezoid::Vertical | Trapezoid::None
169        )
170    }
171
172    /// Panic unless [`is_implemented`](Self::is_implemented).
173    ///
174    /// Called from
175    /// [`Mamba3Config::init`](crate::mamba3::mamba3::Mamba3Config::init), the
176    /// block's only constructor, so an unimplemented pattern fails at
177    /// configuration time rather than producing plausible numbers from the
178    /// wrong recurrence.
179    pub fn assert_implemented(self) {
180        assert!(
181            self.is_implemented(),
182            "Trapezoid::{self:?} is not implemented yet — only \
183             Trapezoid::HorizontalCarryOver (the default), Trapezoid::Vertical and \
184             Trapezoid::None have an algorithm; see info/trapezoid-as-integration.md \
185             §9 for what the others cost"
186        );
187    }
188
189    /// How many `(B, x)` tap slots a cache carries for this pattern at
190    /// `micro_steps` — the depth of the FIFO the tap reads from, hence
191    /// [`tap_lag`](Self::tap_lag) exactly: a lag-`L` tap needs the last `L`
192    /// positions live. The SSM state is one matrix whatever this says — only the
193    /// trapezoid's tap buffer changes.
194    ///
195    /// A slot is a *layout*, not a claim that something crosses the call
196    /// boundary through it: [`HorizontalReset`](Self::HorizontalReset) shares
197    /// the carry-over's slot and resets it per token, and the `u` slots of the
198    /// lag-`u` patterns already cover their within-token tap, whose partner is
199    /// one of those same `u` positions.
200    pub fn tap_slots(self, micro_steps: usize) -> usize {
201        self.tap_lag(micro_steps)
202    }
203}

238    /// Unroll `step` over the sequence, from a fresh cache.
239    fn unrolled(model: &Mamba3, input_bsm: &Tensor<3>) -> (Tensor<3>, Mamba3Cache) {
240        let tokens = input_bsm.dims()[1];
241        let mut cache: Option<Mamba3Cache> = None;
242        let mut outs = Vec::new();
243        for t in 0..tokens {
244            let (o, c) = model.step(input_bsm.clone().narrow(1, t, 1).squeeze_dim(1), cache);
245            outs.push(o.unsqueeze_dim::<3>(1));
246            cache = Some(c);
247        }
248        (Tensor::cat(outs, 1), cache.expect("a non-empty sequence"))
249    }

373            let config = cfg_none(kind, 2);

383                        .in_proj

385                        .val()
386                        .grad(&grads)
387                        .expect("in_proj.weight"),

394            let (step_w, step_dt) = grads(unrolled(&model, &x).0);
395            assert!(
396                max_abs_diff(fwd_w, step_w) < 1e-4,

406    /// The semantic claim: `Trapezoid::None` **is** `λ ≡ 1`.
407    ///
408    /// `σ(30)` rounds to exactly `1.0` in f32, so a carry-over block whose `λ`
409    /// columns are zeroed and whose `λ` bias is `30` has `β = 0` and `γ = Δ`
410    /// exactly. Built by appending that dead segment to a `None` block's own
411    /// in-projection, so the two blocks agree on every other weight.
412    #[test]
413    fn none_equals_lambda_saturated_at_one() {
414        use burn::module::Param;
415        let device: burn::prelude::Device = Default::default();
416        let config = cfg()
417            .with_rotation(RotationKind::Real1D)
418            .with_has_proj_bias(true);
419        let none = config.clone().with_trapezoid(Trapezoid::None).init(&device);
420        let mut carry = config.clone().init(&device);
421
422        // Everything but the in-projection is shared outright.
423        carry.dt_bias_h = none.dt_bias_h.clone();
424        carry.d_h = none.d_h.clone();
425        carry.b_norm = none.b_norm.clone();
426        carry.c_norm = none.c_norm.clone();
427        carry.b_bias_hmr = none.b_bias_hmr.clone();
428        carry.c_bias_hmr = none.c_bias_hmr.clone();
429        carry.out_proj = none.out_proj.clone();
430
431        // `Real1D` projects no rotation, so `λ` is the trailing segment: append
432        // a dead one (zero weights, +30 bias) to reach the carry-over width.
433        let nheads = config.nheads();
434        let w = none.in_proj.weight.val();
435        let [d_model, _] = w.dims();
436        carry.in_proj.weight = Param::from_tensor(Tensor::cat(
437            vec![w, Tensor::zeros([d_model, nheads], &device)],
438            1,
439        ));
440        let b = none.in_proj.bias.as_ref().expect("has_proj_bias").val();
441        carry.in_proj.bias = Some(Param::from_tensor(Tensor::cat(
442            vec![b, Tensor::full([nheads], 30.0, &device)],
443            0,
444        )));
445
446        let x = input(&config, 6);
447        let path = Mamba3SsdPath::default();
448        let (out_none, _) = none.forward(x.clone(), None, path.clone());
449        for (label, out) in [
450            ("single", carry.forward_single_ssd(x.clone(), None, &path).0),
451            ("double", carry.forward_double_ssd(x.clone(), None, &path).0),
452        ] {
453            let d = max_abs_diff(out_none.clone(), out);
454            assert!(d < 1e-6, "λ≡1 carry-over ({label}) vs None: {d:.3e}");
455        }
456        // …and the same through the decode path.
457        let d = max_abs_diff(unrolled(&none, &x).0, unrolled(&carry, &x).0);
458        assert!(d < 1e-6, "λ≡1 carry-over vs None, stepped: {d:.3e}");
459    }

598    /// `forward` continued from a cache **`step` wrote** must equal `step` all
599    /// the way — the one check that pins the two down to the *same* FIFO
600    /// convention (slot order and the decay each slot carries) rather than
601    /// merely to two self-consistent ones.
602    #[test]
603    fn vertical_forward_continues_a_stepped_cache() {
604        let device: burn::prelude::Device = Default::default();
605        for kind in [RotationKind::Real1D, RotationKind::Complex2D] {
606            for micro_steps in [2, 3] {
607                let config = cfg_vertical(kind, micro_steps);
608                let model: Mamba3 = config.init(&device);
609                let x = input(&config, 5);
610                let label = format!("{kind:?} u={micro_steps}");
611
612                // Two tokens by `step`, the remaining three by `forward`.
613                let mut cache: Option<Mamba3Cache> = None;
614                for t in 0..2 {
615                    let (_, c) = model.step(x.clone().narrow(1, t, 1).squeeze_dim(1), cache);
616                    cache = Some(c);
617                }
618                let stepped = cache.expect("two tokens").single_ssd().expect("single-ssd");
619                let (out_tail, cache_fwd) = model.forward_single_ssd(
620                    x.clone().narrow(1, 2, 3),
621                    Some(stepped),
622                    &Mamba3SsdPath::default(),
623                );
624
625                let (out_all, cache_all) = unrolled(&model, &x);
626                let cache_all = cache_all.single_ssd().expect("single-ssd");
627                let d = max_abs_diff(out_tail, out_all.narrow(1, 2, 3));
628                assert!(d < 1e-4, "{label}: forward after step: {d:.3e}");
629                let d = max_abs_diff(cache_fwd.ssm_bhpr, cache_all.ssm_bhpr);
630                assert!(d < 1e-4, "{label}: final state: {d:.3e}");
631                let d = max_abs_diff(
632                    cache_fwd.k_state_bumhr.expect("slots"),
633                    cache_all.k_state_bumhr.expect("slots"),
634                );
635                assert!(d < 1e-4, "{label}: tap FIFO B: {d:.3e}");
636                let d = max_abs_diff(
637                    cache_fwd.v_state_buhp.expect("slots"),
638                    cache_all.v_state_buhp.expect("slots"),
639                );
640                assert!(d < 1e-4, "{label}: tap FIFO x (decay convention): {d:.3e}");
641            }
642        }
643    }

645    /// Gradients too, through the default recompute backward — the band
646    /// correction and the seed are on the autodiff path like everything else.
647    #[test]
648    fn vertical_grads_match_step() {
649        let device: burn::prelude::Device = Default::default();
650        for kind in [RotationKind::Real1D, RotationKind::Complex2D] {
651            let config = cfg_vertical(kind, 2);
652            let model: Mamba3 = config.init(&device.clone().autodiff());
653            let x = input(&config, 4);
654            let head = Tensor::random(x.dims(), Distribution::Normal(0.0, 1.0), &device);
655
656            let grads = |out: Tensor<3>| {
657                let loss = (out * Tensor::from_inner(head.clone())).sum();
658                let grads = loss.backward();
659                (
660                    model
661                        .in_proj
662                        .weight
663                        .val()
664                        .grad(&grads)
665                        .expect("in_proj.weight"),
666                    model.dt_bias_h.val().grad(&grads).expect("dt_bias_h"),
667                )
668            };
669            let x = Tensor::from_inner(x);
670            let (fwd_w, fwd_dt) =
671                grads(model.forward(x.clone(), None, Mamba3SsdPath::default()).0);
672            let (step_w, step_dt) = grads(unrolled(&model, &x).0);
673            assert!(
674                max_abs_diff(fwd_w, step_w) < 1e-4,
675                "{kind:?}: d in_proj.weight"
676            );
677            assert!(
678                max_abs_diff(fwd_dt, step_dt) < 1e-4,
679                "{kind:?}: d dt_bias_h"
680            );
681        }
682    }

684    /// At `u = 1` "the same micro-step of the previous token" *is* "the previous
685    /// position", so the two implemented tapping patterns must run identically —
686    /// the same weights, and bit for bit.
687    #[test]
688    fn vertical_is_the_carry_over_at_one_micro_step() {
689        let device: burn::prelude::Device = Default::default();
690        let base = cfg().with_rotation(RotationKind::Complex2D);
691        let carry = base.clone().init(&device);
692        let mut vertical: Mamba3 = base.clone().with_trapezoid(Trapezoid::Vertical).init(&device);
693        // A tap pattern is not a parameterisation: the two blocks have the same
694        // weight shapes, so sharing every weight is enough to compare them.
695        vertical.in_proj = carry.in_proj.clone();
696        vertical.out_proj = carry.out_proj.clone();
697        vertical.dt_bias_h = carry.dt_bias_h.clone();
698        vertical.d_h = carry.d_h.clone();
699        vertical.b_norm = carry.b_norm.clone();
700        vertical.c_norm = carry.c_norm.clone();
701        vertical.b_bias_hmr = carry.b_bias_hmr.clone();
702        vertical.c_bias_hmr = carry.c_bias_hmr.clone();
703
704        let x = input(&base, 6);
705        let path = Mamba3SsdPath::default();
706        for (label, a, b) in [
707            (
708                "single",
709                carry.forward_single_ssd(x.clone(), None, &path).0,
710                vertical.forward_single_ssd(x.clone(), None, &path).0,
711            ),
712            (
713                "double",
714                carry.forward_double_ssd(x.clone(), None, &path).0,
715                vertical.forward_double_ssd(x.clone(), None, &path).0,
716            ),
717            ("step", unrolled(&carry, &x).0, unrolled(&vertical, &x).0),
718        ] {
719            assert_eq!(
720                max_abs_diff(a, b),
721                0.0,
722                "{label}: Vertical and HorizontalCarryOver coincide at u = 1"
723            );
724        }
725    }

728    /// tap, one slot for the lag-1 patterns, `u` for the lag-`u` ones.
729    #[test]
730    fn tap_slots_follow_the_lag() {

737        // patterns that degenerate to each other agree on the buffer too.

739        assert_eq!(Trapezoid::VerticalPlusHorizontalReset.tap_slots(1), 1);
