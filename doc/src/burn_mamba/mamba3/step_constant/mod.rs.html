1//! # Constant-input stepping shortcut — `step_infinite`
2//!
3//! When the **same token** is fed to [`Mamba3::step`] over and over, every
4//! data-dependent quantity is the same at each step: the trapezoid
5//! coefficients `α`, `β`, `γ`, the QK-normed `b`/`c`, and the per-step
6//! rotation increment (angle `θ̂` for `Complex2D`, unit quaternion `q` for
7//! `Quaternion4D`). Only the *cumulative* rotation moves — by that same
8//! increment each step — so with `P` the per-step rotation operator and `R₁`
9//! the cumulative rotation at the first constant step,
10//!
11//! ```text
12//!   Bₜ = R₁ Pᵗ⁻¹ b ,   Cₜ = R₁ Pᵗ⁻¹ c ,
13//!   hₜ = α hₜ₋₁ + x ⊗ (β Bₜ₋₁ + γ Bₜ)            (t ≥ 2)
14//! ```
15//!
16//! and the unrolled steps collapse to a **matrix geometric series** in
17//! `α P⁻¹` (spectral radius `α < 1`, since `a_floor > 0` and `Δ > 0`).
18//!
19//! `P` is block-diagonal: per RoPE pair it is the complex scalar `e^{iθ̂}`, per
20//! quaternion block left-multiplication by `w = q*`. In both cases all the
21//! factors live in one **abelian** subalgebra (powers of a single rotation
22//! commute — for quaternions, `span{1, û} ≅ ℂ`), so the series is a handful of
23//! scalar complex / quaternion ops per (head, pair/block): `n` steps cost O(1).
24//!
25//! In the readout `y_n = Cₙᵀ h_n + D x` the unbounded phase cancels
26//! (`⟨R c, R v⟩ = ⟨c, v⟩`), leaving only the *relative* rotation `P⁻¹`. As
27//! `n → ∞` the initial-state term and the partial-sum correction decay like
28//! `αⁿ`, so the **output converges** even though the state `h` orbits forever:
29//!
30//! ```text
31//!   y_∞ = xᵀ · cᵀ (γ + β P⁻¹)(I − α P⁻¹)⁻¹ b  +  D x
32//! ```
33//!
34//! — the block's stationary fixed point, independent of any starting cache.
35//! [`Mamba3::step_infinite`] evaluates exactly this (and therefore takes and
36//! returns no cache).
37//!
38//! ## MambaProduct (`micro_steps = u > 1`)
39//!
40//! A constant token still drives `u` *different* micro-steps, so the per-token
41//! map is a product `A·P = (∏ⱼ αⱼ)·P_{u−1}⋯P₀` and the token writes `u` pairs
42//! `(bⱼ, xⱼ)` at `u` different points along it. Collecting the trapezoid's two
43//! taps by which pair they write gives one weight per pair,
44//!
45//! ```text
46//!   aⱼ = ∏_{j'>j} α_{j'} ,   cⱼ = aⱼγⱼ + a_{j+1}β_{j+1}   (j < u−1)
47//! ```
48//!
49//! and the last pair keeps its taps apart, because its β partner is the *next*
50//! token's micro-step 0 and therefore sits one turn further back in the same
51//! geometric series (`γ_{u−1} + a₀β₀ P⁻¹`). The limit is then a sum of `u` terms
52//! of exactly the shape above:
53//!
54//! ```text
55//!   y_∞ = Σⱼ xⱼᵀ · cᵀ Wⱼ bⱼ + D x_{u−1} ,
56//!   Wⱼ = cⱼ · Qⱼ P⁻¹ (I − A P⁻¹)⁻¹  (j < u−1) ,   Q_j = Pⱼ⋯P₀
57//!   W_{u−1} = (γ_{u−1} + a₀β₀ P⁻¹)(I − A P⁻¹)⁻¹
58//! ```
59//!
60//! `Qⱼ P⁻¹` is the rotation still *to come* after micro-step `j`, and at `u = 1`
61//! the whole thing collapses back to the single term above.
62//!
63//! **This exists only for the abelian kinds.** The readout at token `t` sees the
64//! pair written at token `t−n` through `P⁻ᵗ Qⱼ Pᵗ⁻ⁿ⁻¹`, which is a function of
65//! `n` alone iff `Qⱼ` commutes with `P`. For
66//! [`Quaternion4D`](crate::mamba3::rotation::RotationKind::Quaternion4D) and
67//! [`Rotor4D`](crate::mamba3::rotation::RotationKind::Rotor4D) it does not: the
68//! conjugation keeps turning with `t` and the output is almost-periodic, not
69//! convergent. [`Mamba3::step_infinite`] asserts against that combination —
70//! there is no limit to return, which is a property of the recurrence and not a
71//! gap here.
72//!
73//! Numerics: the rotation angle is reduced mod `2π` with the value-exact
74//! [`wrap_angle`]; the geometric denominators satisfy
75//! `|1 − α e^{−iθ̂}|² ≥ (1 − α)²` and are floored by
76//! [`div_eps`](burn_stack::utils::div_eps). When `α → 1` *and* `θ̂ → 0` the series
77//! value `(β+γ)/(1−α)` stays finite but loses fp32 precision once `1 − α` nears
78//! the epsilon floor — the same regime where the unrolled recurrence itself
79//! accumulates near-undamped terms.
80

98    /// Stationary **fixed point** of the block under a constant token: the
99    /// limit of `step(input, …)` outputs as the same `input_bd` is stepped
100    /// forever.
101    ///
102    /// Closed form, O(1) in the horizon (see the module header for the
103    /// derivation). The limit forgets any starting state (`αⁿ → 0`) and the
104    /// SSM state itself never converges (it keeps rotating; only the output
105    /// does), so this takes **no cache and returns none**.
106    ///
107    /// Both rotation kinds and both SSD pathways are covered (the recurrence
108    /// is pathway-agnostic at boundaries). Differentiable; gradients are the
109    /// limit of the unrolled gradients.
110    ///
111    /// # Shapes
112    /// - `input_bd` : `[batch, d_model]`
113    /// - output     : `[batch, d_model]`
114    pub fn step_infinite(&self, input_bd: Tensor<2>) -> Tensor<2> {
115        let proj = self.step_project(input_bd);
116        let u = proj.micro_steps;
117        let spec = self.rotation_spec();
118        let [batch, mimo_rank, nheads, _state_rank] = proj.c_bmhr.dims();
119        assert!(
120            u == 1 || matches!(spec.kind, RotationKind::Real1D | RotationKind::Complex2D),
121            "step_infinite has no limit to return at micro_steps = {u} with {:?}: the \
122             per-token rotation product `P` and its partial products `Qⱼ` do not commute, so \
123             the read-to-write relative rotation `P⁻ᵗ Qⱼ Pᵗ⁻ⁿ⁻¹` keeps turning with `t` and \
124             the output is almost-periodic rather than convergent. Use micro_steps = 1, or an \
125             abelian RotationKind (Real1D / Complex2D). See `crate::mamba3::product`.",
126            spec.kind
127        );
128
129        let micros: Vec<MicroProjection> = (0..u).map(|j| proj.micro(j)).collect();
130        let eps = div_eps(micros[0].alpha_bh.dtype());
131
132        // Suffix decay `aⱼ = ∏_{j'>j} α_{j'}` — how much a write at micro-step
133        // `j` has decayed by the token's end — and `A = ∏ⱼ αⱼ`, the token's own
134        // decay. `a_{u−1} = 1`: the last micro-step's write is not decayed again
135        // before the readout.
136        let mut suffix_bh: Vec<Tensor<2>> =
137            vec![Tensor::ones([batch, nheads], &micros[0].alpha_bh.device()); u];
138        for j in (0..u.saturating_sub(1)).rev() {
139            suffix_bh[j] = suffix_bh[j + 1].clone() * micros[j + 1].alpha_bh.clone();
140        }
141        let total_decay_bh = suffix_bh[0].clone() * micros[0].alpha_bh.clone();
142        let one_minus_a_bh = (-total_decay_bh.clone() + 1.0).clamp_min(eps);
143
144        // How much of the token's write lands on micro-step `j`'s `(b, x)` pair.
145        // Two taps write it: `j`'s own γ tap, and `j+1`'s β tap (the trapezoid's
146        // left endpoint). The last pair is special — its β partner is the *next
147        // token's* micro-step 0, which contributes one extra factor of `P⁻¹`
148        // (its write sits one token later in the same geometric series), so it
149        // keeps the two taps apart.
150        let pair_weight_bh = |j: usize| {
151            let own = suffix_bh[j].clone() * micros[j].gamma_bh.clone();
152            if j + 1 < u {
153                own + suffix_bh[j + 1].clone() * micros[j + 1].beta_bh.clone()
154            } else {
155                own
156            }
157        };
158        // The wrapped β weight attached to the last pair, `a₀·β₀`.
159        let wrap_bh = suffix_bh[0].clone() * micros[0].beta_bh.clone();
160
161        let rot = |r: Option<Tensor<2>>| r.expect("a rotating kind projects rotation channels");
162        let mimo_x_hmp = self.mimo_x_hmp.as_ref().map(|p| p.val());
163        let siso = self.use_siso_decode_kernels();
164
165        // Per-pair/block readout factor. For the last pair it is the familiar
166        // `(γ + β P⁻¹)(I − A P⁻¹)⁻¹`; for the others the weight is a scalar and
167        // the rotation is the *remaining* one, `Qⱼ P⁻¹ = (P_{u−1}⋯P_{j+1})⁻¹`.
168        // The cumulative rotation cancels against `Cₙ` (orthogonality), so only
169        // these relative turns survive.
170        let b_eff = |j: usize| -> Tensor<4> {
171            let b_bmhr = micros[j].b_bmhr.clone();
172            let last = j + 1 == u;
173            // Rotation-free channels: the plain real geometric series.
174            let tail_num_bh = if last {
175                pair_weight_bh(j) + wrap_bh.clone()
176            } else {
177                pair_weight_bh(j)
178            };
179            let tail_bh = tail_num_bh / one_minus_a_bh.clone();
180            match spec.kind {
181                // A real transition: every channel is `tail`.
182                RotationKind::Real1D => b_bmhr * tail_bh.unsqueeze_dims::<4>(&[1, 3]),
183                RotationKind::Complex2D => {
184                    // The same per-step increments `forward`/`step` use — one
185                    // definition, so the fixed point cannot drift from the
186                    // recurrence it is the limit of. `Θ` is the token's total
187                    // turn, `Φⱼ` the part of it still to come after `j`.
188                    let theta = |k: usize| {
189                        angle_increment::<2, 3>(
190                            rot(micros[k].rot_ba.clone()),
191                            micros[k].dt_bh.clone(),
192                            spec.range,
193                        )
194                    };
195                    let mut total_bha = theta(0);
196                    for k in 1..u {
197                        total_bha = total_bha + theta(k);
198                    }
199                    let (cos_t, sin_t) = cos_sin(total_bha.clone());
200                    let a_bh1 = total_decay_bh.clone().unsqueeze_dim::<3>(2);
201                    let den_re = -a_bh1.clone() * cos_t.clone() + 1.0;
202                    let den_im = a_bh1 * sin_t.clone();
203                    let (num_re, num_im) = if last {
204                        // γ + (a₀β₀) e^{−iΘ}
205                        let w_bh1 = wrap_bh.clone().unsqueeze_dim::<3>(2);
206                        let g_bh1 = pair_weight_bh(j).unsqueeze_dim::<3>(2);
207                        (
208                            g_bh1 + w_bh1.clone() * cos_t,
209                            -w_bh1 * sin_t,
210                        )
211                    } else {
212                        // cⱼ e^{−iΦⱼ},  Φⱼ = Σ_{j'>j} θ̂_{j'}
213                        let mut phi_bha = theta(j + 1);
214                        for k in j + 2..u {
215                            phi_bha = phi_bha + theta(k);
216                        }
217                        let (cos_p, sin_p) = cos_sin(phi_bha);
218                        let c_bh1 = pair_weight_bh(j).unsqueeze_dim::<3>(2);
219                        (c_bh1.clone() * cos_p, -c_bh1 * sin_p)
220                    };
221                    let (m_re, m_im) = complex_div(num_re, num_im, den_re, den_im);
222                    mul_complex_partial(b_bmhr, m_re, m_im, tail_bh, self.rope_dim, mimo_rank == 1)
223                }
224                // The non-abelian kinds are reachable only at `u == 1` (asserted
225                // above), where `j` is the one and only pair and the weights
226                // collapse to the plain `(γ, β, α)`.
227                RotationKind::Rotor4D => {
228                    let m = &micros[0];
229                    let g_bhk3 = generator_increment::<2, 3, 4>(
230                        rot(m.rot_ba.clone()),
231                        m.dt_bh.clone(),
232                        self.num_rotation_blocks(),
233                        spec.range,
234                    );
235                    let qp_bhk4 = quat_from_scaled_axis::<4>(g_bhk3);
236                    let (q_bhj4, p_bhj4) = split_rotor(qp_bhk4); // M(v) = q ⊗ v ⊗ p̄
237                    rotor_resolvent_partial(
238                        b_bmhr,
239                        q_bhj4,
240                        p_bhj4,
241                        m.alpha_bh.clone(),
242                        m.beta_bh.clone(),
243                        m.gamma_bh.clone(),
244                        tail_bh,
245                        spec.rope_dim,
246                    )
247                }
248                RotationKind::Quaternion4D => {
249                    let m = &micros[0];
250                    let g_bhj3 = generator_increment::<2, 3, 4>(
251                        rot(m.rot_ba.clone()),
252                        m.dt_bh.clone(),
253                        self.num_quat_blocks,
254                        spec.range,
255                    );
256                    let q_bhj4 = quat_from_scaled_axis::<4>(g_bhj3); // P⁻¹ ↔ q
257                    let alpha_bh11 = m.alpha_bh.clone().unsqueeze_dims::<4>(&[2, 3]);
258                    let beta_bh11 = m.beta_bh.clone().unsqueeze_dims::<4>(&[2, 3]);
259                    let gamma_bh11 = m.gamma_bh.clone().unsqueeze_dims::<4>(&[2, 3]);
260                    // (γ + β q) ⊗ (1 − α q)⁻¹  — all in the abelian subalgebra of q.
261                    let num = quat_scalar_affine(gamma_bh11, beta_bh11, q_bhj4.clone());
262                    let den_inv = quat_inv(quat_one_minus(q_bhj4 * alpha_bh11));
263                    let f_bhj4 = quat_mul(num, den_inv);
264                    // As in `rotate_bc_step`, the rotated width comes from
265                    // `rope_dim` (a partial rotation turns whole 4-blocks).
266                    mul_quat_partial(b_bmhr, f_bhj4, tail_bh, spec.rope_dim)
267                }
268            }
269        };
270
271        // y_∞[m] = Σⱼ Σ_m' ⟨c[m], Wⱼ·bⱼ[m']⟩ · x_vals,ⱼ[m']  — one term per
272        // micro-step, then the shared D-skip/gate/out-projection on the *last*
273        // micro-step's values (the one the readout is contemporaneous with).
274        let mut out_m_bmhp: Option<Tensor<4>> = None;
275        let mut last_x_vals_bmhp: Option<Tensor<4>> = None;
276        for j in 0..u {
277            let b_eff_bmhr = b_eff(j);
278            san(&b_eff_bmhr);
279            let x_vals_bmhp = helpers::build_v_with_mimo::<3, 4>(
280                micros[j].x_bhp.clone(),
281                mimo_x_hmp.as_ref(),
282                1,
283            );
284            let term_bmhp = if siso {
285                // SISO: the Gram matrix is the scalar ⟨c, W·b⟩ per (batch,
286                // nheads), so both matmuls degenerate — contract `state_rank`
287                // with a reduction and broadcast over `per_head_dim`.
288                let gram_bmh1: Tensor<4> = (proj.c_bmhr.clone() * b_eff_bmhr).sum_dim(3);
289                x_vals_bmhp.clone() * gram_bmh1
290            } else {
291                let gram_bhmm = {
292                    let c_bhmr = proj.c_bmhr.clone().swap_dims(1, 2);
293                    let b_bhrm = b_eff_bmhr.permute([0, 2, 3, 1]);
294                    c_bhmr.matmul(b_bhrm) // [batch, nheads, mimo_rank, mimo_rank']
295                };
296                let x_bhmp = x_vals_bmhp.clone().swap_dims(1, 2);
297                gram_bhmm.matmul(x_bhmp).swap_dims(1, 2)
298            };
299            out_m_bmhp = Some(match out_m_bmhp {
300                Some(acc) => acc + term_bmhp,
301                None => term_bmhp,
302            });
303            last_x_vals_bmhp = Some(x_vals_bmhp);
304        }
305        let out_m_bmhp = out_m_bmhp.expect("micro_steps ≥ 1");
306        assert_eq!(
307            [batch, mimo_rank, nheads, self.per_head_dim()],
308            out_m_bmhp.dims()
309        );
310        san(&out_m_bmhp);
311
312        self.step_finish(
313            out_m_bmhp,
314            last_x_vals_bmhp.expect("micro_steps ≥ 1"),
315            proj.z_bi,
316        )
317    }
318}

324/// `(cos, sin)` of an angle tensor, reduced mod `2π` first (value-exact).
325fn cos_sin(angle_bha: Tensor<3>) -> (Tensor<3>, Tensor<3>) {
326    let a = wrap_angle(angle_bha);
327    (a.clone().cos(), a.sin())
328}

330/// Component-wise complex quotient; `|den|²` floored by `div_eps`.
331fn complex_div(
332    nr: Tensor<3>,
333    ni: Tensor<3>,
334    dr: Tensor<3>,
335    di: Tensor<3>,
336) -> (Tensor<3>, Tensor<3>) {
337    let eps = div_eps(dr.dtype());
338    let d2 = (dr.clone() * dr.clone() + di.clone() * di.clone()).clamp_min(eps);
339    (
340        (nr.clone() * dr.clone() + ni.clone() * di.clone()) / d2.clone(),
341        (ni * dr - nr * di) / d2,
342    )
343}

345/// Multiply the rotation-active entries of `x` by the complex scalar
346/// `(re, im)` per pair — same pairing conventions as [`apply_rope_partial`] —
347/// and the pass-through entries by the real scalar `tail`.
348///
349/// `re`/`im` are `[batch, nheads, num_rope_angles]` (broadcast over the
350/// `mimo_rank` axis); `tail` is `[batch, nheads]`.
351fn mul_complex_partial(
352    x_bmhr: Tensor<4>,
353    re_bha: Tensor<3>,
354    im_bha: Tensor<3>,
355    tail_bh: Tensor<2>,
356    rope_dim: usize,
357    rotate_pairwise: bool,
358) -> Tensor<4> {
359    let [batch, mimo_rank, nheads, state_rank] = x_bmhr.dims();
360    let tail_b1h1 = tail_bh.unsqueeze_dims::<4>(&[1, 3]);
361    debug_assert!(rope_dim > 0, "a rotating kind turns at least one pair");
362    let re_b1ha = re_bha.unsqueeze_dim::<4>(1);
363    let im_b1ha = im_bha.unsqueeze_dim::<4>(1);
364
365    if rotate_pairwise {
366        // Interleaved (SISO/NeoX): pairs are local, so the first `rope_dim`
367        // entries can be handled standalone.
368        let n2 = rope_dim / 2;
369        let head = x_bmhr.clone().narrow(3, 0, rope_dim);
370        let head_pairs = head.reshape([batch, mimo_rank, nheads, n2, 2]);
371        let x0 = head_pairs.clone().narrow(4, 0, 1).squeeze_dim::<4>(4);
372        let x1 = head_pairs.narrow(4, 1, 1).squeeze_dim::<4>(4);
373        let x0m = re_b1ha.clone() * x0.clone() - im_b1ha.clone() * x1.clone();
374        let x1m = im_b1ha * x0 + re_b1ha * x1;
375        let head = Tensor::cat(
376            vec![x0m.unsqueeze_dim::<5>(4), x1m.unsqueeze_dim::<5>(4)],
377            4,
378        )
379        .reshape([batch, mimo_rank, nheads, rope_dim]);
380        if rope_dim == state_rank {
381            head
382        } else {
383            let tail = x_bmhr.narrow(3, rope_dim, state_rank - rope_dim) * tail_b1h1;
384            Tensor::cat(vec![head, tail], 3)
385        }
386    } else {
387        // Half-and-half (MIMO/GPT-J): entry `i` pairs with `i + state_rank/2`;
388        // only the first `rope_dim / 2` pairs are active.
389        let half = state_rank / 2;
390        let active = rope_dim / 2;
391        let x_h1 = x_bmhr.clone().narrow(3, 0, half);
392        let x_h2 = x_bmhr.narrow(3, half, half);
393        let x_h1_rope = x_h1.clone().narrow(3, 0, active);
394        let x_h2_rope = x_h2.clone().narrow(3, 0, active);
395        let h1_m = re_b1ha.clone() * x_h1_rope.clone() - im_b1ha.clone() * x_h2_rope.clone();
396        let h2_m = im_b1ha * x_h1_rope + re_b1ha * x_h2_rope;
397        if active == half {
398            Tensor::cat(vec![h1_m, h2_m], 3)
399        } else {
400            let h1_pass = x_h1.narrow(3, active, half - active) * tail_b1h1.clone();
401            let h2_pass = x_h2.narrow(3, active, half - active) * tail_b1h1;
402            Tensor::cat(vec![h1_m, h1_pass, h2_m, h2_pass], 3)
403        }
404    }
405}

411/// `1 − sq` for a (scalar-scaled) quaternion `sq`: negate, add 1 to the real
412/// part.
413fn quat_one_minus(sq_bhj4: Tensor<4>) -> Tensor<4> {
414    let w = -sq_bhj4.clone().narrow(3, 0, 1) + 1.0;
415    let xyz = -sq_bhj4.narrow(3, 1, 3);
416    Tensor::cat(vec![w, xyz], 3)
417}

419/// `a + b·q` for per-head scalars `a`, `b` (`[batch, nheads, 1, 1]`) and a
420/// quaternion tensor `q`.
421fn quat_scalar_affine(a_bh11: Tensor<4>, b_bh11: Tensor<4>, q_bhj4: Tensor<4>) -> Tensor<4> {
422    let w = a_bh11 + b_bh11.clone() * q_bhj4.clone().narrow(3, 0, 1);
423    let xyz = b_bh11 * q_bhj4.narrow(3, 1, 3);
424    Tensor::cat(vec![w, xyz], 3)
425}

427/// Quaternion inverse `q⁻¹ = q* / ‖q‖²`, with `‖q‖²` floored by `div_eps`.
428/// (Used on `1 − α q`, whose norm is bounded below by `1 − α > 0`.)
429fn quat_inv(q_bhj4: Tensor<4>) -> Tensor<4> {
430    let eps = div_eps(q_bhj4.dtype());
431    let n2 = (q_bhj4.clone() * q_bhj4.clone()).sum_dim(3).clamp_min(eps);
432    quat_conj(q_bhj4) / n2
433}

435/// Left-multiply the first `rope_width` state-rank entries of `x` by the (not
436/// necessarily unit) quaternion `f` per block, and scale the pass-through
437/// entries by the real scalar `tail` — the quaternion analogue of
438/// [`mul_complex_partial`].
439fn mul_quat_partial(
440    x_bmhr: Tensor<4>,
441    f_bhj4: Tensor<4>,
442    tail_bh: Tensor<2>,
443    rope_width: usize,
444) -> Tensor<4> {
445    let [batch, mimo_rank, nheads, state_rank] = x_bmhr.dims();
446    let blocks = f_bhj4.dims()[2];
447    let tail_b1h1 = tail_bh.unsqueeze_dims::<4>(&[1, 3]);
448    debug_assert!(rope_width > 0, "a rotating kind turns at least one block");
449    let f_bmhj4 = f_bhj4
450        .unsqueeze_dim::<5>(1)
451        .expand([batch, mimo_rank, nheads, blocks, 4]);
452    if rope_width == state_rank {
453        rotate_state_rank_blocks::<4, 5>(x_bmhr, f_bmhj4)
454    } else {
455        let head =
456            rotate_state_rank_blocks::<4, 5>(x_bmhr.clone().narrow(3, 0, rope_width), f_bmhj4);
457        let tail = x_bmhr.narrow(3, rope_width, state_rank - rope_width) * tail_b1h1;
458        Tensor::cat(vec![head, tail], 3)
459    }
460}

462// ---------------------------------------------------------------------------
463// Rotor (`SO(4)`) helpers — the two-sided resolvent, per block
464// ---------------------------------------------------------------------------
465
466/// Apply `(γ + βM)(I − αM)⁻¹` to the rotation-active entries of `x`, where
467/// `M(v) = q ⊗ v ⊗ p̄` is the per-step `SO(4)` rotation of
468/// [`RotationKind::Rotor4D`], and scale the pass-through entries by the real
469/// scalar `tail` — the two-sided analogue of [`mul_quat_partial`].
470///
471/// Two-sided, the geometric series no longer lives in a commutative subalgebra
472/// (that shortcut is what [`quat_inv`] exploits for `Quaternion4D`), so the
473/// resolvent is taken over `ℝ⁴` by **Cayley–Hamilton**. `M` is orthogonal with
474/// characteristic polynomial `λ⁴ − c₁λ³ + c₂λ² − c₁λ + 1`, and its two plane
475/// angles are `a∓b` for the half-angles `a`, `b` of `q` and `p` (the standard
476/// `SO(4) ≅ (SU(2)×SU(2))/±1` decomposition — the axes fix the invariant
477/// *planes*, only the half-angles fix the *angles*), so with
478/// `k₁ = cos(a−b)`, `k₂ = cos(a+b)`:
479///
480/// ```text
481///   c₁ = 2(k₁ + k₂) = tr M ,   c₂ = 2 + 4k₁k₂ ,
482///   det(I − αM) = (1 − 2αk₁ + α²)(1 − 2αk₂ + α²) ,
483///   (I − αM)⁻¹  = (e₀ + e₁M + e₂M² + e₃M³) / det(I − αM)
484/// ```
485///
486/// with `e₃ = α³`, `e₂ = α² − c₁α³`, `e₁ = α − c₁α² + c₂α³`,
487/// `e₀ = 1 − c₁α + c₂α² − c₁α³` (the divided-difference form
488/// `q(λ) = (χ(μ)−χ(λ))/(μ−λ)` at `μ = 1/α`, rescaled). The cubic is evaluated
489/// by Horner **on the vector**, so no `4×4` matrix is ever materialised: each
490/// application of `M` is two quaternion products. `k₁ = k₂ = 1` (no rotation)
491/// collapses the whole thing to `(β+γ)/(1−α)`, i.e. `tail`.
492///
493/// Numerics: the determinant is formed factor-wise as `(1−α)² + 2α(1−kᵢ)`,
494/// which is manifestly `≥ (1−α)²` and free of the cancellation the expanded
495/// quartic would suffer; the numerator carries the same `α → 1` precision
496/// caveat as the abelian branch (see the module header).
497#[allow(clippy::too_many_arguments)]
498fn rotor_resolvent_partial(
499    x_bmhr: Tensor<4>,
500    q_bhj4: Tensor<4>,
501    p_bhj4: Tensor<4>,
502    alpha_bh: Tensor<2>,
503    beta_bh: Tensor<2>,
504    gamma_bh: Tensor<2>,
505    tail_bh: Tensor<2>,
506    rope_width: usize,
507) -> Tensor<4> {
508    let [batch, mimo_rank, nheads, state_rank] = x_bmhr.dims();
509    let blocks = q_bhj4.dims()[2];
510    let tail_b1h1 = tail_bh.unsqueeze_dims::<4>(&[1, 3]);
511    debug_assert!(rope_width > 0, "a rotating kind turns at least one block");
512    assert_eq!(
513        rope_width,
514        blocks * 4,
515        "the rotated width is a whole number of quaternion blocks"
516    );
517    let eps = div_eps(alpha_bh.dtype());
518
519    // Per-block plane cosines. `Re q = cos a`, `‖Im q‖ = |sin a|`; a sign flip
520    // of `sin a` only swaps k₁ ↔ k₂, and every quantity below is symmetric in
521    // the two, so the absolute value costs nothing.
522    let per_block = |t: Tensor<4>| t.unsqueeze_dim::<5>(1); // [b,h,J,1] → [b,1,h,J,1]
523    let wc = per_block(q_bhj4.clone().narrow(3, 0, 1) * p_bhj4.clone().narrow(3, 0, 1));
524    let ss = per_block(
525        safe_norm(q_bhj4.clone().narrow(3, 1, 3)) * safe_norm(p_bhj4.clone().narrow(3, 1, 3)),
526    );
527    let k1 = wc.clone() + ss.clone();
528    let k2 = wc - ss;
529
530    // Scalars, broadcast over (mimo, block, component).
531    let a = alpha_bh.unsqueeze_dims::<5>(&[1, 3, 4]);
532    let beta = beta_bh.unsqueeze_dims::<5>(&[1, 3, 4]);
533    let gamma = gamma_bh.unsqueeze_dims::<5>(&[1, 3, 4]);
534    let a2 = a.clone() * a.clone();
535    let a3 = a2.clone() * a.clone();
536    let c1 = (k1.clone() + k2.clone()) * 2.0;
537    let c2 = k1.clone() * k2.clone() * 4.0 + 2.0;
538    let one_minus_a2 = (-a.clone() + 1.0) * (-a.clone() + 1.0);
539    let det = (one_minus_a2.clone() + (-k1 + 1.0) * a.clone() * 2.0)
540        * (one_minus_a2 + (-k2 + 1.0) * a.clone() * 2.0);
541    let det = det.clamp_min(eps);
542    let e3 = a3.clone();
543    let e2 = a2.clone() - c1.clone() * a3.clone();
544    let e1 = a.clone() - c1.clone() * a2.clone() + c2.clone() * a3.clone();
545    let e0 = -c1.clone() * a + c2 * a2 - c1 * a3 + 1.0;
546
547    // M(v) = q ⊗ v ⊗ p̄, on the block-split view of the rotated entries.
548    let expand = |q: Tensor<4>| {
549        q.unsqueeze_dim::<5>(1)
550            .expand([batch, mimo_rank, nheads, blocks, 4])
551    };
552    let ql = expand(q_bhj4);
553    let qr = expand(quat_conj(p_bhj4));
554    let m = |v: Tensor<5>| quat_mul(quat_mul(ql.clone(), v), qr.clone());
555
556    let head = x_bmhr
557        .clone()
558        .narrow(3, 0, rope_width)
559        .reshape([batch, mimo_rank, nheads, blocks, 4]);
560    // Horner on the vector: u = (e₀ + e₁M + e₂M² + e₃M³) x.
561    let u = head.clone() * e3;
562    let u = m(u) + head.clone() * e2;
563    let u = m(u) + head.clone() * e1;
564    let u = m(u) + head * e0;
565    let out = (u.clone() * gamma + m(u) * beta) / det;
566    let out = out.reshape([batch, mimo_rank, nheads, rope_width]);
567
568    if rope_width == state_rank {
569        out
570    } else {
571        let tail = x_bmhr.narrow(3, rope_width, state_rank - rope_width) * tail_b1h1;
572        Tensor::cat(vec![out, tail], 3)
573    }
574}
