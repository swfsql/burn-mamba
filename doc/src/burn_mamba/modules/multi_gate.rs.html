1//! Multi-Gate Residuals (MGR) — a depth-wise residual scheme replacing the plain
2//! additive skip of a [`Layers`](crate::modules::Layers) stack.
3//!
4//! Instead of one residual stream, MGR keeps up to **`n_stream` parallel
5//! streams** `sᵢ`. The stack input is stream 1; the streams then grow and are
6//! mixed in two phases (paper §"Our Architecture"), with one
7//! [`MultiGateResidual`] per layer:
8//!
9//! * **Accumulation** — while fewer than `n_stream` streams exist, the layer
10//!   output `F_l` is *appended* as a new stream ([`MultiGateResidual::accumulate`]). This is
11//!   what makes the streams **distinct**: after the first `n_stream−1` layers
12//!   they hold `[x, F₀, …, F_{n−2}]` (a bounded AttnRes over the early layers).
13//! * **Mixing** — from then on the stream count is capped and each stream is
14//!   interpolated towards `F_l` by its own gate ([`MultiGateResidual::forward`]).
15//!
16//! Both phases end in the same aggregator, and both are convex (norm-bounded):
17//!
18//! 1. **Mixer** (independent sigmoid gate) — each stream is interpolated towards
19//!    the current layer output `F_l` by a per-stream gate `βᵢ`:
20//!    `sᵢ' = (1−βᵢ)·sᵢ + βᵢ·F_l`, with
21//!    `βᵢ = σ( (w⁽ᵝ⁾ · RMSNorm(sᵢ))/√d + b⁽ᵝ⁾ᵢ )`.
22//! 2. **Aggregator** (depth-wise attention pooling, "AttnPool") — the updated
23//!    streams are pooled into the next layer's input `h` by a softmax over
24//!    streams: `αᵢ = softmax_i( (w⁽ᵅ⁾ · RMSNorm(sᵢ'))/√d )`, `h = Σᵢ αᵢ·sᵢ'`.
25//!
26//! Both `w` vectors are learnable in `ℝ^d` (init zero), the RMSNorm is
27//! parameter-free, and `b⁽ᵝ⁾` is a per-stream learnable bias. Only the
28//! **independent** (sigmoid) gate is implemented; the paper's competitive
29//! (softmax) variant is omitted.
30//!
31//! Seeding every stream with a *copy* of the stack input instead would be a
32//! symmetry the model can never break — identical streams give identical
33//! scores, hence identical gates and gradients, collapsing MGR to a single
34//! lerped stream. The accumulation phase is what avoids that.
35//!
36//! MGR is purely **point-wise over `(batch, sequence)`** — the streams only
37//! evolve along *depth*, never along the sequence — so `forward` over a sequence
38//! equals `step` unrolled token-by-token, and `step` carries no extra state
39//! (each token rebuilds its own depth-streams).
40//!
41//! **Gate-bias initialisation.** Following Highway Networks, a negative
42//! `init_bias` biases the gates towards *carry* (small updates) at the start of
43//! training. The paper scales it with the number of *mixing* layers `L`
44//! (total layers minus the `n−1` accumulating ones) — see
45//! [`MultiGateResidualConfig::depth_init_bias`]. `init_bias` is taken directly,
46//! so the caller applies that formula (or picks its own). Default `0` (gates
47//! open at `σ(0)=0.5`).
48//!
49//! That formula assumes one *shared* timescale for all `n` streams, which is a
50//! long-training-run choice: it buys stability by making every layer's
51//! contribution small (`σ(b) ∝ 1/√L`), and the streams then differ only by what
52//! they were seeded with. [`MultiGateResidualConfig::init_bias_step`] instead
53//! spreads the initial biases over the streams — an update-biased stream down to
54//! a carry-biased one — so the set covers several depth-timescales from step
55//! zero. `0` keeps the paper's uniform init.
56//!
57//! **Output scale.** Every step here is a convex combination, and the aggregator
58//! is a *mean* over the `n` streams, so the stack's output stays `O(1)` where a
59//! plain additive skip grows it with depth (`x + Σ F_l`) — measured at ~15×
60//! larger for a 16-layer stack. Nothing downstream is wrong with either, but a
61//! head initialised for one sees the other far off its range, and closing that
62//! gap by training `out_proj` alone takes many steps. A norm before the head
63//! makes it moot: [`VocabNetwork`] always has one, while on a [`LatentNetwork`]
64//! it is the opt-in [`final_norm`]. Prefer enabling it when pairing MGR with a
65//! latent head, or expect a slow start.
66//!
67//! [`VocabNetwork`]: crate::modules::network::VocabNetwork
68//! [`LatentNetwork`]: crate::modules::network::LatentNetwork
69//! [`final_norm`]: crate::modules::network::LatentNetwork::norm_f

80/// One layer's Multi-Gate Residual parameters: the mixer query `w⁽ᵝ⁾` + bias
81/// `b⁽ᵝ⁾`, and the aggregator (AttnPool) query `w⁽ᵅ⁾`.
82#[derive(Module, Debug)]
83pub struct MultiGateResidual {
84    /// Mixer query `w⁽ᵝ⁾ ∈ ℝ^d` (the per-stream sigmoid gate), `[d_model]`.
85    pub w_beta: Param<Tensor<1>>,
86    /// Aggregator query `w⁽ᵅ⁾ ∈ ℝ^d` (the AttnPool softmax), `[d_model]`.
87    pub w_alpha: Param<Tensor<1>>,
88    /// Per-stream mixer gate bias `b⁽ᵝ⁾`, `[n_stream]`.
89    pub b_beta: Param<Tensor<1>>,
90    /// Model width `d`.
91    #[module(skip)]
92    pub d_model: usize,
93    /// Number of parallel residual streams `n`.
94    #[module(skip)]
95    pub n_stream: usize,
96}
97
98impl MultiGateResidual {
99    fn scale(&self) -> f32 {
100        (self.d_model as f32).powf(-0.5)
101    }
102
103    /// The parameter-free RMS denominator `d(x) ∈ [‥, 1]` such that the RMSNorm
104    /// (matching [`RmsNorm`] math with `γ ≡ 1`) is `x / d(x)`. Returning the
105    /// denominator rather than the normalised tensor lets [`Self::normed_score`]
106    /// fold it out of the (feature-axis) score reduction, so the full-width
107    /// normalised tensor is never built. The fp16 path keeps the same
108    /// overflow-safe max-rescale, folded into the same scalar denominator.
109    ///
110    /// [`RmsNorm`]: crate::modules::RmsNorm
111    fn rms_denom<const D: usize>(&self, x: Tensor<D>) -> Tensor<D> {
112        match x.dtype() {
113            DType::F64 | DType::F32 | DType::Flex32 | DType::BF16 => {
114                let eps = div_eps(x.dtype());
115                // eps *inside* the root (matches `RmsNorm`): the `sqrt` backward
116                // is otherwise singular for a zero-norm slice.
117                ((x.clone() * x).mean_dim(D - 1) + eps).sqrt()
118            }
119            DType::F16 => {
120                use burn::tensor::ElementConversion;
121                let eps: f16 = f16::from_elem(div_eps(x.dtype())) * f16::from_f32(2.);
122                // Single global scalar `max`, reshaped to `[1; D]` so it
123                // broadcasts against the `[‥, 1]` partial RMS.
124                let max = x.clone().no_grad().detach().abs().max().reshape([1; D]);
125                let x_ = x.clone() / (max.clone() + eps); // x_.abs() <= 1
126                // eps inside the root (matches `RmsNorm`'s F16 branch).
127                let rms_partial = ((x.clone() * x_).mean_dim(D - 1) + eps).sqrt();
128                // `max` is detached (no backward), but floor it too so an
129                // all-zero tensor (`max = 0`) yields a nonzero denominator
130                // rather than `0/0` in the caller — matching the F32 branch.
131                rms_partial * (max + eps).sqrt()
132            }
133            _ => unreachable!("rms_denom expects a float dtype"),
134        }
135    }
136
137    /// The RMSNorm-then-dot score `scale · Σ_feat(x · w) / (rms(x)+eps)`,
138    /// shape `[‥, 1]`. The RMS denominator is constant over the feature axis, so
139    /// it is folded out of the reduction (via [`Self::rms_denom`]) — equal to
140    /// `Σ_feat(rms_norm(x) · w) · scale` but without materialising the full-width
141    /// normalised tensor.
142    fn normed_score<const R: usize>(&self, x: Tensor<R>, w: Tensor<R>) -> Tensor<R> {
143        let dot = (x.clone() * w).sum_dim(R - 1);
144        dot * self.scale() / self.rms_denom(x)
145    }
146
147    /// The shared mix + pool, generic over the streams rank `R` (the *stream*
148    /// axis is `R-2`, the *feature* axis `R-1`). [`Self::forward`] (`R = 4`) and
149    /// [`Self::step`] (`R = 3`) only differ by that rank, so both lift their
150    /// `layer_output` to a singleton stream axis, call this, and drop it again.
151    /// All reductions keep their axis (size 1) for broadcasting, so scores/gates
152    /// are `[…, n_stream, 1]` throughout.
153    ///
154    /// - `layer_output`: `F_l` lifted to a unit stream axis, `[…, 1, d_model]`
155    /// - `streams`: the `n_stream` residual streams, `[…, n_stream, d_model]`
156    ///
157    /// Returns `(h, streams')` with `h` still carrying its unit stream axis
158    /// (`[…, 1, d_model]`) and `streams'` the same shape as `streams`.
159    fn mix_pool<const R: usize>(
160        &self,
161        layer_output: Tensor<R>,
162        streams: Tensor<R>,
163    ) -> (Tensor<R>, Tensor<R>) {
164        let stream_axis = R - 2;
165        assert_eq!(
166            streams.dims()[stream_axis],
167            self.n_stream,
168            "the mixing phase runs at the full stream count"
169        );
170
171        // `b_beta` reshaped to broadcast on the stream axis: `[1, …, n_stream, 1]`.
172        let mut bias_shape = [1usize; R];
173        bias_shape[stream_axis] = self.n_stream;
174        let b_beta = self.b_beta.val().reshape(bias_shape);
175        // The query vector broadcasts on the feature axis: `[1, …, 1, d_model]`.
176        let w_beta = self.w_beta.val().unsqueeze::<R>();
177
178        // Mixer: independent per-stream sigmoid gate, `β`: `[…, n_stream, 1]`.
179        let beta = sigmoid(self.normed_score(streams.clone(), w_beta) + b_beta);
180        // Lerp `(1−β)·streams + β·layer_output` (equal to the paper's
181        // `streams + β·(layer_output − streams)`) — written so no full-width
182        // intermediate is retained: `streams` is the already-saved input and
183        // `layer_output` is `[…, 1, d_model]`, so neither `mul` saves a new
184        // `[…, n_stream, d_model]` tensor and the `+` saves nothing.
185        let new_streams = streams * (-beta.clone() + 1.0) + layer_output * beta;
186
187        (self.attn_pool(new_streams.clone()), new_streams)
188    }
189
190    /// The accumulation-phase counterpart of [`Self::mix_pool`]: append
191    /// `layer_output` (`[…, 1, d_model]`) to `streams` (`[…, k, d_model]`,
192    /// `k < n_stream`) as a new stream, then pool as usual. Returns
193    /// `(h, streams')` with `streams'` one stream wider.
194    fn append_pool<const R: usize>(
195        &self,
196        layer_output: Tensor<R>,
197        streams: Tensor<R>,
198    ) -> (Tensor<R>, Tensor<R>) {
199        assert!(
200            streams.dims()[R - 2] < self.n_stream,
201            "the accumulation phase stops at `n_stream` streams"
202        );
203        let new_streams = Tensor::cat(vec![streams, layer_output], R - 2);
204        (self.attn_pool(new_streams.clone()), new_streams)
205    }
206
207    /// Aggregator: depth-wise attention pooling over any stream count `k ≥ 1`
208    /// (softmax over the stream axis `R-2`), keeping that axis at size 1 so the
209    /// result still broadcasts against the streams.
210    fn attn_pool<const R: usize>(&self, streams: Tensor<R>) -> Tensor<R> {
211        let (stream_axis, feat_axis) = (R - 2, R - 1);
212        assert_eq!(
213            streams.dims()[feat_axis],
214            self.d_model,
215            "stream width must equal d_model"
216        );
217        let w_alpha = self.w_alpha.val().unsqueeze::<R>();
218        let alpha = softmax(self.normed_score(streams.clone(), w_alpha), stream_axis);
219        (alpha * streams).sum_dim(stream_axis)
220    }
221
222    /// Full-sequence mix + pool.
223    ///
224    /// - `layer_output`: this layer's transform `F_l`, `[batch, sequence, d_model]`
225    /// - `streams`: the `n_stream` residual streams, `[batch, sequence, n_stream, d_model]`
226    ///
227    /// Returns `(h, streams')`: the pooled input `h` for the next layer
228    /// (`[batch, sequence, d_model]`) and the updated streams (same shape as in).
229    pub fn forward(&self, layer_output: Tensor<3>, streams: Tensor<4>) -> (Tensor<3>, Tensor<4>) {
230        let (new_h, new_streams) = self.mix_pool::<4>(layer_output.unsqueeze_dim(2), streams);
231        (new_h.squeeze_dim(2), new_streams)
232    }
233
234    /// Single-token mix + pool (the [`Self::forward`] math with the sequence axis
235    /// dropped).
236    ///
237    /// - `layer_output`: `[batch, d_model]`
238    /// - `streams`: `[batch, n_stream, d_model]`
239    ///
240    /// Returns `(h, streams')`: `[batch, d_model]` and `[batch, n_stream, d_model]`.
241    pub fn step(&self, layer_output: Tensor<2>, streams: Tensor<3>) -> (Tensor<2>, Tensor<3>) {
242        let (new_h, new_streams) = self.mix_pool::<3>(layer_output.unsqueeze_dim(1), streams);
243        (new_h.squeeze_dim(1), new_streams)
244    }
245
246    /// Accumulation phase of [`Self::forward`]: `layer_output` becomes a **new**
247    /// stream instead of being mixed into the existing ones (the mixer gate is
248    /// not used at all). Only valid while `streams` holds fewer than `n_stream`
249    /// streams.
250    ///
251    /// - `layer_output`: this layer's transform `F_l`, `[batch, sequence, d_model]`
252    /// - `streams`: `[batch, sequence, k, d_model]` with `k < n_stream`
253    ///
254    /// Returns `(h, streams')`, `streams'` being `[batch, sequence, k+1, d_model]`.
255    pub fn accumulate(
256        &self,
257        layer_output: Tensor<3>,
258        streams: Tensor<4>,
259    ) -> (Tensor<3>, Tensor<4>) {
260        let (new_h, new_streams) = self.append_pool::<4>(layer_output.unsqueeze_dim(2), streams);
261        (new_h.squeeze_dim(2), new_streams)
262    }
263
264    /// Single-token [`Self::accumulate`] (the sequence axis dropped), the
265    /// accumulation-phase counterpart of [`Self::step`].
266    ///
267    /// - `layer_output`: `[batch, d_model]`
268    /// - `streams`: `[batch, k, d_model]` with `k < n_stream`
269    ///
270    /// Returns `(h, streams')`: `[batch, d_model]` and `[batch, k+1, d_model]`.
271    pub fn accumulate_step(
272        &self,
273        layer_output: Tensor<2>,
274        streams: Tensor<3>,
275    ) -> (Tensor<2>, Tensor<3>) {
276        let (new_h, new_streams) = self.append_pool::<3>(layer_output.unsqueeze_dim(1), streams);
277        (new_h.squeeze_dim(1), new_streams)
278    }
279}

281/// Configuration for a single [`MultiGateResidual`].
282#[derive(Config, Debug)]
283pub struct MultiGateResidualConfig {
284    /// Model width `d`.
285    pub d_model: usize,
286    /// Number of parallel residual streams `n`.
287    pub n_stream: usize,
288    /// Initial gate bias `b⁽ᵝ⁾` of the **first** stream (see module header).
289    #[config(default = 0.0)]
290    pub init_bias: f64,
291    /// Per-stream offset added on top of [`Self::init_bias`]: stream `i` starts
292    /// at `init_bias + i · init_bias_step`, so a negative step gives the streams
293    /// **different timescales** — an update-biased first stream down to a
294    /// carry-biased last one. `0` (the default) starts them all equal, which is
295    /// what the paper prescribes.
296    #[config(default = 0.0)]
297    pub init_bias_step: f64,
298}
299
300impl MultiGateResidualConfig {
301    /// The paper's depth-adaptive gate bias for the independent (sigmoid) mixer:
302    /// `−ln( √(L/21)·(e³+1) − n )`, where `L = n_mixing_layers` is the number of
303    /// layers that actually *lerp* (the stack depth minus the `n−1` accumulating
304    /// ones) and `n = n_stream`.
305    ///
306    /// It keeps the total per-layer increment `O(1)` — `σ(b) ∝ 1/√L` — so the
307    /// gates start biased towards *carry*, as in Highway Networks. Panics when
308    /// the stack is too shallow for the stream count (`√(L/21)·(e³+1) ≤ n`,
309    /// i.e. no carry budget is left to distribute).
310    pub fn depth_init_bias(n_mixing_layers: usize, n_stream: usize) -> f64 {
311        const L_BASE: f64 = 21.0;
312        const B_BASE: f64 = -3.0;
313        let inner = (n_mixing_layers as f64 / L_BASE).sqrt() * ((-B_BASE).exp() + 1.0);
314        assert!(
315            inner > n_stream as f64,
316            "depth_init_bias: {n_mixing_layers} mixing layers are too few for \
317             {n_stream} streams (pick a smaller `n_stream` or set the bias directly)"
318        );
319        -(inner - n_stream as f64).ln()
320    }
321
322    /// Allocate one layer's MGR parameters (`w⁽ᵝ⁾`, `w⁽ᵅ⁾` zero; `b⁽ᵝ⁾` the
323    /// arithmetic ramp `init_bias + i · init_bias_step`).
324    pub fn init(&self, device: &Device) -> MultiGateResidual {
325        let ramp = Tensor::<1, Int>::arange(0..self.n_stream as i64, device).float();
326        MultiGateResidual {
327            w_beta: Initializer::Zeros.init::<1, _>([self.d_model], device),
328            w_alpha: Initializer::Zeros.init::<1, _>([self.d_model], device),
329            b_beta: Param::from_tensor(ramp * self.init_bias_step + self.init_bias),
330            d_model: self.d_model,
331            n_stream: self.n_stream,
332        }
333    }
334}

336/// A stack of [`MultiGateResidual`]s for the enclosing
337/// [`Layers`](crate::modules::Layers). When `per_virtual` is `false` there is one
338/// module **per real layer** (virtual layers reuse them by real index); when
339/// `true` there is one **per virtual layer** (each virtual pass owns its own).
340#[derive(Module, Debug)]
341pub struct MultiGate {
342    /// The MGR modules: length `n_real_layers` (per-real) or `n_virtual_layers`
343    /// (per-virtual) — see [`Self::per_virtual`].
344    pub layers: Vec<MultiGateResidual>,
345    /// Number of parallel residual streams `n`.
346    #[module(skip)]
347    pub n_stream: usize,
348    /// `true` ⇒ one MGR per *virtual* layer (indexed by virtual position);
349    /// `false` ⇒ one per *real* layer (reused across virtual passes by real index).
350    #[module(skip)]
351    pub per_virtual: bool,
352}
353
354impl MultiGate {
355    /// Index into [`Self::layers`] for a given `(virtual_idx, real_idx)` layer
356    /// position: the virtual index when each virtual layer owns its MGR
357    /// ([`Self::per_virtual`]), otherwise the real index.
358    pub fn module_index(&self, virtual_idx: usize, real_idx: usize) -> usize {
359        if self.per_virtual {
360            virtual_idx
361        } else {
362            real_idx
363        }
364    }
365}

367/// How a [`Layers`](crate::modules::Layers) stack threads residuals between
368/// layers: the plain additive skip, or Multi-Gate Residuals.
369#[derive(Module, Debug)]
370pub enum Residuals {
371    /// Plain Pre-LN additive residual — each [`Layer`](crate::modules::Layer)
372    /// adds its own skip connection.
373    Standard(NoOp),
374    /// Multi-Gate Residuals: `n_stream` parallel streams with per-layer gated
375    /// mixing + attention pooling.
376    MultiGate(MultiGate),
377}
378
379/// Configuration / factory for [`Residuals`].
380#[derive(Config, Debug)]
381pub enum ResidualsConfig {
382    /// Plain additive Pre-LN residual.
383    Standard,
384    /// Multi-Gate Residuals over `n_stream` streams.
385    MultiGate {
386        /// Number of parallel residual streams `n`.
387        n_stream: usize,
388        /// First stream's initial gate bias (see
389        /// [`MultiGateResidualConfig::init_bias`]).
390        init_bias: f64,
391        /// Per-stream gate-bias offset (see
392        /// [`MultiGateResidualConfig::init_bias_step`]); `0` starts every
393        /// stream equal.
394        init_bias_step: f64,
395        /// `true` ⇒ one MGR per *virtual* layer; `false` ⇒ one per *real* layer
396        /// (reused across virtual passes). See [`MultiGate::per_virtual`].
397        per_virtual_layer: bool,
398    },
399}
400
401impl ResidualsConfig {
402    /// Build the runtime [`Residuals`] for a stack of `n_real_layers` real weight
403    /// sets unrolled over `n_virtual_layers` (virtual) passes. The MGR module
404    /// count follows `per_virtual_layer` (one per virtual layer vs one per real
405    /// layer).
406    pub fn init(
407        &self,
408        d_model: usize,
409        n_real_layers: usize,
410        n_virtual_layers: usize,
411        device: &Device,
412    ) -> Residuals {
413        match self {
414            ResidualsConfig::Standard => Residuals::Standard(NoOp),
415            ResidualsConfig::MultiGate {
416                n_stream,
417                init_bias,
418                init_bias_step,
419                per_virtual_layer,
420            } => {
421                let count = if *per_virtual_layer {
422                    n_virtual_layers
423                } else {
424                    n_real_layers
425                };
426                let layers = (0..count)
427                    .map(|_| {
428                        MultiGateResidualConfig::new(d_model, *n_stream)
429                            .with_init_bias(*init_bias)
430                            .with_init_bias_step(*init_bias_step)
431                            .init(device)
432                    })
433                    .collect();
434                Residuals::MultiGate(MultiGate {
435                    layers,
436                    n_stream: *n_stream,
437                    per_virtual: *per_virtual_layer,
438                })
439            }
440        }
441    }
442}
