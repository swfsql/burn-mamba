## Triage notes

**Decisions of the maintainer:**

- Do not rename the ladder, its examples or its symbol `R`.
- The README of the ladder states that `R` is a symbol of the input, not a **Reset**.

**Checks against the code** (at `40af69da`):

- In `../burn-stack/GLOSSARY.md`, a **Reset** is the mark on the first token of a
  segment. A packed call (`forward_packed`) receives this mark beside the input. The
  block then starts the segment from the start state.
- Each rung reads a stream that contains the symbol `R`. At each position, it reports
  what the other symbols did since the last `R`.
- Each rung is a Mamba-3 block. The block erases its state on `R` through its
  data-dependent `A` (`A(R) ≈ −20`). The hand-built solutions set this value, and
  training finds it.
- No rung makes a packed call. No file of the ladder names `forward_packed` or a
  segment.
- The section "The shared shape" of the ladder README calls `R` "a reset `R`". No
  sentence of the README tells it apart from a **Reset**.
- "reset" is on about 600 lines of the ladder. It is also in six example names of
  `Cargo.toml`, in a command of `CLAUDE.md` and in the folders of the runs.
- The `spinor-product` section says "packed two symbols per token". This is not a
  packed call.
