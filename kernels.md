# Kernel launch counts

One SSM block per case, generated by `./kernels.sh` on 2026-09-10. Each cell is the number of GPU kernels launched by one iteration of that case; lower is better.

Counts are exact and repeatable — they follow from the op graph, not from the machine — so one iteration per case is measured rather than a criterion sample. They are read from cubecl's own per-sync profiling summary, which serialises the queue: the counts are meaningful, the timings in `target/kernel-logs/` are not.

| run | configuration |
|---|---|
| `cuda` | `batch=2 sequence=256 d_model=256 state_rank=64 per_head_dim=64 warmup_iters=1 backend=dispatch<cubecl<cuda>>` |
| `cuda-fusion` | `batch=2 sequence=256 d_model=256 state_rank=64 per_head_dim=64 warmup_iters=1 backend=dispatch<fusion<cubecl<cuda>>>` |
