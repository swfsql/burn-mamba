# Kernel launch counts

One SSM block per case, generated by `./kernels.sh` on 2026-11-09. Each cell is the number of GPU kernels launched by one iteration of that case. Lower is better.

One iteration per case is measured rather than a criterion sample. A `cuda` count follows from the op graph, not from the machine, so it is exact and repeatable. The counts come from the per-sync profiling summary of cubecl, which serialises the queue. So the timings in `target/kernel-logs/` have no meaning. A count of the autotune column also depends on the candidates that the tuner selects in each process, so it can change between runs. That column comes from 3 run(s). A cell `a–b` gives the lowest and the highest count.

| run | configuration |
|---|---|
| `cuda` | `batch=2 sequence=256 d_model=256 state_rank=64 per_head_dim=64 warmup_iters=3 backend=dispatch<cubecl<cuda>>` |
| `cuda-fusion` | `batch=2 sequence=256 d_model=256 state_rank=64 per_head_dim=64 warmup_iters=3 backend=dispatch<fusion<cubecl<cuda>>>` |
