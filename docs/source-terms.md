# Source terms

Look up a word of a Mamba paper, a Mamba blog, the official code or mamba3-minimal
here before you port from that source. An entry gives our term and the wrong port
that the word can cause. Read the cited lines before you port from an entry.

`GLOSSARY.md` and `../burn-stack/GLOSSARY.md` are the authority for our words, and
this doc renames nothing (ADR-0008). A word goes in a glossary if an agent that
reads only our code and docs needs it. A word goes here if only an agent that reads
the sources needs it. The words of the H-Net and Multi-Gate Residuals papers are in
`../burn-stack/docs/source-terms.md`.

A source citation has the form `file:line`, with these path aliases. A citation of
our own code gives the item name.

thing. A split is one source word that covers several terms of ours. The entries go
from the highest risk of a wrong port to the lowest. The order is a judgement.
